# Paper Items — Current Entry Point

Before creating or materially redesigning any Figma item, read:

1. `FIGMA-GLOBAL-QUALITY-STANDARD.md`
2. the target item's `CURRENT-STATUS.md` or Current authority document
3. the target item's `ASSET-REGISTER.md`
4. the target item's `PLACEMENT-PLAN.md` / `FIGMA-PLACEMENT-PREP.md`
5. the target item's copy and dummy-data files
6. the latest Figma execution checkpoint

## Mandatory shared rule

All current and future Figma work in this wedding project must:
- avoid generic AI-looking layouts
- use item-specific art direction
- preserve native editable text
- preserve semantic replaceable image roles
- use named styles/components for repeated rules
- use creative asymmetry only after underlying alignment is stable
- perform screenshot QA and evidence-driven correction
- record actual live state and remaining blockers in GitHub

The mature るるぶ editorial system is a workflow reference, not a visual template for passport, boarding pass, ticket, signage, or other items.
