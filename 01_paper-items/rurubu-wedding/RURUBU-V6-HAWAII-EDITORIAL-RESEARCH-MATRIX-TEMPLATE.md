## Extracted principles

### Cover system

- Destination recognition must happen before reading body text.
- One dominant photo owns at least roughly half of the front cover.
- Masthead/title must have a stable silhouette and reliable contrast.
- Supporting cover lines are grouped into 2–4 unequal sets.
- Use at most one vertical/edge reading axis.
- Full rounded cover cards start at 0 and are added only for semantic containment.
- Hawaii signal comes from photography, light, material, and palette before hibiscus/palm decoration.

### Inside system

Profile/Q&A:
- asymmetric profiles
- direct text, rules, pull quotes, and one optional main panel
- generated dummy faces must remain identity-neutral

History:
- chronology is the alignment logic
- calm route/map field
- one lead memory image plus supporting milestones

Memory spots:
- one lead destination plus three support destinations
- markers shared between map and captions
- mixed ratios with consistent caption relationship

### Back-cover system

- quieter density than the front
- one emotional closing image
- Friends & Family photographs are unequal in size and role
- one coherent closing route/date/gratitude module
- no repeated promotional card grid

### Typography system

1. display / issue promise
2. section heading
3. article heading
4. body
5. caption / note / folio

Mandatory QA:
- Japanese line-start and line-end rules
- punctuation and bracket treatment
- Japanese/Latin/numeral consistency
- short, expected, and 130–150% long copy
- actual-size small-text review

### Image-generation system

Before generation, every role defines:
- target aspect ratio
- focal subject
- visual direction
- text-safe zone
- crop range
- color/time-of-day relationship
- recognizable-person rule
- prohibited artifacts
