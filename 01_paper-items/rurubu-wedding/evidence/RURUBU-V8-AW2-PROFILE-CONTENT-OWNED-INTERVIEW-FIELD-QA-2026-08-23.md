## Fresh professional research used in this run

This run deliberately moved away from the recent V8 grid and photo-selection references.

1. Pentagram's editorial-design practice describes publication design as a balance of theme and variations: a familiar setting should allow stories to unfold in new and surprising ways rather than repeat one module mechanically.
2. Veronica Ditting's description of an editorially driven process emphasizes the dialogue between form, creative direction, photography and language rather than treating form as an independent template.
3. Seibundo Shinkosha's `idea` magazine authority reinforces that a publication can retain one editorial identity while changing specification and treatment according to subject matter; consistency does not require uniform page modules.

Rurubu-specific hypothesis:

> On an interview/profile spread, repeated Q&A structure should not automatically force every answer into the same spatial cadence. If one answer performs the emotional closing job, test whether the interview field can remain disciplined while giving that answer a materially different role.

This is not a rule to make every third answer larger, nor permission for decorative asymmetry.

## Learning

`RSL-236 / F-RSL-236-INTERVIEW-RAIL-REPEATS-EQUAL-QA-MODULES-DESPITE-UNEQUAL-ANSWER-SALIENCE`

Transferable hypothesis: when an interview/profile spread uses repeated question modules, test whether the semantic role of the answers is actually equal. If one answer carries a different editorial job—opening, contrast, emotional close, or transition—allow a bounded content-owned field variation while preserving reading order and publication identity.
