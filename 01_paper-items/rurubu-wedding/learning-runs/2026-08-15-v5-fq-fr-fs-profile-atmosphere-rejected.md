# 2026-08-15 — V5 FQ / FR / FS profile-atmosphere studies rejected

Scope: Rurubu WEDDING only.

## Starting point

FO `1200:2` remained the adopted inside comparator after the Memory Spots semantic-coherence improvement. Its left profile page uses two distinct non-person atmosphere images with native `SHOGO` / `SHI-CHAN` identity text placed separately on the cream information plane.

## Visible problem explored

Although the identity semantics were safe, the two upper atmosphere images can still read as two pseudo-profile panels. The experiment asked whether one shared non-person editorial hero would feel more intentional and less like two substitute portraits.

## FQ — rejected

FQ `1204:2` replaced the two upper profile atmosphere roles with:
- one full-width verified street/travel atmosphere hero;
- one exact Q60 Yokohama inset.

Result: the page became more obviously travel-oriented, but the same street source also served as the dominant Memory Spots lead on the opposite page and the Q60 skyline also appeared as Memory Spots support 02. The repeated dominant/support sources became conspicuous across one spread and made the system feel templated.

FQ was renamed `REJECTED_HIDDEN_INSIDE_FQ_SHARED_STREET_DUPLICATE_ROLE_2026_08_15` and hidden.

## FR — rejected

FR `1205:2` kept the shared-hero concept but changed the main profile hero to the verified cafe/lifestyle atmosphere, retaining the Q60 skyline inset.

Result: it avoided the dominant street repetition, but the shared food/lifestyle hero plus skyline inset weakened the visual distinction between the two named profile columns and pushed the page toward a generic cafe/travel feature rather than a couple-profile editorial.

FR was renamed `REJECTED_HIDDEN_INSIDE_FR_SHARED_CAFE_PROFILE_WEAK_DIFFERENTIATION_2026_08_15` and hidden.

## FS — rejected

FS `1206:2` removed the Q60 inset entirely, leaving one shared cafe atmosphere hero above the two native identity columns.

Result: identity safety stayed strong and source repetition decreased, but the page became too flat and lost the asymmetric photo rhythm expected from the Rurubu-like direction. The single shared image did not provide enough individual editorial differentiation to beat FO at whole-spread scale.

FS was renamed `REJECTED_HIDDEN_INSIDE_FS_SINGLE_SHARED_PROFILE_MOOD_TOO_FLAT_2026_08_15` and hidden.

## Root-cause learning

A safe non-person substitute is not automatically improved by collapsing multiple roles into one generic shared hero. For profile/editorial pages without verified real-person photography, the design still needs **distinct editorial identity cues** without implying that an invented raster depicts the named person.

Useful axes to separate:
1. identity safety;
2. source repetition across the spread;
3. individual profile differentiation;
4. photo-led rhythm;
5. semantic relevance to the profile story.

Optimizing only one axis can regress the others.

## V6 implication

For V6, define two non-person profile visual roles before generation/selection, each tied to a different verified interest/object/atmosphere concept rather than two generic substitute portraits or one generic shared hero. Keep names and mutable facts native and clearly detached from raster identity. If real verified couple photography becomes available, it should enter through explicit provenance rather than inheriting these dummy-image semantics.
