# Lesson — Repeated theme symbols need distinct editorial jobs

Date: 2026-08-03
Applies to: Rurubu V5, V6, and later wedding editorial items
Status: `TESTED / NOT_YET_PROMOTED_TO_PROJECT_RULE`

## Source

Live V5 front-cover review before and after hiding node `77:252 / RURUBU/Icon/plane`.

## Observed opportunity

The front cover used several independent aviation signals in the same upper region:

- a flight-path motif inside/around the masthead
- a ticket-like date badge with aviation details
- a separate blue plane icon beside the date badge

Each element was individually compatible with the travel theme, but the cluster repeated the same message. The separate icon did not identify a destination, date, page, category, route, or action.

## Hypothesis

When a theme is already established by stronger identity and information-bearing elements, removing a weaker duplicate symbol should improve hierarchy without weakening recognition.

## Test

The separate plane frame was hidden rather than deleted. Before/after screenshots were compared at whole-cover, reading, and detail scales.

## Result

The date badge became a clearer single issue-information unit, the masthead/date area became calmer, and travel-guide recognition remained intact. No information, structure, text, crop, or rollback state was lost.

## General editorial principle

A thematic icon earns its place through a distinct editorial job, not merely by matching the theme. Multiple airplanes, stamps, cameras, hearts, flowers, or route marks in one region must be evaluated as a cluster.

Useful jobs include:

- identifying a category
- linking a map or route
- marking a page reference
- clarifying date or location
- indicating a photograph or recommendation
- supporting a deliberate reading direction

A symbol that only repeats atmosphere is a subtraction candidate when stronger signals already exist.

## Possible regression

Removing too many thematic cues can make an item generic or overly quiet. Therefore, this lesson does not authorize blanket icon removal. Whole-item recognition and emotional tone must be checked after every subtraction.

## Process change

During decorative audits:

1. inventory all repeated theme symbols in the local visual cluster
2. state the editorial job of each
3. preserve the strongest information-bearing signal
4. prototype hiding the weakest duplicate
5. compare whole-item recognition and reading order
6. keep rollback available

## Next application

Review the V5 circular-snap camera icon separately. Unlike the removed plane, the camera icon directly labels a photo-oriented module, so it may be functionally justified. Test rather than assume.
