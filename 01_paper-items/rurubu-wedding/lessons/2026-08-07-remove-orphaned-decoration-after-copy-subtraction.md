# Remove Orphaned Decoration After Copy Subtraction

Date: 2026-08-07
Status: `VERIFIED FOR V5 / NOT YET PROJECT_RULE`

## Source

Live Rurubu V5 outer back page. After `77:142 / AUTH_BACK_MICRO_1` was hidden, the paired pink dashed line `77:141 / AUTH_MICRO_RULE` remained above `77:47 / BACK_VISUAL_HISTORY_TITLE`.

## Hypothesis

Removing text can leave behind a decorative dependent that no longer explains, separates, anchors, or connects anything. Hiding that orphaned dependent should improve editorial coherence more than restyling it.

## Result

Hiding `77:141` removed the unexplained accent while preserving `OUR JOURNEY ROUTE`, route geometry, native text, all image fills, the fold guide, semantic nodes, and V4 rollback frames. Whole-item, reading/page, and actual-size/structure review found no empty hole, clipping, collision, text reflow, or hierarchy loss.

## Failure / limit

Do not remove a rule merely because nearby copy changes. Keep it when it still defines grouping, provides necessary separation, links a caption and image, or remains visually functional at actual print size.

## Adopted use

For V5, every subtraction must trigger a dependent-element audit covering rules, brackets, underline strokes, tape, badges, shadows, and background fields. Preserve removed dependents as hidden rollback nodes when practical.

## Next application

Apply this audit to future bounded V5 changes, but prioritize closing dominant-photo provenance and derivative-quality evidence before additional low-impact decoration work.
