# Duplicate Section Ribbon Should Yield to the Native Heading

Date: 2026-08-06
Status: `VERIFIED FOR V5 / NOT YET PROJECT_RULE`

## Source

Live Rurubu V5 back cover, nodes `77:33`, `77:88`, and `77:89`.

## Hypothesis

When a magazine section already has a clear native heading, a second ribbon repeating the same label can be removed without harming navigation.

## Result

Hiding the duplicate Friends & Family ribbon preserved the section title, photos, captions, reading order, fold guide, semantic structure, and rollback nodes while reducing one UI-like horizontal color field.

## Failure / limit

This is not a blanket rule against ribbons. A ribbon may remain useful when it is the only section locator, supplies necessary contrast, or carries distinct information.

## Adopted use

For Rurubu V5, subtract duplicate section-label ribbons before adding new decorative devices. Verify at whole-item, reading, and actual-size scales.

## Next application

Audit other remaining labels only for true semantic duplication. Do not remove unique navigation or factual content.
