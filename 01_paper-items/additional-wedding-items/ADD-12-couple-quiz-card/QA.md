# ADD-12 新郎新婦クイズカード — QA

Status: `QA_CONTRACT_READY`

## Content QA

- [ ] 設問本文が本人確認済み
- [ ] 正解が本人確認済み
- [ ] 選択肢に重複・曖昧さがない
- [ ] 正解が複数解釈できない
- [ ] 内輪すぎて大半のゲストが参加できない設問へ偏っていない
- [ ] 個人情報・センシティブ情報・誰かを傷つける内容を含まない
- [ ] 回答方法と締切が明確
- [ ] 記名／匿名、景品、抽選の扱いが明確
- [ ] placeholder、TBD、仮回答が最終PDFに残っていない

## Visual QA

- [ ] タイトルより設問本文が視線の中心になっている
- [ ] 問題番号→本文→選択肢→回答動作の順に読める
- [ ] 選択肢が機械的な均等カードUIになっていない
- [ ] 文章量の差を光学調整している
- [ ] 正解を示唆する色・位置・面積差がない
- [ ] 装飾が設問や記入欄を圧迫していない
- [ ] 既存4種の縮小コピーに見えない
- [ ] 旅行テーマは構造と編集判断で表現され、アイコンの羅列になっていない

## Mechanical QA

- [ ] A6仕上がり寸法が正しい
- [ ] 塗り足し3 mmを確保
- [ ] 安全域5 mm以上を確保
- [ ] 表裏の天地・綴じ方向が正しい
- [ ] 回答マーク欄が実際の筆記具で記入可能
- [ ] 細線が印刷で消えない
- [ ] 黒の総インキ量が過剰でない
- [ ] 画像を使う場合は実効解像度を確認
- [ ] フォント置換・文字化けがない

## Screenshot QA

Figma再開後、以下を最低限保存する。

1. 表面全体
2. 裏面全体
3. 問題本文と選択肢の拡大
4. 表裏を並べた比較
5. A4面付け版（作成した場合）

スクリーンショット上で発見した欠陥は、修正前後のnode IDと判断理由を記録する。

## Physical QA

- [ ] 100%実寸で試し刷り
- [ ] 卓上照明下で本文を読める
- [ ] 鉛筆・ボールペンで回答しやすい
- [ ] 裏写りが許容範囲
- [ ] 回収箱・受付・卓上のいずれかで用途が迷わない
- [ ] 裁断後に問題番号・回答欄が窮屈でない

## Reject conditions

以下のいずれかがあれば完成扱いにしない。

- 仮設問や仮正解の混入
- 正解の視覚的誘導
- 記入欄不足
- 表裏方向の誤り
- 小さすぎる文字
- 本人写真の無断加工・AI人物代替
- 他アイテムの見た目をそのまま流用
