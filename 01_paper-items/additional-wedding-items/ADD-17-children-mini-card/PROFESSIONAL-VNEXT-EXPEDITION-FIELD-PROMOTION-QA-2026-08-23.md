## Why the previous Current was reopened

The prior `FOLDOUT DISCOVERY MAP` Current (`62:2 / 62:22`) was structurally strong and had already passed professional QA, but fresh whole-item review still showed a relatively adult/worksheet-like visual temperature for an item whose role is **playful exploration**.

The problem was not missing information or missing image assets. The page needed more anticipation, movement and child-neutral delight without becoming a web form, party clip-art sheet or age-specific illustration.

The previous Current was not deleted. It is retained as rollback/history and was only opened for comparison after the new clean-room direction matured.

## Rejected iterations during this run

### Disconnected color bars

The first full-size A build used three independent cobalt/pink/yellow bars. Screenshot review showed that they read as generic decorative strokes rather than one meaningful travel/discovery gesture.

Method switch: replaced the three bars with one coherent route-like vector gesture and moved it away from the activity surface.

### Rounded footer containment

The first build placed the closing line inside a rounded cobalt footer box. At thumbnail scale it reintroduced the exact pill/card vocabulary the visual program is trying to avoid.

Method switch: removed the container, retained only open native copy + a short functional color accent.

### Initial long-copy spacing

The first realistic stress made the long `[お題]` copy visually collide with the activity corner cue, while the long optional name left insufficient reserve above the footer.

Repair:
- widened the prompt lane and used `31 px / 46 px` native typography;
- moved the four activity ticks lower so the prompt expands above them;
- raised optional name/date to create a stable lower reserve;
- kept the headline size and activity openness instead of shrinking all type.

Fresh stress screenshot after repair: PASS.
