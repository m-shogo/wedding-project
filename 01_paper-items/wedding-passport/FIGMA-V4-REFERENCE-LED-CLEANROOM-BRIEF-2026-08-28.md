## V4 art direction

Working direction name: `NAVY BOOKLET / IVORY INDEX / MUTED GOLD`

### Front cover

- dominant: deep navy, not inherited green;
- support: warm ivory / paper-white;
- accent: muted antique gold, with a very small optional warm-red data accent only if the reference hierarchy needs it;
- first read: `WEDDING PASSPORT` / Japanese primary title treatment;
- second read: date/location;
- one strong generated/composed fixed identity asset may occupy the middle 45–55% of the page, but must not contain variable text;
- avoid fake passport numbers, fake MRZ, fake official seals, generic airplane clip-art, badge sheets, or travel-sticker clutter.

### Back cover

- should feel like the closing face of the same physical booklet, not a second poster;
- keep a large calm text-safe zone for native thank-you / note copy;
- fixed ornament should be subordinate and asymmetric rather than a full-width web-header/footer device;
- no generated lettering.

### Menu + drink

- native text is the hero because final copy changes;
- use editorial grouping rather than rounded cards;
- allow one composed/fixed paper or border treatment only if it materially improves reference match;
- establish one strong vertical or offset information rhythm; do not make food and drink two identical equal UI panels;
- actual-size long-copy legibility wins over visual density.

### Seating

- primary user task: find table + name quickly;
- 11 groups × max 7 remain native/adaptive;
- V4 may test a central visual/map/index field with peripheral table clusters only if long-name stress remains readable at actual size;
- do not use a literal world map if it consumes the name area or becomes first-read;
- table labels stay subordinate to guest names.
