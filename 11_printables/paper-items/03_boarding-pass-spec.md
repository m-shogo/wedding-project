# 03 BOARDING PASS Spec

更新: 2026-07-29

## 役割
受付で使う航空チケット風エスコートカード。**見た瞬間に自分の名前とTABLEが分かること**を最優先にする。

## 面構成
- FRONT: BOARDING PASS / GUEST NAME / TABLE / DATE / FROM / TO / GATE
- BACK: THANK YOU / 会場・旅程メッセージ / ルート線 / 装飾バーコード
- 右半券: TABLE / serial / 任意の演出要素

## 固定方向性
- Ivory / Navy / restrained Gold
- 必要ならテーブルごとにMuted Accentを1色追加
- 横長、右側stub、ミシン目表現
- 実在航空会社の券面をコピーしない

## 情報優先順位
1. GUEST NAME
2. TABLE
3. DATE / VENUE
4. GATE / FROM / TO等の演出情報

## 量産ルール
- ゲスト名、TABLE、必要なら色だけを差し替えられるテンプレート構造にする。
- 長い名前への対応ルールを事前に定義する。
- 文字数差でレイアウトが崩れないよう、Auto Layout / text bounds / min font sizeを設計する。
- CSV/表形式データからの一括流し込みを想定する。

## 半券
- 実際に投票・抽選・受付などで使う目的が決まった場合のみ機能化。
- 目的がないなら「半券らしく見せるだけ」にして、無理に情報を増やさない。

## 避ける
- 装飾優先で名前が小さくなること
- 実在航空会社ロゴ
- 実際に読み取れる不要なQR/バーコード
- 小さなラベルの乱立
- TABLE番号が本文と同じ大きさになること
