# 05 Shared Design Rules

更新: 2026-07-29

## 目的
4つのモチーフが別でも、**同じ結婚式のシリーズ**に見えるようにする。

## 全体トーン
- 上品 65%
- 楽しさ 35%
- 旅行
- 少しレトロ
- 晴れやか
- 情報設計は現代的

## 共通ベース
- Navy
- Warm Ivory

## 補助色
- Sky Blue
- Mint / Sage
- muted Red
- Yellow
- restrained Gold

## 色の使い方
- 1面で強いアクセント色は1〜2色まで。
- 色数が多い場合も、彩度と面積に強弱をつける。
- Goldはベタ面の主役にせず、罫線・ロゴ・小さなアクセント中心。
- 背景と本文のコントラストは実寸印刷で確認する。

## タイポグラフィ
### 原則
- 1アイテム内のメイン書体は2ファミリー程度まで。
- Display / Heading / Body / Caption の役割を分ける。
- 小さい印刷物は“画面で読める”ではなく“原寸で読める”を基準にする。
- 文字サイズだけで階層を作らず、weight / spacing / color / ruleも使う。

### 日本語
- 見出し: 個性を出してよい。
- 本文: 読みやすさ優先。
- 和文の字間を英字と同じ感覚で広げすぎない。

## グリッド
- Figmaで最初にレイアウトガイドを作り、後から目分量で置かない。
- Outside / Inside / Fold / Safe Area / Bleed をレイヤー分離する。
- ページ内の写真・見出し・本文の左端/右端を意図的に揃える。
- 雑誌風でも“ランダム配置”ではなく、グリッドから意図的に外す。

## 余白
- 空白は余った場所ではなくデザイン要素として確保する。
- 1ブロック内の内側余白、ブロック間余白、ページ外周余白を混同しない。
- 同階層の余白は同じ数値を使う。

## 共通モチーフ
- Stamp
- Route / rail / flight path
- Map line
- Serial number
- Fine rule
- Emblem
- Ticket / passport micro-details

## モチーフの制限
- 1面に主役モチーフ1つ、補助2〜3つを目安にする。
- 飛行機・地球・コンパス・スタンプ・地図を全部同じ強さで出さない。

## 写真
- 最終版は実写真。
- 表紙では写真を主役にできるだけの面積を与える。
- 写真上に文字を置く場合、顔・重要被写体と競合させない。
- 写真を無理に多数入れず、用途に応じて大写真と小写真の役割を分ける。

## アイコン
- 1アイテム内でストローク系/塗り系を混在させない。
- 同じライブラリまたは同じ線幅へ統一する。
- Iconify等を使う場合も、セットを決めて混在を避ける。

## 禁止
- 既存ブランド/公的券面の完全コピー
- AI画像に生成された文字を最終ロゴとしてそのまま使う
- 出典不明のSNS画像を制作素材として転載
- “情報を足せば本物っぽい”という発想
- 影・グラデーション・テクスチャを理由なく重ねる
