# 04 青春ふたりきっぷ Spec

更新: 2026-07-29

## 役割
MINTIAへ貼る、鉄道記念券風のプチギフトラベル。**小さな面積でも“切符感”と“結婚式の記念感”が両立すること**を目標にする。

## 固定文言
- `青春ふたりきっぷ`
- `WEDDING JOURNEY TICKET`
- `新郎駅 → 新婦駅 → 未来行き`
- `2026.10.24`

## 固定方向性
- Sage / aged Ivory / Ink Black
- Accent: muted Red / railway Blue
- 表面のみ
- 細い地紋、二重罫線、番号、架空改札印
- 電車モチーフは小さく、レトロ寄り

## 情報優先順位
1. 青春ふたりきっぷ
2. 新郎駅 → 新婦駅 → 未来行き
3. 2026.10.24
4. 発行番号 / スタンプ / 補助文

## 小型印刷ルール
- MINTIA現物を実測するまで最終寸法を固定しない。
- 小さい文字・細線は実寸試し刷りを必須にする。
- 地紋は画面上で見える強さではなく、印刷時の潰れ・モアレを考えて決める。
- 赤青スタンプはアクセント。文字を覆わない。

## 使いたい要素
- 連番/発行番号
- 券面中央の区間表示
- 角の小さな日付
- 架空の改札印
- 線画の電車
- 切符らしい細則風マイクロコピーは少量のみ

## 避ける
- JRロゴ/社名/真正券面のコピー
- 実際の乗車条件や運賃表記のコピー
- 小さすぎる細則で埋める
- 汚し加工のやりすぎ
- 可愛すぎるキャラクター化
