# 01 WEDDING PASSPORT Spec

更新: 2026-07-29

## 役割
旅行テーマの結婚式を、上質な旅券風冊子として見せる。見た目だけのパスポート再現ではなく、**MENU / DRINK / SEATINGを美しく読ませる印刷物**として成立させる。

## 面構成
- 表紙: `WEDDING PASSPORT`
- 裏表紙: 短い旅程メッセージ / 架空の消印 / 控えめな番号・バーコード風装飾
- 中面左: `MENU & DRINK`
- 中面右: `SEATING CHART`

## 固定方向性
- Navy / warm Ivory / restrained Gold
- Stampだけ muted Red / muted Blue
- 少しクラシックだが、古びすぎない
- 紙の質感は上品。過剰なヴィンテージ汚しはしない
- 表紙は装飾を絞り、中央エンブレムとタイトルに集中

## 情報優先順位
1. MENU / DRINK / SEATINGの可読性
2. 冊子としての格調
3. 2026.10.24 / YOKOHAMA
4. 旅行スタンプや航路の世界観

## 座席表ルール
- 最終レイアウトは実際の11卓と席次データを見て決める。
- ゲストが自分の卓・名前を最短で見つけられることを優先。
- 背景地図は5〜12%程度の視覚強度を基準に検討し、名前より目立たせない。
- 新郎新婦席は明確に別階層にする。

## MENUルール
- COURSE名 → 料理名 → 補足の3階層まで。
- 全文中央揃えに固定しない。内容量に応じて左揃え/中央揃えを比較する。
- Drinkはカテゴリ分けし、長い一覧を一続きの小文字にしない。

## 表紙ロゴ / エンブレム
- AI画像上の架空ロゴをそのまま使わず、最終Figmaではベクターで再構築。
- 地球 / 航路 / 飛行機 / 月桂樹を全部詰め込まない。主役を1〜2モチーフに絞る。
- `WEDDING PASSPORT` の文字組み自体をロゴとして成立させる。

## 避ける
- 日本国旅券・国章・MRZ等の完全コピー
- 実在航空会社ロゴ
- 金色の多用
- 旅行アイコンの詰め込み
- 細すぎる文字
- 背景地図が主役になる構成
