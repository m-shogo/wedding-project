# 06 Pre-Figma Readiness Gate

更新: 2026-07-29

## 目的
Figmaで考え始めず、**考える工程をほぼ終えてからFigmaで精密に組む**ための開始ゲート。

## Global Gate
以下7項目中、最低6項目が揃うまで本番Figmaを `CURRENT` にしない。

- [ ] デザイン方向性
- [ ] 参考選別 `STRONG / PARTIAL / REJECT`
- [ ] 面構成
- [ ] 実寸または印刷サイズ方針
- [ ] 写真枚数
- [ ] 本文のおおよその文字量
- [ ] 印刷方式

## Figma file rule
本番は1アイテム1Figmaファイル。4 URL。

各ファイル内は可能な範囲で以下を持つ。
- `00_README`
- `01_REFERENCE`
- `02_ASSETS`
- `03_FOUNDATIONS`
- `04_EXPLORATION`
- `05_CURRENT`
- `06_PRINT`
- `90_ARCHIVE`

Starterプラン等のページ制限がある場合は、PageではなくSectionで同等の構造を作る。
