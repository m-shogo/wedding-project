# 5. True alpha — HARD

For floating generated assets:

Preferred:
`direct true alpha → immediate alpha-channel preflight → Figma`

If direct alpha fails:
`one safe flat matte → one background extraction → alpha preflight`

Never use checkerboard as a matte/background.
Baked checkerboard RGB is a generation failure.

Verify both:
- outside transparency
- intended interior opacity/detail

Do not accept halo, erased light/white petals, damaged thin routes or holes.
