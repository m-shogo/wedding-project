# モーション図鑑 Property Help / 日本語説明ガイド

Status: ACTIVE / MUTABLE  
Date: 2026-08-26  
Scope: `wedding-project` Movie only

## Purpose

モーション図鑑では、Motion名だけでなく、各Propertyの値が「何を意味し、変えると映像がどう変わるか」を日本語で短く説明できるようにする。

最重要原則:

> **値だけを見せない。変えるとどう見えるかまで日本語で分かるようにする。**

> **見れば分かる部分は動画Previewを優先し、説明は短く補助する。**

## UI方針

説明は常時長文表示しない。

- Motionカードの短い説明
- `?` / tooltip
- Property accordion内の補足
- 必要時だけ「詳しく見る」

を基本とする。

## Property説明例

### Transform

- X: 左右の位置。値を小さくすると左、大きくすると右へ動く。
- Y: 上下の位置。値を小さくすると上、大きくすると下へ動く。
- Scale: 大きさ。100%が元サイズ。大きくすると寄り、小さくすると引きになる。
- Rotation: 回転角度。0°が元の向き。
- Z / Depth: 3D対応Motionだけで表示。奥行き方向の移動に使う。

現在値の説明例:

```text
Y -200% → 20%
画面のかなり上から、最終位置まで下りてきます。
```

### Opacity

```text
0% = 見えない
100% = 完全に見える
0% → 100% = 徐々に現れる
```

### Easing

- 自然に止まる: 最初は速く、最後にゆっくり止まる。
- 自然に動き出す: 最初はゆっくり、後半に速くなる。
- ゆっくり始まって止まる: 始まりと終わりの両方が滑らか。
- 一定速度: 最初から最後まで同じ速さ。

DaVinci固有のSpline/Bezier値は通常UIで説明しすぎない。必要時のみ「DaVinciで見る」へ降りる。

### Blur

ぼかし量。大きくすると輪郭がぼやけ、小さくするとくっきりする。

### Crop

画像や動画の見せる範囲。上下左右のどこを切るかを調整する。

### Mask

見える範囲を決める。Maskを動かすことで、文字や画像を隠した状態から見せる演出を作れる。

### Perspective

遠近感・傾きを調整する。通常Motionでは隠し、使用するMotionだけに表示する。

## Current-value explanation

可能ならPropertyの一般説明だけでなく、現在設定されている値を自然文へ変換する。

例:

```text
Transform
X -30% → 50%
Y -200% → 20%
Duration 0.8秒
Easing 自然に止まる

説明:
画面左上の外側から0.8秒かけて入り、最後はゆっくり止まります。
```

これにより、数値を学習しながら編集できる。

## Japanese-first naming

ユーザー向けは日本語を主とする。

```text
下から文字が出る
Mask Reveal
```

のように、日本語名を主表示し、正式名称は補助表示にする。

検索も日本語・擬音・用途で見つかることを優先する。

例:

- シュッ
- ふわっと
- 上から入る
- 写真を少し見せてから
- 旅行先の名前を出したい

## Boundary

説明機能を巨大な動画編集教科書にしない。

```text
動画Preview
→ 短い日本語説明
→ Propertyの意味
→ 必要ならDaVinciの仕組み
```

の順に段階的に見せる。

> **日本語で意味が分かる。でも説明を読まなくても動画を見れば選べる。**
