# 初期制作環境の判断

## 日付

2026-06-07

## 判断

このリポジトリは、実素材そのものよりも、構成、判断、ログ、プロンプト、編集指示を管理する場所にする。

## 理由

- 写真、動画、音源、最終書き出しには個人情報と権利リスクがある。
- GitHubに大きな素材を入れると運用が重くなる。
- 結婚式ムービーでは、素材の採否と編集判断が後から見返せることが重要。
- AI動画は短尺背景素材として資産化し、複数ムービーへ再利用する。

## 運用

- 実ファイルはローカルフォルダに置く。
- Gitには `.gitkeep`、制作ドキュメント、CSVログ、プロンプト、判断メモを残す。
- 外部AIやSNS投稿に進む前に、権利・プライバシー確認をする。
