# モーション図鑑 Compare Mode v1

Date: 2026-08-26
Status: Accepted
Scope: Movie / モーション図鑑

## 結論

モーション図鑑の比較機能は、最初は **2つ比較** に限定する。

3つ以上を同時表示するとPreviewが小さくなり、動画の違いを判断しにくくなるため、A/B比較を基本とする。

## UX

ユーザーは図鑑上で2つまで比較対象を選び、`比較する` を押す。

比較画面は左右2ペイン。

```text
┌──────────────┬──────────────┐
│ A             │ B             │
│ 下から文字が出る │ ふわっと文字が出る │
│ Mask Reveal   │ Fade Up       │
│ [動画Preview] │ [動画Preview] │
│ ☆ / ★         │ ☆ / ★         │
│ [Aを採用]      │ [Bを採用]      │
└──────────────┴──────────────┘

[ 同時再生 ]  [ 0.5x ] [ 1x ]
```

## 比較条件

Motionそのものの違いを見やすくするため、比較時は可能な限り条件を揃える。

- 同じ写真 / 動画
- 同じテキスト
- 同じ背景
- 同じ表示位置
- 同じScene尺
- 同じCanvas / Aspect Ratio

比較対象固有のMotion値は保持する。比較のためにMotion自体を同じ値へ変形しない。

## 操作

v1で必要な操作は以下だけ。

- 2つ選択
- 比較画面へ移動
- 同時再生
- 0.5x / 1x 再生
- Aを採用 / Bを採用
- それぞれに★お気に入り

採用した側は現在のScene Composer / SceneInstanceへ引き継ぐ。

## 表示方針

比較画面の主役は動画Preview。

説明は補助に留める。

表示候補:

- 日本語の分かりやすいMotion名
- 正式名称（小さく補助）
- 代表的な違い 1〜3個
- ★状態

大きな差分表、AI採点、勝手なおすすめ順位付けはv1では作らない。

## なぜ2つか

- Previewを十分大きく保てる
- 視線移動が少ない
- A/Bどちらを採用するか決めやすい
- モバイル/狭い画面へも縮退しやすい
- 比較UIが重くなりすぎない

## 画面幅が狭い場合

PCでは左右2ペインを基本とする。

狭い画面では上下配置またはA/B切替表示へ縮退してよいが、比較対象は常に2つまでとする。

## 非目標

v1では以下をしない。

- 3つ以上の同時比較
- AIによる自動勝敗判定
- 100点満点などのMotionスコア
- 詳細Propertyを常時一覧表示
- DaVinci Inspectorの複製

## 原則

> 同じ条件で2つを動画で見比べ、自分で決める。

Compare Modeは判断を代行する機能ではなく、判断を簡単にする機能とする。
