# Project Memory

このリポジトリは、結婚式動画制作をメインにしつつ、結婚式全体のコンセプト、内容、判断、好みを覚えるための場所でもある。

## 目的

- 毎回同じ説明をしなくて済むようにする。
- コンセプト、世界観、素材判断、BGM判断、演出判断を残す。
- 動画以外の相談も、動画の世界観や結婚式全体に関係するものは記録できるようにする。
- Gitを、制作の履歴と記憶として使う。

## メインとサブ

メイン:

- オープニングムービー
- プロフィールムービー
- 紹介ムービー、その他動画
- AI背景素材
- BGM、テロップ、編集指示

サブ:

- 招待状、席次表、しおり、返礼品
- 会場演出
- コピー、挨拶文、コメント
- テーマ、色、雰囲気、ゲスト体験

サブの相談も受ける。ただし、動画の世界観と矛盾しないように扱う。

## 記録するもの

- 決めたこと
- 迷っていること
- 不採用にした理由
- 好きな方向性
- 避けたい方向性
- 参考にしたもの
- 次にやること

## 記録先

- 全体方針: `docs/01_brief.md`
- 世界観: `docs/02_style-bible.md`
- テーマ変更: `docs/theme-switching.md`
- 素材と情報: `docs/materials-todo.md`
- 作業状態: `docs/task-board.md`
- 判断ログ: `docs/decisions/`
- テキスト案: `08_texts/`

## 運用ルール

- 重要な好みや判断が出たら、該当ドキュメントに残す。
- 迷った理由は `docs/decisions/` に短く残す。
- 写真、動画、音源などの実ファイルは原則Gitに入れない。
- Gitには、ログ、判断、構成、プロンプト、編集指示を残す。
- 動画以外の内容も、結婚式全体のコンセプトに関係するなら記録してよい。
