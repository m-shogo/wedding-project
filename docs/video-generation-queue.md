# 動画生成キュー運用

更新基準日: 2026-08-07

`movie-dashboard` の **動画生成キュー** は、Prompt Bankに保存した動画プロンプトをモデル別にまとめ、生成サービス間の移動とコピペを減らすための実行画面。

## 目的

動画プロンプトを作った後に、次の手作業が増えないようにする。

- どのモデルへ投げるか探す
- シーン名を確認する
- Prompt / Avoid / notesを別々にコピーする
- Seedance / Runway / Veoを何度も行き来する
- どこまで生成したか忘れる

## 標準フロー

1. **動画プロンプト** でシーンとプリセットを選び、Prompt Bankへ保存する。
2. **動画生成キュー** を開く。
3. `生成待ち + テスト中` を表示する。
4. 同じモデルのショットをまとめて処理する。
5. 1本ずつ進める場合は **コピー + テスト中** を使う。
6. 生成した動画を素材ライブラリへ登録する。
7. Prompt Bankで結果素材をpromptIdへ紐付ける。
8. QA後にPromptを採用 / 不採用へ移動する。

## 生成パック

1ショットのコピー内容には次をまとめる。

- MODEL
- SHOT
- SCENE
- PRESET
- FINISH CANDIDATE
- PROMPT
- AVOID
- NOTES

生成サービス側で毎回情報を集め直さないため、Prompt Bankを実行可能なパックへ変換する。

## モデル単位の一括コピー

同一モデルの表示中ショットを1つのテキストとしてコピーできる。

推奨例:

```text
Seedance 2.0 Mini
  雲海
  飛行機窓
  空港ロビー
  海

↓ 低コスト試作をまとめて実行

Runway Gen-4.5 / Veo 3.1
  採用候補だけ仕上げ
```

モデルを1ショットごとに切り替えるより、同じサービス内でまとめて生成する。

## ステータス

- `draft`: まだ生成へ投げていない。
- `testing`: 試作中または比較生成中。
- `adopted`: 採用したPrompt。
- `rejected`: 不採用Prompt。

**コピー + テスト中** は、コピーと同時に `draft → testing` を行う。
単なるコピーはステータスを変更しない。

## Export

表示中のキューは次で書き出せる。

- Markdown: 人間が読みやすい生成指示パック。
- JSON: 他ツールや後続自動化へ渡しやすい構造化データ。

大きな画像・動画自体はExportへ含めず、promptId / sceneId / resultAssetIdsなどの管理情報だけを含める。

## QA上の注意

生成キューは「生成した」ことを自動判定しない。
コピーしただけで採用扱いにはしない。

採用には従来どおり次が必要。

- 人物・動物・文字・ロゴ・看板が0。
- ショット固有QAを通る。
- 形状、光、慣性、カメラ速度が安定。
- 結果素材をPromptへ紐付ける。
- CapCut実尺で前後ショットと確認する。
