# 制作方針

## ゴール

動画制作をメインに、旅行テーマで統一された映画予告編風と冒険アニメOP風の結婚式ムービーを作る。

このリポジトリは、動画だけでなく、結婚式全体のコンセプト、内容、好み、制作判断を覚えるためにも使う。

優先順位:

1. オープニングムービー
2. プロフィールムービー
3. 紹介ムービー、その他動画
4. AI背景素材ライブラリ
5. 関連するテロップ、BGM、編集指示
6. 印刷物、返礼品、しおりなどのサブ制作物

ゲストに残したい印象は次の通り。

- 完成度が高い
- 二人らしい
- 世界観が統一されている
- 最後まで飽きない
- 少し泣ける
- 旅行テーマが自然につながっている
