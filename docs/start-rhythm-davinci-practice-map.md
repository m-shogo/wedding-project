## Rule

Each technique becomes `used_in_wedding` only after it is actually applied to a Wedding scene and reviewed. Watching a tutorial is not completion.

## Fusion threshold

Stay in Edit Page when the idea is only:
- crop/reframe
- small pan/push
- opacity/dissolve
- simple title
- basic keyframe/ease

Move to Fusion only when the idea genuinely needs linked node behavior, such as:
- shape-driven text reveal
- mask + transform relationship
- multiple parameters that must share a controlled animation curve

Complexity itself is not a quality signal.
