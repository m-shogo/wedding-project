# Wedding Movie Reference Source Policy

For StaRt / DaVinci study:

- Store metadata, URLs, timestamps, observations and our own technique notes in Git.
- Do not mirror or redistribute third-party YouTube/commercial wedding sample video files.
- Download only resources explicitly distributed by the rightsholder/provider for training or reuse, such as Blackmagic official guides/lesson files.
- Keep purchased/licensed BGM outside Git and pass the existing Opening sound-rights gate before candidate/approved/final status.
- Any reference-derived technique must be re-authored from the underlying editing principle, not copied as a branded/template visual treatment.
