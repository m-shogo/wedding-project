# WHOLE-BOOK RHYTHM LEARNED FROM THE REFERENCE

1. Cover = maximum impact.
2. Map/journey = scenic/open and travel-heavy.
3. Profile = structured personal information.
4. Memories = photo-rich emotional browsing.
5. Venue = practical guide.
6. Schedule = structured utility.
7. Q&A = playful reading.
8. Message = calm participation area with decorative closing cluster.

This rhythm is substantially stronger than making all pages equally dense or all pages follow one template.
