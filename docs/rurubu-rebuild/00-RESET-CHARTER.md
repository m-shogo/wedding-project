# Rurubu WEDDING — Reference-First Rebuild Charter

Status: `CANONICAL_RESET_2026-08-30`

## Decision

From this point, Rurubu WEDDING design is rebuilt from the canonical reference image and real wedding content. Previous V6/V7/V8/V9/V10 layout recipes, page mappings, Figma geometry, component decisions, and visual habits are **not design authority**.

They may be consulted only for factual content, already-approved real assets, or technical lessons that remain useful. They must not constrain composition.

## Core production model

`REFERENCE IMAGE`
→ `VISUAL DECOMPOSITION`
→ `NEW PAGE ARCHITECTURE`
→ `PAGE MANUALS`
→ `PARTS LIBRARY`
→ `EXACT FIGMA PLACEMENT CONTRACT`
→ `LIVE FIGMA ASSEMBLY`
→ `SCREENSHOT / A5 / PRINT QA`

Figma is an assembly and editing surface, not the creative decision-maker.

## Zero-carryover rule

Do not preserve an old choice merely because it already exists.

Re-evaluate from zero:
- page order;
- page purpose;
- hero positions;
- photo counts;
- title positions;
- color dominance;
- frame families;
- use of maps/routes;
- decorative vocabulary;
- body-copy zones;
- information hierarchy;
- page density;
- component reuse.

Existing work survives only if it independently passes the new reference-first specification.

## Non-negotiable editability

The rebuild must still preserve future editing:
- real photos replaceable through masks;
- names/dates/times/profile facts/Q&A/body copy native and editable;
- title art and decorative assets may be composed/raster/vector when visually superior;
- frame artwork remains separate from photo source;
- no whole-page flattening as the production master.

## Design priority

1. editorial concept;
2. reference-faithful visual grammar;
3. clear hierarchy;
4. photo behavior;
5. Japanese information design;
6. reusable parts;
7. Figma editability;
8. print safety;
9. micro-polish.

## Failure condition

If a page looks like a modern web UI, wedding template, equal-card system, Auto Layout demo, or generic AI composition, rebuild structure before adding decoration.
