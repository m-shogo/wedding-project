# 結婚式動画プロンプト・プリセット運用

更新基準日: 2026-08-07

`movie-dashboard` の **動画プロンプト** 画面で使う、結婚式・旅行テーマ専用の短尺AI動画プリセット。

## 最短操作

1. 上部で絵コンテのシーンを選ぶ。
2. 欲しいショットに近いプリセットを1つ選ぶ。
3. 自動入力された主動作・カメラ・光・参照役割を必要な部分だけ直す。
4. まず表示された試作モデルで2〜4案比較する。
5. warningと重点QAを確認する。
6. **保存 + シーンへ紐付け** を押す。
7. Prompt Bankと絵コンテの両方に同じpromptIdが記録されたことを確認する。
8. 採用候補だけ仕上げモデルへ回し、CapCut実尺で前後ショットと確認する。

## プリセット

| プリセット | 初期試作 | 仕上げ候補 | 最重要QA |
|---|---|---|---|
| 雲海 | Seedance 2.0 Mini | Runway Gen-4.5 | 雲が沸騰せず、翼・水平線が変形しない |
| 飛行機窓・地上 | Seedance 2.0 Mini | Runway Gen-4.5 | 翼・窓枠・滑走路の直線が曲がらない |
| 無人の搭乗ゲート | Seedance 2.0 Mini | Runway Gen-4.5 | 人物・読める案内・座席増殖がない |
| 無人の空港ロビー | Seedance 2.0 Mini | Veo 3.1 | 遠景の人影・文字、床・柱の変形がない |
| 滑走路の灯り | Seedance 2.0 Mini | Veo 3.1 | 直線・灯火間隔・消失点が安定 |
| ハワイの海 | Seedance 2.0 Mini | Runway Gen-4.5 | 波の巨大化や液体変形、水平線ドリフトがない |
| 旅先の夜景 | Seedance 2.0 Mini | Veo 3.1 | 建物変形、不要ネオン・粒子・看板追加がない |

## プリセットの役割

プリセットは完成プロンプトを固定するものではない。

- 失敗しにくい初期値を80%まで埋める。
- 1ショット1主動作、1カメラ意図を守る。
- 結婚式で繰り返し使う禁止事項と形状QAを毎回思い出さなくてよくする。
- モデル名が変わっても `shot intent` を残し、モデル別コンパイラだけ差し替えられるようにする。

## シーン自動紐付け

シーンを選んで保存した場合は次を同時に行う。

- Promptレコードの `relatedSceneIds` にsceneIdを追加。
- Sceneレコードの `promptIds` にpromptIdを追加。
- Prompt notesへsceneId / purpose / visualを保存。
- 選択中ムービーが `all` でも、選んだシーンのmovieIdを正として保存。

これにより、Prompt Bankで作ったものと絵コンテ上の用途が分離しないようにする。

## 重点ルール

- 人物、新郎新婦、家族、友人、犬はAIで置換しない。
- 文字・ロゴ・看板・テロップは生成映像に焼き込まない。
- 空港素材は人物が1人でも生成されたら不採用。
- 綺麗さより、実写真・実動画の前後に置いて違和感がないかを優先する。
- 同じ破綻が3回続いたら、プロンプトを長文化せず静止画・参照素材・ショット・モデルを変更する。
- 高品質モデルへ進む前に、低コスト試作で構図と動きが成立していることを確認する。

## Definition of Done

1ショットのAI素材は次を満たして初めて採用候補とする。

- Prompt Bankと絵コンテが相互に紐付いている。
- 生成時モデル、モード、尺、プリセット、warningsが記録されている。
- 人物・動物・文字・ロゴ・看板が0。
- 形状・光・慣性・カメラ速度が時間方向に安定。
- テロップ余白が必要なショットでは最後まで維持。
- CapCutの実尺で前後ショットと接続してもAI素材だけ浮かない。
- 採用/不採用の理由を結果素材またはレビュー記録に残す。
