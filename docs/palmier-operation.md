# Palmier Free + Claude Code MCP 運用手順

Created: 2026-08-07

## 目的

Palmier Free + Claude Code MCP を、結婚式ムービー制作の **素材整理・ラフカット・不足素材洗い出し** に使う。

Palmierは最終編集ソフトではない。最終仕上げはCapCutで行う。

## 役割分担

| 領域 | 担当 | やること |
|---|---|---|
| 構成設計 | docs / movie-dashboard | 絵コンテ、素材、プロンプト、タスク整理 |
| 短尺モーション素材 | motion-studio | 搭乗券、地図、雲、扉の光、カウントダウン |
| AI背景動画 | Seedance / Kling等 | 3〜5秒の背景・つなぎ素材 |
| ラフ編集 | Palmier Free | 10秒、30秒、90秒の仮配置と不足洗い出し |
| 最終編集 | CapCut | BGM合わせ、キーフレーム、字幕、色味、書き出し |
| 管理 | movie-dashboard | 採否、素材パス、Prompt Bank、CapCut Pack |

## Freeで使う範囲

Palmier Freeで使うもの:

- 動画エディタ
- MCP接続
- Claude Codeからのタイムライン確認・ラフ編集
- 素材整理
- MP4のラフ書き出し

Palmier Freeで使わないもの:

- Palmier内AI生成
- Pro / Max クレジット消費
- 本番動画の最終仕上げ

AI動画生成はPalmier外で行う。まずはSeedance / Klingを候補にする。

## AI利用ルール

AIで作るもの:

- 空港の光
- 搭乗ゲート風の抽象背景
- 飛行機窓
- 雲海
- ハワイの海
- 雨上がりビーチ
- 夜景
- 扉の光
- カウントダウン用の光
- 抽象的な粒子

AIで作らないもの:

- 新郎新婦
- 犬
- 家族
- 友人
- 顔が主役の動画
- 実在ブランドロゴ
- 正確な文字が必要な動画
- 看板や地名が主役の映像

固定negative:

```text
no people, no animals, no text, no logo, no watermark, no signage
```

日本語運用メモ:

```text
人物なし、動物なし、文字なし、ロゴなし、透かしなし、看板なし
```

## ローカル素材配置

Palmierテスト用素材はGit管理外に置く。

```text
02_opening-movie/source/palmier-test-001/
  ai-videos/
  remotion-renders/
  photos/
  music/
  exports/
```

大きな素材ファイルはGitに入れない。Gitに残すのは素材パス、採否、判断、プロンプト、編集指示だけ。

## MCP接続確認

Palmierを開いた状態でClaude Codeに投げる。

```text
Palmier Pro MCPへの接続を確認してください。

まだ編集はしないでください。
現在開いているPalmierプロジェクトについて、以下だけ確認してください。

1. プロジェクトを認識できるか
2. タイムラインを読めるか
3. 素材ライブラリを読めるか
4. クリップの長さ・種類・配置を取得できるか
5. どのMCP操作が使えるか

結果を日本語で簡潔に報告してください。
保存・削除・移動・トリムなどの変更操作はまだ実行しないでください。
```

合格条件:

- タイムライン情報を読める
- 素材一覧を読める
- 変更操作をしていない
- 使えるMCP操作が一覧化される

## 10秒試作

目的:

- Palmier MCPが実用になるか確認する
- 素材の読み取り、並び替え、トリムが安全にできるか確認する
- 30秒試作へ進めるか判断する

素材量:

- AI動画 4本
- motion-studio書き出し 2本
- 写真 3枚
- BGM 1曲

構成:

| 秒数 | 内容 | 素材候補 |
|---:|---|---|
| 0-2 | 出発前の空気 | 空港の光、暗転、粒子 |
| 2-6 | 新郎新婦名・日付 | 搭乗券風タイトル、motion-studio |
| 6-10 | 入場前の期待感 | 扉の光、カウントダウン前背景 |

Claude Code用プロンプト:

```text
Palmier Proの現在のプロジェクトを使って、結婚式オープニングムービーの10秒試作を作ってください。

目的:
Palmier Free + Claude Code MCPで実用的にラフ編集できるか確認すること。

テーマ:
旅行。披露宴開始前の「これから旅が始まる」空気。

素材:
現在Palmierに読み込まれている素材だけを使う。

構成:
0-2秒: 空港・光・出発前の空気
2-6秒: 新郎新婦名と日付を見せる仮タイトル
6-10秒: 入場前の期待感、光、扉、カウントダウン前の余韻

条件:
- AI動画は1カット3〜5秒以内
- 人物写真は自然に使う
- 文字は仮置きでよい
- 素材は削除しない
- 元素材は変更しない
- まずはラフでよい
- 完了後、不足素材と気になった点を日本語で一覧化してください。
```

## 30秒試作

目的:

- オープニングとして成立するか確認する
- 旅行テーマが伝わるか確認する
- 90秒ラフへ進む素材・構成の穴を洗い出す

素材量:

- AI動画 6〜8本
- motion-studio書き出し 3〜4本
- 写真 8〜12枚
- BGM 1曲

構成:

| 秒数 | 内容 | 素材候補 |
|---:|---|---|
| 0-5 | 出発前の空気 | 空港の光、暗転、粒子 |
| 5-15 | 搭乗券風タイトル | 名前、日付、会場名 |
| 15-23 | 旅の始まり | 飛行機窓、雲海、航路 |
| 23-30 | 入場前の余韻 | 扉の光、カウントダウン前背景 |

Claude Code用プロンプト:

```text
Palmier Proで、結婚式オープニングムービーの30秒試作を作ってください。

テーマ:
旅行。披露宴の始まりを「旅の出発」に見立てる。

構成:
0-5秒: 出発前の空気。空港の光、暗転、期待感
5-15秒: 搭乗券風タイトル。新郎新婦名、日付
15-23秒: 飛行機窓、雲、旅の始まり
23-30秒: 扉の光、入場直前の余韻

条件:
- AI素材は背景とつなぎに限定
- 人物、犬、家族、友人のAI生成・AI変形は禁止
- AI動画は1カット3〜5秒中心
- 文字が必要な場所は仮テキストでよい
- 最終テロップ、音ハメ、色調整はCapCutで行う
- 似た映像を連続させない
- 完成後、不足素材・再生成したい素材・CapCutで仕上げる箇所を一覧化してください。
```

## 90秒ラフへ進む条件

以下をすべて満たしたら90秒ラフへ進む。

- Palmier MCPでプロジェクト・素材・タイムラインを安定して読める
- 10秒試作で保存・素材破壊・タイムライン破綻がない
- 30秒試作で旅行テーマと入場前の高揚感が伝わる
- 不足素材が一覧化されている
- CapCutへ渡すべき作業とPalmierで済ませる作業が分かれている

## CapCutへ渡す条件

PalmierからCapCutへ渡す前に確認する。

- 仮尺が決まっている
- シーン順が決まっている
- 採用候補素材がシーンに紐づいている
- 仮タイトル位置が決まっている
- 不足素材がMissing Listへ移っている
- 仕上げ作業がCapCut編集パックに整理されている

CapCutでやること:

1. BGM合わせ
2. 写真のキーフレーム
3. テロップ
4. トランジション
5. 色味調整
6. 会場仕様に合わせた書き出し

## やってはいけないこと

- 本番素材を直接破壊する
- Palmierで最終編集までやろうとする
- AIに文字入り動画を作らせる
- 人物、犬、家族、友人をAI動画化する
- 似たAI動画を長く連続させる
- 採否理由を記録せずに素材を増やす
- 10秒テスト前に90秒ラフへ進む
