# P05 — VENUE GUIDE

Status: `CANONICAL_PAGE_MANUAL`
Role: `VENUE GUIDE`
Editorial metaphor: `destination guide / spot feature`

## PAGE JOB
Introduce the wedding venue like a featured travel destination: attractive first, useful second, never a corporate venue brochure.

## READING PATH
1. FIRST READ — `会場ガイド` / venue-feature title.
2. SECOND READ — large venue hero photo.
3. THIRD READ — 2–4 venue/detail satellite photos.
4. USEFUL INFO — venue name, short guide copy, access/map information if needed.
5. MICRO DISCOVERY — map markers, small arrows, flowers, location-style notes.

## ZONE MAP
- top 0–18%: page title + venue name.
- upper/middle 17–62%: venue hero + right/side satellite photo cluster.
- middle/lower 58–78%: short descriptive guide copy.
- lower 75–100%: map/access/mini-guide band.
- edge zones: floral/location decoration.

## PHOTO PLAN
- `P05_VENUE_HERO`: one large independently replaceable venue image.
- `P05_VENUE_DETAIL_01..04`: 2–4 details such as chapel/interior/table/garden only when real sources exist.
- hero must be materially larger than satellites.
- satellites should mix portrait/landscape/square rather than equal gallery cells.

## MAP PLAN
- `P05_VENUE_MAP`: simplified venue/access/local-area map if genuinely useful.
- map is a clear lower utility region, not decorative wallpaper.
- factual place/access labels stay native.

## TITLE / TYPOGRAPHY
- strong rounded/outlined Japanese title supported by flowers/travel cue.
- venue name gets its own readable factual treatment.
- descriptive copy remains dark native text on light field.

## PARTS
- page title plate;
- venue hero mask/frame;
- mixed detail frames ×2–4;
- map/map-pin system;
- location label;
- tropical corner/photo-junction clusters ×1–3;
- small travel/guide icon only where meaningful.

## COLOR JOBS
- dominant: cream/paper with venue photography.
- support: blue/cyan.
- emotional accent: pink/coral.
- highlight: yellow sparingly.
- facts: dark ink.

## OVERLAP
- one detail frame may overlap hero edge;
- floral cluster may bridge hero/detail junction;
- title support art can cross title/upper-photo boundary;
- map stays readable and should not be covered by unrelated decoration.

## EDITABILITY
Native:
- venue name;
- address/access facts;
- short descriptive copy;
- map labels;
- any confirmed facility notes.

Replaceable:
- all venue/detail photography.

Composed:
- title art;
- frames;
- decorative map base;
- floral/location accents.

## FORBIDDEN
- corporate facility card grid;
- five equal venue thumbnails;
- fake access/map facts;
- long text directly over busy venue photography;
- decorative map with no utility;
- inherited V10 page geometry.

## QA
Pass when venue hero is unmistakable, guide information can be found in under 10 seconds, map/utility is real and readable, satellite photos vary visibly, and the page feels like a destination feature rather than a facility dashboard.
