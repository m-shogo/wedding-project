# P02 — WEDDING JOURNEY

Status: `CANONICAL_PAGE_MANUAL`
Role: `WEDDING JOURNEY / INTRO`
Editorial metaphor: `travel-feature opener with world map`

## PAGE JOB
Establish the travel theme and show the wedding as the next destination in the couple's shared journey.

## READING PATH
1. FIRST READ — Wedding Journey title.
2. SECOND READ — large world-map / route field.
3. THIRD READ — 3–4 memory-photo clusters.
4. USEFUL INFO — date, venue and short intro.
5. MICRO DISCOVERY — airplane, luggage, ticket, camera and small notes.

## ZONE MAP
- top 0–20%: title + short deck;
- center 12–70%: map/route hero;
- lower 55–95%: photo and travel-object clusters;
- bottom 85–100%: date/venue utility;
- selected corners: floral accents.

## PHOTO PLAN
- `P02_MEMORY_POLAROID_01..04`: 3–4 independently replaceable photos.
- map is the structural hero; photos are satellites.
- vary sizes and positions; do not create one equal bottom row.

## MAP PLAN
- `P02_WORLD_MAP`: large simplified decorative map.
- `P02_ROUTE`: dotted/illustrated line tied to real story points when confirmed.
- `P02_PLANE`: 1–2 airplane motifs maximum.
- unconfirmed destination labels stay TBD/native.

## PARTS
- page title;
- world map;
- dotted route;
- airplane ×1–2;
- polaroid frames ×3–4;
- travel still-life ×1;
- date stamp;
- tropical corner ×1–2.

## COLOR JOBS
- dominant: cyan/sky/ocean;
- map: warm yellow/cream;
- support: pink/coral;
- utility: dark ink on stable cream field.

## OVERLAP
background → map → route → replaceable photo masks → frames → native text/title → foreground objects.

Allow one polaroid to cross the map edge and one lower travel-object cluster to overlap a photo corner.

## EDITABILITY
Native: intro, date, venue, destination labels, factual route labels.
Replaceable: all memory photos.
Composed: map, decorative route, travel objects, title art.

## FORBIDDEN
- map dashboard with equal pin cards;
- invented destinations;
- four equal polaroids in a row;
- meaningless route;
- reuse of P01 cover geometry.

## QA
Pass when the map is the structural hero, photo sizes vary, factual labels remain editable, and the page reads as a broad journey opener rather than a card layout.
