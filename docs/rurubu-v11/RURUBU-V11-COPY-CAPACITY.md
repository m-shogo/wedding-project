# Rurubu WEDDING V11 — Copy Capacity Guardrails

Status: `CANONICAL_WORKING_CAPACITY`

Purpose: prevent late factual copy from destroying the designed hierarchy. These are working capacity bands, not content-writing requirements.

Japanese character counts are approximate and should be validated in the final font/width at A5 actual size.

## P01 COVER
- hero/identity factual line: 10–24 chars.
- each coverline: ideally 6–18 Japanese chars; max ~24 before redesign.
- 3–5 coverlines total.
- venue/date utility: 1–3 short lines.

Do not solve overflow by making coverlines microtext.

## P02 WEDDING JOURNEY
- intro deck: ~30–70 chars.
- each destination/memory label: 4–14 chars.
- each microcaption: ~10–30 chars.
- 3–4 memory photos recommended.

If more narrative is needed, remove a photo or create a larger calm field; do not stack tiny text over the map.

## P03 PROFILE
Per person recommended:
- 4–7 compact fact rows;
- values generally 4–20 chars;
- one personality note up to ~35 chars.

Mini-story:
- 3–5 milestones;
- each date + ~8–25 chars.

`Best/Favorites` feature:
- 3–5 items;
- labels short.

If content exceeds this, prioritize facts instead of shrinking type.

## P04 MEMORIES
- intro: ~25–60 chars.
- 4–6 photos total including hero.
- destination label: 4–14 chars.
- caption: ~15–45 chars each.

One or two photos may carry longer captions; not every image needs equal copy.

## P05 VENUE GUIDE
- venue name: 1–2 lines max.
- intro/guide copy: ~60–130 chars across one or two blocks.
- each detail-photo caption: ~10–35 chars.
- map/access utility: 2–5 concise lines/labels.

Long venue history belongs elsewhere; this page is a guide feature.

## P06 1DAY
- 5–8 confirmed event rows recommended.
- time: short fixed label.
- event name: ideally 4–16 chars.
- optional event note: ~8–25 chars, only for selected events.
- side feature: ~30–90 chars total.

If the real schedule has more stops, combine minor moments or reduce decoration before reducing type size.

## P07 Q&A
- 4–6 questions.
- question: ~8–28 chars.
- answer: ideally ~20–70 chars per question.
- one or two answers may be longer, balanced by shorter neighbors.

If every answer exceeds ~70–90 chars, redesign the page as a reading feature rather than forcing six dense boxes.

## P08 MESSAGE / BACK
- main guest message: roughly 90–220 Japanese chars depending on line measure and whether a photo is included.
- CTA: ~20–60 chars.
- hashtag: one short line.
- date/name utility: compact.

The message field is the hero; do not fill it with decoration when copy is long.

---

# Overflow rule

When copy exceeds the working band, adjust in this order:
1. remove/reduce non-essential decoration;
2. enlarge/reconfigure the calm text zone;
3. reduce support-photo count or change crop geometry;
4. tighten copy through editorial rewriting with user approval;
5. only then make a small type-size adjustment within readability limits.

Never jump directly to tiny body text.

# Underflow rule

When content is short, do not automatically invent filler copy or add random decoration.

Use:
- larger photography;
- stronger title/feature scale;
- intentional negative space;
- one meaningful micro-discovery;
- improved overlap/edge behavior.

Empty content is not permission to fabricate personal facts.
