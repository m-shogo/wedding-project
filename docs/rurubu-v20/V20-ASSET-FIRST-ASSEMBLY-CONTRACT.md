# V20 Asset-First Assembly Contract

Status: `CANONICAL / FIGMA-AS-COMPOSITOR / CURRENT_PAGE_ROLES_2026-09-01`

Highest page-role authority: `V20-CURRENT-PAGE-ARCHITECTURE.md`.

## Purpose

Visual quality should exist in approved real photos, page-specific prepared art, editorial hierarchy and current page specs before final Figma placement.

Figma mainly:
- places/crops/masks
- manages z-order
- keeps real photos replaceable
- keeps factual/personal text editable
- performs final QA/export

## Production ratio

Most visible personality should come from real photography + prepared editorial art, with native typography/copy and only limited simple Figma geometry.

Do not build publication identity from generic cards/pills/gradients/icon packs.

## Asset tiers

### Real content
- real couple/travel/friend/life photos
- verified facts/dates/names
- grounded memories/captions

Never replace autobiographical content with generated fake memories.

### Prepared visual art
- masthead/title/subtitle units
- photo frames/backings
- paper/tape/ticket/stamp/ribbon art
- route/thread only where current page role needs it
- page-specific edge/micro accents

### Native editable layers
- names/dates
- profile/story/friend captions
- Q&A
- thank-you copy
- P08 barcode digits
- masks/guides

## Generation rule

Whole-page generation is allowed as disposable art-direction proof. Final production is decomposed into layers.

Never bake variable factual copy, fake Japanese body text or generated autobiographical people into production assets.

## Asset promotion

`BRIEF → GENERATED/DRAWN → ALPHA/EDGE QA → A5 QA → PAGE ROLE QA → APPROVED → FIGMA PLACEMENT`.

## Placement discipline

- semantic layer names
- no whole-page flattening
- real photos independent
- factual text independent
- freeform editorial clusters not forced into Auto Layout
- background → photo → frame/art → native text → foreground accents

## Legacy boundary

Do not reuse old assets merely because they exist.

In particular:
- old P05 Hawaii/proposal assets are removed/superseded
- old P07 luggage-tag/ticket/stamp/discovery assets are superseded

`KEEP THE JOB; REDESIGN THE OBJECT FROM ZERO.`

## Success

A future editor can swap a photo, edit a caption, change a date or hide decoration without regenerating the entire page, while the publication still feels authored rather than UI-template-based.
