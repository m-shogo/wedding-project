# V20 Quality Gates

Status: `CANONICAL_V20_QA`

V20 does not use V10/V11 visual scores, old reference-node mappings, or old page-similarity thresholds as design authority.

QA is based on V20's own page jobs, spread architecture, North-Star taste principles, editability, content truth, and print geometry.

## Gate 0 — Grounding

Pass before structural Figma work:
- A5 portrait / 8 pages confirmed;
- page architecture exists;
- missing personal facts explicitly identified;
- no fixed page depends on fabricated Q&A or dates;
- North-Star image is taste-only, not a template;
- P01–P08 manuals exist;
- production geometry exists.

## Gate 1 — Photo inventory

Before detailed Figma composition:
- actual candidate photos are inventoried by role;
- each page has enough plausible sources for its minimum photo count;
- hero candidates identified separately from support photos;
- duplicates/repeats identified;
- orientation/crop feasibility checked;
- proxy vs final status recorded.

If a page lacks enough real photos, redesign its photo budget before polishing Figma. Do not solve it by repeating one image five times.

## Gate 2 — Greybox / silhouette

Build page geometry with masks, titles and text supports before detailed decoration.

Review at thumbnail scale:
- P01 silhouette differs from P02;
- P02 differs from P03;
- P04–P05 clearly reads as one center spread;
- P06 is an irregular photo-led mosaic;
- P07 chronology is obvious;
- P08 visibly calms down.

Fail if multiple pages look like the same boxes with different content.

## Gate 3 — Reading hierarchy

For every page name:
1. FIRST READ;
2. SECOND READ;
3. THIRD READ;
4. useful information;
5. micro discovery.

Pass only when a screenshot supports that order.

Fail if:
- 4+ large elements compete equally;
- decoration is noticed before the actual page subject;
- the title is weak enough to disappear at thumbnail scale;
- a guest must hunt for the next reading point.

## Gate 4 — Anti-UI / editorial behavior

Pass when:
- equal card grids are avoided;
- scale classes vary;
- photo treatments vary with purpose;
- overlaps are intentional;
- at least some edge tension exists where page role permits;
- copy-heavy pages contain a calm reading field;
- repeated components do not determine the whole page.

Immediate revision triggers:
- three or more equal rounded cards;
- same radius/shadow treatment everywhere;
- all sections centered;
- identical adjacent page structures;
- sticker density used to hide weak hierarchy.

## Gate 5 — North-Star taste check

Compare against the Drive North-Star image only for general energy.

Ask:
- does the page have authored title silhouette?
- is photo hierarchy strong?
- is asymmetry intentional?
- is there tactile layering?
- does travel language feel useful/personal?
- is density clustered rather than uniform?
- is there one calm readable area where needed?
- does it feel joyful rather than corporate?

Do NOT ask whether coordinates/layout match the image.

## Gate 6 — Content truth

Every visible factual/personal claim must be one of:
- confirmed/fixed;
- grounded candidate with explicit review state;
- clearly marked placeholder in nonfinal production.

Fail if final-looking output contains:
- invented relationship dates;
- invented Q&A answers;
- fake venue facts;
- fake QR/flight/gate/transport data;
- generated text errors;
- placeholder personal facts presented as final.

## Gate 7 — Editability

Pass when:
- changing text is native;
- each photo is independently replaceable;
- frame/decor is separate from photo source;
- no whole page is flattened;
- semantic layer names exist;
- a future editor can replace a photo without reconstructing the page;
- page-specific composed art contains no hidden authoritative variable copy.

## Gate 8 — Three-scale review

Review each page/spread at:
1. thumbnail / 3-second scan;
2. normal reading scale;
3. A5 actual-size equivalent.

At thumbnail:
- page purpose/title/hero survive.

At reading scale:
- hierarchy and captions make sense.

At actual size:
- body/caption text remains comfortable;
- trim/safe area is respected;
- details are not too tiny to enjoy.

## Gate 9 — Spread review

For P02–P03, P04–P05, P06–P07:
- shared identity exists;
- pages are not mirrored templates;
- fold does not swallow critical content;
- density differs enough to create rhythm;
- visual bridge is intentional and limited.

P04–P05 specifically:
- center spread is the emotional peak;
- route connects real content;
- Hawaii/proposal emphasis is clear if retained in final content;
- fold-crossing elements are noncritical.

## Gate 10 — Color / grayscale hierarchy

Pass when:
- one dominant + support + surprise accent logic is visible;
- small text contrast is strong;
- bright fields do not carry low-contrast white small text;
- hierarchy still makes sense when mentally/desaturated to grayscale;
- page identity does not depend only on hue.

## Gate 11 — Photo resolution / provenance

Before final promotion:
- source locator recorded;
- final/proxy state recorded;
- effective PPI checked at intended size;
- no reference-only image is production art;
- no mystery external asset lacks provenance/licensing note;
- low-resolution hero assets are replaced or explicitly blocked from print-ready state.

## Gate 12 — Copy stress

Before layout freeze, test realistic longer content:
- profile facts near maximum intended count;
- story paragraph near upper working budget;
- destination paragraph near upper working budget;
- P07 unresolved guidance replaced with realistic multi-line placeholder length;
- P08 closing message near upper budget.

Do not solve overflow by shrinking body text below the intended readable range. Reflow/reduce/edit instead.

## Gate 13 — Print geometry

Before print-ready claim:
- full-bleed and trim dimensions verified;
- critical safe area checked;
- center-fold risks checked;
- exported PDF physical page dimensions verified;
- fonts/images reviewed;
- printer-specific bleed/profile requirements applied;
- physical proof or printer proof inspected where possible.

`FIGMA COMPLETE != PRINT READY`.

## V20 page scorecard

Use a 0–5 discussion score only after meaningful content exists. It is diagnostic, not an automatic pass number.

- page-job clarity;
- title/hero hierarchy;
- photo behavior;
- editorial asymmetry;
- useful density;
- tactile layering;
- readability;
- content truth;
- editability;
- page uniqueness / book rhythm.

Any hard failure in content truth, editability, or print safety overrides a high aesthetic score.

## Correction priority

When a page feels weak, fix in this order:
1. page job;
2. content selection;
3. hero/photo choice;
4. scale hierarchy;
5. composition silhouette;
6. reading path;
7. copy support/calm zone;
8. overlap/crop;
9. color roles;
10. parts/decoration;
11. micro-spacing.

Never start by adding more stickers.
