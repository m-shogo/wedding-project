## Design consequence for V20

Hawaii has enough real-photo depth to support multiple editorial roles without repeating one photograph.
Therefore:
- P04–P05 may legitimately make Hawaii the emotional/photo peak;
- P01 does not need a generated tropical scene;
- P02 can use Hawaii source photography but should not become a Hawaii page;
- P03/P06 should use the emotional/personality subset rather than the same environmental heroes;
- avoid using 031/035/007/016 as four equivalent cards; they overlap in visual function and should be selected selectively.
