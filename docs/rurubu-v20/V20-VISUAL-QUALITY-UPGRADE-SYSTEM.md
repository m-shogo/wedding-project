# V20 Visual Quality Upgrade System

Status: `CANONICAL_QUALITY_REFINEMENT / CURRENT_PAGE_ROLES_2026-09-01`

Core question:
> What single change makes this page look more like a professionally art-directed Japanese travel magazine at A5 size without pushing information load above the current target?

## Calibration

- `RURUBU FEEL = 100%`
- information/clutter load = about 75% of previous max-clutter experiments
- readability high

Adding more stickers is never the default correction.

## Quality loop

`REAL SOURCE REVIEW → SERIOUS PAGE OPTION → FIGMA/PAGE PROOF → PAGE/SPREAD/A5 REVIEW → FIX LARGEST GAP → RECHECK → MICRODETAILS LAST`.

Common best corrections:
- remove decoration
- improve source photo/crop
- strengthen title hierarchy
- reduce competing modules
- increase local contrast
- create better calm space
- improve photo-size relationships

## Photo treatment

Use page-specific mixtures of full/strong crops, printed-photo objects, postcard/polaroid only when useful, irregular crops and selective cutouts. Do not repeat one frame recipe everywhere.

Current important exception:
**P05 has no page-wide hero.** Its quality comes from two friend clusters with medium/small unequal photos, not by enlarging one image into a centerpiece.

## Typography

Large titles are graphic structure. Body/captions remain comfortable at A5; never shrink them to preserve clutter.

## Editorial copy

Prefer short, grounded, human copy. Reject generic romantic filler, fake editor quotes, invented facts and meaningless decorative English.

## Page rhythm

- P01 cover — high impact
- P02 profile + Q1/Q2 — lively but readable
- P03 story + Q3/Q4 — calmer narrative
- P04 travel memories — strongest interior travel page
- P05 SHOGO/SHIORI friends — warm social multi-photo feature, no giant hero
- P06 real life + Q5/Q6 — playful
- P07 thank-you/closing — deliberate release
- P08 back cover — quietest

## P08 quality

P08 is a real-magazine-like back cover, not the main emotional closing page.

Aim for:
- quiet field/photo/art
- tiny issue/meta
- optional small names/date
- one tiny motif
- barcode digits exactly `2026102400000`

No long thank-you or collage.

## Microdetails

Microdetails are last polish. Use only when they have a job. Do not use old P07 discovery labels as generic decoration elsewhere merely because they exist.

## Image generation

Generate page-aware title/frame/vessel/edge art after defining semantic job, physical size, transparency, z-order and source-photo relationship.

Never generate fake autobiographical people/dogs/memories as production truth.

## Professional critique

Review as:
- art director: clear idea/silhouette?
- editorial designer: reading order/density correct?
- book designer: spread rhythm?
- Japanese typographer: A5 readability?
- photo editor: correct source/crop/role?
- print designer: resolution/bleed/fold/CMYK safety?
