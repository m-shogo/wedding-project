# V20 Reading Path System

Status: `CANONICAL_READING_FLOW_RULE`

Every page and spread must define a deliberate reader path before detailed styling.

## Required path

1. `FIRST READ` — title/hero idea recognized in ~3 seconds.
2. `SECOND READ` — dominant photo or story anchor.
3. `THIRD READ` — supporting cluster that explains or enriches the main idea.
4. `USEFUL INFO` — facts, dates, captions, route, profile data, schedule.
5. `MICRO DISCOVERY` — stamps, arrows, tiny notes, visual jokes, editorial details.

## Spread-level rule

For P02–P03, P04–P05 and P06–P07, define one path across the full spread first, then local page paths.

A spread fails when:
- left and right pages compete as two unrelated covers;
- 4+ elements demand equal first attention;
- the eye gets trapped in a decorative cluster;
- a route/arrow points against the intended reading direction;
- useful information is only discoverable after decorative microcopy.

## Hierarchy tools

Use in this priority order:
1. scale;
2. image weight/crop;
3. position;
4. contrast;
5. grouping/proximity;
6. overlap;
7. color;
8. decoration.

Do not repair a weak reading path by adding stickers.

## Center spread P04–P05

Target behavior:
- FIRST READ: spread title / journey idea;
- SECOND READ: emotional peak image, likely Hawaii if the actual photo pool supports it;
- THIRD READ: Okinawa/Korea/supporting travel clusters;
- USEFUL INFO: destination labels, grounded short memories, route logic;
- MICRO DISCOVERY: stamps/ticket/camera/detail accents.

The exact positions remain photo-dependent; this is hierarchy authority, not a coordinate template.

## QA

At thumbnail scale, ask a reviewer to point to what they see 1st, 2nd and 3rd. If that order differs materially from the page manual, revise hierarchy before micro-polish.
