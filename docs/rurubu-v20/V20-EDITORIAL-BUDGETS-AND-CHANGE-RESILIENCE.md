## Change classes

### SAFE
- typo/caption correction
- photo swap inside same semantic role
- one small accent removal

### LOCAL REFLOW
- longer profile fact
- different support-photo aspect ratio
- one P04 travel memory added/removed
- one SHOGO or SHIORI friend photo added/removed on P05
- one P05 caption expanded within budget
- P07 closing copy length change

### ARCHITECTURE CHANGE
Requires explicit user decision:
- P05 becomes family content again
- P05 stops being split SHOGO/SHIORI friends
- P05 gains one giant page-wide hero as the primary composition
- P04 stops owning travel memories
- P07 returns to guide/discovery role
- P08 returns to full closing-message role
- page count/format changes
