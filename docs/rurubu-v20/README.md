# Rurubu WEDDING V20

Status: `CLEAN_SLATE_CANONICAL`

V20 is a complete redesign track. It does not inherit V10/V11 page composition, Figma layout, page-role mapping, old reference nodes, or old AI-look scoring as design authority.

## What V20 may inherit
Only factual / production constraints that remain true, for example:
- wedding date and confirmed names/content;
- final booklet size / print constraints once confirmed;
- real source photos/assets that are still useful;
- printer-safe requirements such as bleed, safe area, resolution and editable-photo needs.

These are facts and production constraints, not visual design inheritance.

## What V20 explicitly does NOT inherit
- V10/V11 page layouts;
- V10/V11 page order;
- V10/V11 frame geometry;
- old Figma page structure;
- old component grammar;
- old title placement;
- old card/module patterns;
- old color assignment by page;
- old reference-node mapping;
- old linter scores as quality authority;
- old prompts as design intelligence.

## New canonical chain

`NORTH STAR IMAGE`
→ `visual-language decomposition`
→ `content architecture from zero`
→ `P01–P08 page manuals`
→ `parts library`
→ `Figma placement instructions`
→ `new V20 Figma production surface`
→ `screenshot / print QA`

Figma must not invent the composition. Prompts are execution artifacts generated from the page manuals.
