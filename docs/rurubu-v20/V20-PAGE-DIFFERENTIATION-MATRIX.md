# V20 Page Differentiation Matrix

Status: `CANONICAL_ANTI-REPETITION_RULE`

V20 shares one publication identity but must not repeat one AI/template composition eight times.

## Required differentiation axes

For every page/spread, record:
- composition verb;
- hero position;
- title alignment/silhouette;
- dominant color job;
- density peak location;
- calm-zone location;
- photo count/rhythm;
- primary frame/crop language;
- principal overlap gesture;
- edge/bleed gesture.

Adjacent spreads should normally differ on at least 4 axes.

## Current V20 directional matrix

| Surface | Composition verb | Hero tendency | Density peak | Photo language | Character |
|---|---|---|---|---|---|
| P01 Cover | STACK / BURST / INVITE | one dominant cover photo | center/lower + coverlines | hero + selective cutout/satellite | loudest first impression |
| P02–P03 | PAIR / INTRODUCE / FLOW | people + story anchor | offset left/right clusters | portrait + episode support | know the couple, then enter story |
| P04–P05 | JOURNEY / CROSS / PEAK | one spread-level emotional hero | destination clusters across spread | place + people + detail, strongest variety | book's visual/emotional peak |
| P06–P07 | SNAP / ROUTE / CONTRAST | casual-life image vs useful day guide | P06 collage, P07 itinerary | candid mixed crops vs ordered guide images | human reset → useful wedding-day navigation |
| P08 | RESOLVE / EXHALE | one restrained closing image/message | intentionally reduced | 1–2 calm images | warm ending |

This matrix is directional, not fixed coordinates. Actual source photos can change the exact arrangement while preserving differentiation.

## Anti-clone failures

Fail/revise when:
- all page titles sit top-center;
- every page uses the same 3-photo card cluster;
- all photos use one rounded-rectangle radius;
- every page peaks at the center;
- the same hot-pink/blue/yellow balance repeats everywhere;
- every page uses the same sticker density;
- P04–P05 feels like two normal pages rather than a center spread;
- P08 is as dense as P01/P04–P05.

## Rule for shared parts

Reusable parts create identity, not layout identity. A stamp/frame/arrow may recur, but its scale, context, rotation and editorial job should change rather than being stamped into the same coordinates on every page.
