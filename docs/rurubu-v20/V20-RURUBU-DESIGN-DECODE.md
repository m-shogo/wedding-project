# V20 Rurubu Editorial Design Decode

Status: `CANONICAL_DESIGN_DECODE / CURRENT_PAGE_ROLES_2026-09-01`

Purpose: define the editorial phenomena that make V20 feel like a professionally authored Japanese travel magazine while keeping the current information load readable.

## Core target

- `RURUBU FEEL = 100%`
- `EDITORIAL DENSITY = 75% OF PREVIOUS MAXIMUM-CLUTTER TESTS`
- `READABILITY = HIGH`

The target comes from:
`EDITORIAL IDEA → CLEAR PROMISE → STRONG TITLE/PHOTO GESTURE → UNEQUAL PHOTO HIERARCHY → ASYMMETRIC CLUSTERS → PURPOSE-BUILT VESSELS → MEANINGFUL COLLISION → SELECTIVE DISCOVERIES → CALM SPACE → PAGE TEMPO`.

`THE PAGE FEELS RICH BEFORE BODY COPY, WITHOUT FILLING EVERY GAP.`

- P01: joyful `るるぶ WEDDING` cover
- P02: meet SHOGO and SHIORI + Q1/Q2

No current page uses the old P07 discovery-guide role or old P05 Hawaii/proposal role.

## Title silhouette

Major titles are graphic events, not labels. Use large scale jumps, keylines, hard offset shadows, irregular stacks/ribbons and selective overlap with photography.

P05 title is strong but below cover/travel-hero scale; it must leave room for two friend clusters.

## Photo hierarchy

Use visible semantic roles rather than equal cards.

- P01: one dominant hero
- P02: two main people roles
- P03: one story anchor + supports
- P04: one travel hero + supports
- **P05: exception — no page-wide hero; two friend clusters with medium/small unequal photos**
- P06: one candid hero + supports
- P07: one calm closing photo
- P08: 0–1 background photo

Unequal does not always mean one giant image. On P05, inequality happens locally inside each friend cluster.

## Controlled density

High-energy pages use:
- one first-read event
- 1–3 meaningful secondary reads
- selective micro discoveries
- intentional calm fields

Under the current 75% target, do not default to 8–18 tiny discoveries. Add small details only when they create real editorial reward.

## Collision

Useful collisions include title/photo overlap, paper/frame crossings, captions attached to photo edges, and restrained stamp/tape interactions.

Current exceptions:
- P05 uses lighter cluster-local overlap so friend faces stay readable
- P07/P08 deliberately reduce collision

## Information vessels

Build an ecology rather than one repeated component:
- profile fact labels
- story episode paper
- travel destination/memory vessels
- friends cluster labels + caption vessels
- shared Q&A shell family
- closing message support
- tiny back-cover metadata

## Q&A family

Six questions share 70% visual DNA and vary 30% by page:
- P02 tidy
- P03 emotional
- P06 playful

Questions/answers remain native editable text.

## Color jobs

Use hot pink/coral, sun yellow, ocean cyan/blue, navy/ink and cream/white as editorial jobs, not equal rainbow blocks on every page.

## Active edges

Energetic pages may activate selected edges. Do not activate every corner simply to mimic density.

P05 should keep enough open paper around the SHOGO/SHIORI grouping. P07/P08 should be much calmer.

## Real → generated bridge

Inspect real photos first, then generate page-specific title/frame/vessel/edge art that belongs to those sources. Generated decoration must not look like an unrelated sticker kit.
