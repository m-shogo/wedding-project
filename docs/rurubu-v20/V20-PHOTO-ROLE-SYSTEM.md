# V20 Photo Role System

Status: `CANONICAL_BEFORE_FIGMA_PHOTO_PLACEMENT / CURRENT_PAGE_ROLES_2026-09-01`

V20 does not select photos by old page number or old frame geometry. Photos are classified by editorial job, then assigned to the current page role.

Highest page-role authority:
- `V20-CURRENT-PAGE-ARCHITECTURE.md`
- `V20-PAGE-BY-PAGE-DESIGN-SPEC.md`

## Core roles

- `HERO` — strongest page/spread anchor where the page role actually requires one.
- `EMOTION` — expression, intimacy, laughter, human moment.
- `PLACE` — destination/environment.
- `ACTION` — eating, walking, playing, activity/movement.
- `DETAIL` — food, ticket, object, signage, hands, small memory.
- `COMEDY` — casual/funny/off-guard image.
- `PORTRAIT` — person-first identity photo.
- `FRIEND_MEMORY` — friendship/group/candid memory for P05.
- `CUTOUT_CANDIDATE` — subject separates cleanly from background.
- `TRANSITION` — image used to bridge zones rather than dominate.

## Critical P05 exception

P05 is not a HERO-led page.

Current P05:
- `SHOGO FRIENDS` cluster
- `SHIORI FRIENDS` cluster
- roughly 3–4 final photos per cluster when sources support it
- no family content
- **no single giant page-wide HERO/anchor photo**

For P05, classify candidates primarily as:
- `FRIEND_MEMORY / SHOGO`
- `FRIEND_MEMORY / SHIORI`
- optional local `EMOTION / COMEDY / ACTION / DETAIL` subroles

One image inside each cluster may be somewhat larger locally, but neither becomes a page-dominating HERO.

## Selection metadata

Record:
- Drive/source filename
- real / generated / dummy / reference classification
- people present only when known from source/user confirmation
- page/cluster candidate
- place/event when grounded
- orientation tendency
- focal point
- crop tolerance
- cutout potential
- emotional strength
- environmental strength
- uniqueness vs other selected photos
- possible editorial roles

Never infer friend identities/relationships from faces alone.

## Hard rules

1. Filename/page prefix is never layout authority.
2. Do not fill one page/spread with near-identical poses.
3. A strong travel page mixes people/place/action/detail when real material supports it.
4. HERO is not automatically the highest-resolution file.
5. HERO is not mandatory on every page; **P05 explicitly has no page-wide HERO**.
6. Do not force portrait photos into wide masks because old geometry exists.
7. Frame geometry follows source behavior.
8. Real autobiographical photography has priority over generated substitute imagery.
9. `DUMMY` and `REFERENCE` never become final autobiographical truth.
10. P05 family/Hawaii/proposal photos do not gain current P05 authority from historical assignment.

## Page-specific photo logic

- P01: 1 HERO + 1 support, optional detail
- P02: 2 main people photos + optional support
- P03: 1 story anchor + 1–2 supports
- P04: 1 travel HERO + 3–5 unequal supports/details
- **P05: two friend clusters, around 6–8 total; no page-wide HERO**
- P06: 1 candid HERO + 2–4 supports
- P07: 1 calm closing photo
- P08: 0–1 background photo

## Diversity gate

For photo-heavy pages/spreads, verify variation across several axes:
- shot distance
- orientation
- people vs environment
- activity vs posed
- color/lighting
- crop treatment
- emotional tone

For P05 additionally verify:
- SHOGO and SHIORI clusters are immediately distinguishable
- group faces remain recognizable at A5
- neither cluster collapses into a tiny contact sheet
- neither cluster is dominated by one oversized photo
