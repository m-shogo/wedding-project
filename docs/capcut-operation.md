# CapCut運用手順

## 目的

CapCutを考える場所にせず、事前に決めた構成を迷わず組み立てる場所にする。

## 原則

- BGMを先に置く。
- 写真とテロップは見やすさ優先。
- 動きは少なく、ゆっくり。
- トランジションは控えめ。
- AI背景素材は章切り替えや空気感に限定する。

## CapCutを開く前

- `docs/templates/storyboard.csv` を作る。
- `docs/templates/capcut-edit-plan.csv` を作る。
- 使用写真を決める。
- BGM候補と盛り上がり位置を決める。
- AI素材候補を絞る。

## アプリの状態

このMacではHomebrew caskでCapCutを入れる。

確認:

```bash
brew list --cask capcut
ls -ld /Applications/CapCut.app
```

起動:

```bash
open -a CapCut
```

## 素材の置き場

AI生成素材:

```text
~/ComfyUI-Shared/output/video/
```

書き出し:

```text
90_exports/
```

実動画、写真、BGM、CapCutの巨大な作業ファイルは原則Gitに入れない。repoには、構成、編集指示、採点、レビューだけ残す。

## 作業順

1. プロジェクトを作る。
2. 会場仕様に合わせて画角を設定する。
3. BGMを置く。
4. BGMの山にマーカーを付ける。
5. 章ごとの仮ブロックを置く。
6. 写真を秒割り通りに置く。
7. AI背景素材を章切り替えに置く。
8. キーフレームで写真にゆっくり動きを付ける。
9. テロップを置く。
10. トランジションを最小限に入れる。
11. 音量を調整する。
12. 通しで見て、読めないテロップを直す。
13. ラフを書き出す。
14. `docs/templates/review-notes.csv` にレビューを残す。

## 画面での具体操作

### 1. 新規プロジェクト

CapCutを開いて、`New project` を作る。

最初に確認すること:

- 画角は会場仕様に合わせる。未確認なら横長16:9で仮組みする。
- 解像度とfpsは、会場仕様が決まるまで仮で進める。
- プロジェクト名は内容と版数が分かる名前にする。

例:

```text
opening_10sec_test_v001
profile_chapter1_test_v001
```

### 2. 素材を読み込む

`Import` で読み込むもの:

- 写真
- BGM
- ComfyUIのAI背景動画
- 必要ならロゴや装飾素材

AI背景動画は、まず次の場所から探す。

```text
~/ComfyUI-Shared/output/video/
```

### 3. BGMを先に置く

タイムラインの最初にBGMを置く。

ここで決めること:

- 冒頭の入り
- 盛り上がる位置
- 章切り替えの位置
- 最後の余韻

BGMの山に合わせて、タイムライン上にマーカーやメモを置く。写真やAI素材は、その後に合わせる。

### 4. 仮ブロックを置く

写真や動画を細かく触る前に、章ごとの箱を置く。

例:

```text
0:00-0:05  ハワイ海AI背景 + タイトル
0:05-0:10  写真3枚 + 旅行感
0:10-0:15  雲海AI背景 + 入場前の余韻
```

### 5. AI背景素材を置く

AI背景は主役にしすぎない。

使いどころ:

- 冒頭の空気作り
- 章切り替え
- 写真が足りない場所の背景
- 最後の余韻

避けること:

- AI素材だけで長く見せる
- 人物、動物、文字、ロゴが出た素材を使う
- カメラが速い素材を使う
- 写真やテロップより目立たせる

### 6. 写真に動きを付ける

写真はキーフレームでゆっくり動かす。

基本は1枚につき1つの動きだけ。

```text
ズームイン: 100% → 108%
ズームアウト: 108% → 100%
パン: 左寄せ → 右寄せ
```

### 7. テロップを置く

テロップは短く、読みやすくする。

基本:

- 下中央
- 白文字
- 影を少し
- 1-2行
- 顔にかぶせない

AI背景の上に置く場合は、最初からテロップ余白がある素材だけ使う。

### 8. 書き出す

書き出し前に `docs/templates/export-checklist.csv` を見る。

出力先:

```text
90_exports/
```

命名例:

```text
opening-movie_v001_review.mp4
opening-movie_v002_bgm-adjusted.mp4
opening-movie_final_screening.mp4
```

書き出したら、`docs/templates/review-notes.csv` に気づいた点を残す。

## ComfyUIからCapCutに渡す流れ

1. CodexかChatGPT/Claudeで、欲しいAI背景素材を1つ決める。
2. ComfyUIで低解像度の短尺テストを作る。
3. 人物、動物、文字、ロゴ、速すぎる動きがないか確認する。
4. 採用候補だけ `docs/templates/ai-shot-list.csv` と `docs/templates/asset-log.csv` に記録する。
5. CapCutでBGMに合わせて配置する。
6. テロップや写真と合わせて見て、目立ちすぎるAI素材は短くする。

Codexへの依頼例:

```text
ComfyUIの出力動画を確認して、CapCutで使うなら何秒から何秒を切り出すべきか、
テロップ位置、フェード、BGM合わせまで編集指示にして。
実動画はGitに入れず、ログだけrepoに残して。
```

ChatGPT/Claudeへの依頼例:

```text
この10秒試作の流れを、結婚式オープニングとして見やすく直して。
BGMの山、写真の出し方、AI背景を入れる場所、テロップ案を秒単位で出して。
```

## 写真キーフレーム基本

ズームイン:

```text
0秒: 100%
4秒: 108%
```

ズームアウト:

```text
0秒: 108%
4秒: 100%
```

ゆっくりパン:

```text
0秒: 左寄せ
4秒: 右寄せ
```

## テロップ基本

- 1-2行
- 短く
- 白文字
- 影は少し
- 下中央中心
- 写真の顔にかぶせない
- 読む時間を確保する

## トランジション基本

優先:

- クロスフェード
- 黒フェード
- 白フェード
- 光で自然に切る

避ける:

- 派手な回転
- 強すぎるズーム
- 速すぎるワイプ
- 効果音頼りの切り替え

## 書き出し前チェック

- テロップが読める
- 顔に文字がかぶっていない
- 音量が大きすぎない
- AI素材が目立ちすぎない
- 章切り替えが分かる
- 会場仕様に合っている
- バックアップ用も書き出す

記録先:

- `docs/templates/export-checklist.csv`
