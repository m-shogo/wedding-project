# CapCut運用手順

## 目的

CapCutを考える場所にせず、事前に決めた構成を迷わず組み立てる場所にする。

## 原則

- BGMを先に置く。
- 写真とテロップは見やすさ優先。
- 動きは少なく、ゆっくり。
- トランジションは控えめ。
- AI背景素材は章切り替えや空気感に限定する。

## CapCutを開く前

- `docs/templates/storyboard.csv` を作る。
- `docs/templates/capcut-edit-plan.csv` を作る。
- 使用写真を決める。
- BGM候補と盛り上がり位置を決める。
- AI素材候補を絞る。

## 作業順

1. プロジェクトを作る。
2. 会場仕様に合わせて画角を設定する。
3. BGMを置く。
4. BGMの山にマーカーを付ける。
5. 章ごとの仮ブロックを置く。
6. 写真を秒割り通りに置く。
7. AI背景素材を章切り替えに置く。
8. キーフレームで写真にゆっくり動きを付ける。
9. テロップを置く。
10. トランジションを最小限に入れる。
11. 音量を調整する。
12. 通しで見て、読めないテロップを直す。
13. ラフを書き出す。
14. `docs/templates/review-notes.csv` にレビューを残す。

## 写真キーフレーム基本

ズームイン:

```text
0秒: 100%
4秒: 108%
```

ズームアウト:

```text
0秒: 108%
4秒: 100%
```

ゆっくりパン:

```text
0秒: 左寄せ
4秒: 右寄せ
```

## テロップ基本

- 1-2行
- 短く
- 白文字
- 影は少し
- 下中央中心
- 写真の顔にかぶせない
- 読む時間を確保する

## トランジション基本

優先:

- クロスフェード
- 黒フェード
- 白フェード
- 光で自然に切る

避ける:

- 派手な回転
- 強すぎるズーム
- 速すぎるワイプ
- 効果音頼りの切り替え

## 書き出し前チェック

- テロップが読める
- 顔に文字がかぶっていない
- 音量が大きすぎない
- AI素材が目立ちすぎない
- 章切り替えが分かる
- 会場仕様に合っている
- バックアップ用も書き出す

記録先:

- `docs/templates/export-checklist.csv`
