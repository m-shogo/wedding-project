# 全動画 素材・情報TODO

全ムービー制作に必要な素材と情報のチェックリスト。

現在のサンプル題材は「旅行」。今後テーマが変わる場合は、モチーフ、参考映像、AI背景素材、コピーだけ差し替える。

## 優先順位

1. オープニングムービー
2. プロフィールムービー
3. 紹介ムービー、その他動画
4. AI背景素材
5. テロップ、BGM、編集指示
6. 印刷物、返礼品、しおりなどのサブ制作物

印刷物や返礼品は、動画の世界観が固まってから合わせる。
