# NRSL — Travel energy should be structurally bound to the artifact’s semantic journey

Source scope/item: non-Rurubu / ADD-03 当日タイムテーブル

State: `TESTED_LOCAL / PRE_FIGMA_VERIFICATION / CROSS_ITEM_CANDIDATE_NOT_YET`

## Visible problem

The live `DAY BROADSHEET` Current remains structurally excellent and sellable, but a fresh screenshot audit shows an emotional ceiling against the latest user brief: it reads mainly as a sober printed program. Travel / departure anticipation is weak because the composition communicates chronology as stacked information rather than as a felt journey through one day.

## Root-cause hypothesis

Adding travel colors, abstract waves, paper blocks, or map-like containers is not sufficient. Those additions can recreate generic travel-poster or UI/card grammar. A travel-themed print artifact becomes more specific when the dominant visual gesture is **structurally tied to what the artifact actually does**.

For a timetable, the strongest transferable candidate is not “use a route line everywhere”; it is: if a visual journey is introduced, it should correspond to the artifact’s real semantic sequence rather than function as independent decoration.

## Expected improvement

Increase travel / movement / celebration energy while preserving fast timetable recognition and keeping all factual/variable text native.

## Regression risk

- route geometry can compete with Japanese copy;
- the result can become a travel poster or map app;
- repeated use of route curves across unrelated items would become another suite template;
- excitement can increase while timetable specificity decreases.

Therefore the receiving artifact must prove the gesture at whole / reading / actual-size scales and long-copy stress before adoption.

## What must remain item-specific

Do not transfer ADD-03’s exact route curve, colors, folds, event anchors, A2/A3 geometry, or timetable copy to other items.

## Cross-item applicability hypothesis

On another artifact that needs “more travel energy,” first ask what **real user journey or physical behavior** the item represents. A dominant travel gesture is worth testing only when it can be derived from that semantic role. If the gesture exists only because the theme is travel, treat it as decorative and likely generic.
