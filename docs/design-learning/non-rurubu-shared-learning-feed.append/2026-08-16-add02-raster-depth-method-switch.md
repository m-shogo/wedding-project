## Visible problem

Two independent clean-room iterations (V3 and V5) produced structurally sound, editable table-sign families but still failed to clearly beat retained production. The repeated gap was not information hierarchy or native-editability correctness; several destinations still lacked convincing material/editorial depth and destination-specific visual punch.

## Root-cause hypothesis

When a print artifact is already structurally sound, continuing to describe material, paper, architecture, atmosphere or tactile depth with abstract vector geometry can plateau. A single isolated composed raster role may carry tonal/material information more efficiently than another layer of vector ornament, while native semantic text remains independently editable.

This is not a claim that raster is globally superior to SVG. The method applies only where continuous-tone/material depth is the observed bottleneck.

## Bounded test

A brand-new clean-room V6 page tested Italy, France and Japan only. No retained production or prior clean-room visual was opened during authoring. Each representative used:

- one new fixed composed raster IMAGE role;
- native editable destination/table/date/country-note text;
- no variable/factual copy baked into raster;
- `1000×1480` root;
- explicit long-copy stress before retained-production comparison.

France produced a materially stronger folded-publication depth direction and survived completion-only comparison as a serious candidate. Italy improved tonal/material depth but retained production still had stronger identity. Japan remained too quiet and was rejected.

## Expected improvement

Use pixel/composed imagery only where it earns its role by adding real depth, materiality or atmosphere that abstract vector construction could not achieve economically or convincingly.

## Regression risks

- generic texture can add noise without destination identity;
- low-resolution raster may look acceptable at thumbnail scale but fail print/actual-size QA;
- flattening the whole artifact would destroy semantic editability;
- applying the same raster treatment to every item can create a new template signature;
- a visually rich raster can compete with native copy or collapse text-safe space.

## Structural / long-copy evidence

All three V6 representatives read back as:

- root `1000×1480`;
- native text count `5`;
- IMAGE fill count `1`;
- visible text outside root `0`.

Fresh stress exposed a note/date collision risk in France and inadequate reserve in Japan. The fix was structural: note + date became a native vertical auto-layout stack. Post-repair stress bottoms were Italy `1266`, France `1412`, Japan `1334` against root bottom `1480`, with outside visible text `0`.

This confirms that adding a richer image role does not reduce the requirement to rerun dynamic-copy QA.

## What must remain item-specific

Do not transfer Italy/France/Japan palettes, folds, material motifs, table-sign layout, typography coordinates, country identity devices or the exact ratio of image to text. Do not copy this treatment into Rurubu or another paper item.

## Cross-item applicability hypothesis

When another materially different print artifact has already passed hierarchy/editability QA but repeated vector/native construction still looks flat, run one bounded comparison with an isolated high-quality composed raster role. Keep variable text native, define a text-safe zone, rerun long-copy QA, and evaluate material-depth gain separately from source-resolution readiness.

A receiving item should reject the raster approach if the visible problem is actually hierarchy, typography, spacing, or physical-paper logic rather than missing material depth.
