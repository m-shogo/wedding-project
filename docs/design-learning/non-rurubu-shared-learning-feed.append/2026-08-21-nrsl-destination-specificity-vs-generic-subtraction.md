## NRSL — Removing a repeated graphic grammar is not enough; replacement must add item-specific meaning

State: `VERIFIED_LOCAL → CROSS_ITEM_CANDIDATE`
Failure fingerprint: `F-NRSL-GENERIC-SUBTRACTION-WITHOUT-SPECIFICITY`
Source item: `ADD-02 11卓の国別テーブルサイン`

### Visible problem

ADD-02's promoted 11-destination family is energetic and structurally healthy, but a fresh whole-family screenshot exposed a possible ceiling: multiple destinations still use related circles, rounded strokes and oversized numerals. The family is not identical, yet some differentiation is carried by palette/rotation of a shared abstract grammar rather than by stronger destination-specific visual character.

### Root-cause hypothesis

When a repeated visual grammar is identified, simply removing the repeated shapes or replacing them with one new system can make the design **less templated but also less specific**. The result may become generic modernist poster design, generic signage, or a new repeated physical-object metaphor.

The missing step is semantic gain: the replacement should increase meaning specific to the item/destination, not only decrease similarity.

### Bounded test

Production remained untouched. A new blank-frame Figma study page was created using only destination name, table number, date, native theme-copy roles and `1000×1480` dimensions:

- page `146:46 / VNEXT_STUDY / ADD-02 / PLACE-DERIVED FAMILY / 2026-08-21`;
- A `TYPE AS LANDSCAPE`: `146:47 / 146:57`;
- B `FOLDED PAPER INDEX`: `146:67 / 146:78`;
- C `EDITORIAL BAND`: `146:89 / 146:99`;
- D `TYPOGRAPHIC SOUVENIR`: `147:2 / 147:11`.

HAWAII and JAPAN were used as two deliberately different receiving destinations.

### Result

All four were rejected for production promotion.

- A removed repeated abstract shapes but became too quiet and generic.
- B added paper plausibility but reused one fold/index metaphor across both destinations, reproducing the physical-metaphor convergence risk.
- C recovered energy but read as generic event signage rather than place-specific destination identity.
- D used destination typography itself as the hero and was the strongest new direction, but live actual-size screenshots still felt sparse/gallery-like and lost too much of the celebratory wedding-travel energy.

Current production therefore remains selected.

### Three-scale evidence

- D HAWAII `147:2`, actual `1000×1480`: structurally clean but visually under-authored for the brief;
- D JAPAN `147:11`, actual `1000×1480`: same conclusion;
- no production node, generated asset or Drive binary changed.

### External professional-learning connection

Public professional references reinforced the diagnosis:

- Pentagram hospitality work shows that a system can unify many moods through a concept tied to place/material rather than repeating one graphic module.
- Kendall Henderson's Tokyo project demonstrates that a place lexicon can be distilled through typography, colour and shape, but still needs enough specific visual evidence to evoke the place.
- Cooper Hewitt/AIGA poster analysis shows there is no single universal “pop” device; scale, crop, hierarchy and contrast only work when assembled around the communication goal.

### Expected improvement

Future redesigns should evaluate both sides of the equation:

1. Did the new direction reduce a visible template fingerprint?
2. Did it add an equally strong or stronger item-specific semantic/experiential reason?

A direction that only satisfies #1 should not be promoted.

### Regression risk

This principle can be abused to demand literal icons/photos everywhere. Do not equate “specificity” with clip-art, flags, stereotypes, fake landmarks, literal airline cues, or decorative image generation. Specificity may come from typography, material, user action, genuine photography, illustration, crop, print behavior, or a fixed-art lexicon appropriate to the item.

### What must remain item-specific

Do not transfer ADD-02's country names, table numbering, dimensions, HAWAII/JAPAN palette, poster proportions or destination hierarchy. Do not turn every receiving item into a destination poster or require generated imagery.

### Cross-item applicability hypothesis

When family-scale QA identifies repeated visual grammar and a clean-room alternative is built, score **semantic gain** explicitly. If the new design is merely different but less emotionally or functionally specific, reject it and switch method.

### Next receiving-item experiment

Use this on the next non-Rurubu family-diversity redesign where subtraction or metaphor replacement is proposed. Before promotion, require a one-sentence answer to: **what item-specific meaning did the replacement add?**

For ADD-02 itself, the next method is destination visual-lexicon research plus a bounded non-person atmosphere/texture/editorial-art role on two anchor destinations, not continued polishing of the four rejected generic systems.
