# RSL-255 — grounded place/story must own the memory page when authority already exists

Date: 2026-08-24

State: `VERIFIED_LOCAL_MULTI-SYSTEM → CROSS_ITEM_CANDIDATE`

## Visible problem

V7 G2 and V8 AQ3 were visually mature but still used generic travel-memory grammar such as `朝 / 海辺を歩く`, `昼 / 小さな店に入る`, `夕 / 街の光を見る`, `夜 / 食卓で終える` even though the Rurubu content authority already contained grounded couple-specific Memory Spot material: Okinawa, Korea, Hawaii proposal, and today's Yokohama destination.

The problem was not that the generic copy was false in a narrow sense. It was that a polished publication used generic invented travel beats in place of stronger available grounded content, making the page more template-like and less couple-specific than the authority allowed.

## Root-cause hypothesis

Layout/visual rhythm had become the semantic owner. Copy was being kept because it fitted the existing design roles, instead of letting grounded content determine what those roles should communicate.

Professional reference observation used for this test:
- strong travel editorial practice depends on specific/local knowledge rather than generic travel aesthetics;
- photo/editorial-book practice treats words, captions and sequence as part of meaning, so copy should not be an afterthought pasted into a fixed image grammar.

These observations were treated as hypotheses, not promoted rules by themselves.

## Verified local principle

**When grounded, sufficiently specific content already exists for a semantic page role, do not retain generic thematic placeholder copy merely because it fits the current layout. Re-design the semantic roles around the grounded content, while keeping unresolved facts explicitly unresolved.**

This is not a command to maximize factual density or remove editorial writing. Draft/editorial connective copy remains valid when clearly used as editorial copy and anchored to grounded facts.

- V8 typography/grid/whitespace treatment;

- the conclusion that a generic caption is always inferior.
