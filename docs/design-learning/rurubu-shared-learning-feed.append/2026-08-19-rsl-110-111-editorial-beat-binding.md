# RSL-110 / RSL-111 — Rurubu bounded editorial-beat learning

## RSL-110 — Quiet support information can become a second editorial beat through native typography

State: `VERIFIED_LOCAL → CROSS_ITEM_CANDIDATE`

Source: Rurubu V6 1DAY Plan EJ → EQ.

Visible problem: a correct photo-led page still had a lower field that read as leftover POINT/TRIP DATA support information.

Root-cause hypothesis: the problem was not missing imagery. Support information lacked editorial scale hierarchy.

Bounded test: preserved all photos and right-page structure; promoted the existing reader-facing note into `POINT / 01` + a larger native headline, retained an editable body, and increased native TRIP DATA value readability.

Failure evidence: first added text node landed at the Figma page root; parent readback caught it. First long-copy proof then showed a non-text rule crossing enlarged values; that proof was rejected and the rule moved before retest.

Evidence: EQ `1803:2`, left `1803:3`; whole PASS; actual-size 794×1123 PASS; collision 0; safe risk 0; corrected long-copy proof `1805:68 / 1805:69` collision 0, safe risk 0, rule contact 0.

What must remain Rurubu-specific: exact Yokohama itinerary copy, colors, sizes, coordinates and travel-magazine grammar.

Cross-item hypothesis: where support copy is correct but visually reads as leftover space, another print item may independently test stronger native type hierarchy before adding a card or image. Dynamic copy must be restressed after spatial/type changes.

## RSL-111 — A small source-safe photo can gain editorial responsibility by binding to native number/title

State: `VERIFIED_LOCAL → CROSS_ITEM_CANDIDATE`

Source: Rurubu V6 Cafe EP → ER.

Visible problem: Cafe 02 read as a small photo module followed by a separate title/copy module.

Root-cause hypothesis: the photo did not need to become larger; it needed to participate in the same editorial beat as the native number and title.

Bounded test: retained the same 238×218 replaceable source-safe photo, introduced only a light rotation/reposition, and moved native `02`/title/copy into one asymmetric composition.

Failure evidence: first ER structure QA caught a 25×54px native text collision between `02` and title. The text stack moved right; intentional photo/number overlap was retained.

Evidence: ER `1805:134`, Cafe `1805:135`; whole PASS; actual-size 794×1123 PASS; native text 17; collision 0; safe risk 0; photo remains 238×218 and independently replaceable.

What must remain Rurubu-specific: photo choice, 02 geometry, palette, Japanese title treatment and travel-guide visual grammar.

Cross-item hypothesis: when a small legitimate image is technically correct but feels like a detached card, another print item may independently test semantic binding to an existing native typographic beat before generating or enlarging imagery.
