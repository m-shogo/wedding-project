## Visible problems

Two different native Japanese text roles in the same spread exposed the same class of professional defect despite technically valid boxes:

1. Guide 01 body displayed `ゆっくり流れる時間。` as `...時` / `間。`.
2. Left sensory copy displayed the intended sentence `思い出を巡りながら、今日の横浜へ。` with `へ。` visually stranded on a separate line.

Neither problem was truncation or factual-copy error. Both were semantic/compositional failures visible at reading or actual-size scale.

## Root-cause hypothesis

Text-box technical fit is not equivalent to Japanese typographic correctness. Short semantic units can be damaged by the combined line measure, font scale, alignment and neighboring geometry even when native text remains fully present.

## Bounded experiments

### G6 / compact guide body

- scale-only `22 → 20 px` still failed visually;
- `19 px / width 200` fixed the break but collided with the large `01`;
- final `19 px / x927 / width193` preserved `ゆっくり流れる時間。` as one semantic line and removed the collision.

### G7 / larger sensory copy

G6 remained visually coherent overall but actual-size review exposed a second semantic-wrap defect in `TEXT / V7 MEMORY SENSORY`: the particle/punctuation `へ。` was stranded after `今日の横浜`.

Rollback-safe G7 changed only that native text role:

- node `2424:7`

The width stays clear of the adjacent secondary-image role and retains V7 hierarchy.

## Transferable principle

When Japanese copy has an awkward semantic break, test **measure + scale + alignment + neighboring geometry as one system** and require both screenshot review and structural readback after each materially different correction. Do not solve the symptom with a box, badge, arbitrary manual decoration or blanket smaller type.

This is not a rule that particles must never start a line, nor a universal point-size/line-length prescription. The defect must be judged in context using reading flow and optical balance.
