## Observation

A truth-safe print spread can still feel weak/AI-like when unresolved factual roles are distributed as small equal-weight labels across a large field. The defect is not always solved by adding modules or decoration.

## Root-cause hypothesis

When a page contains a fixed count of semantic roles (here six facts and six questions), using those roles themselves as strong scanning anchors can create editorial density without UI containment. Image anchors should bind major fields; semantic numerals can establish quick navigation; unresolved facts remain native/replaceable.

## Failure fingerprints

### `FIGMA_CLONE_HIDDEN_SEMANTIC_NUMBERS`

Cloned comparison nodes can preserve `visible=false`; styling/repositioning a hidden semantic layer does not reactivate it. After clone, read back visibility for every semantic role being promoted. Explicitly unhide only intended roles.

Status: `VERIFIED_LOCAL`.

### `EDITORIAL_RELAYOUT_RETAINS_LEGACY_TEXT_MEASURE`

Moving existing text roles into a tighter hierarchy while retaining old widths can create collisions even when the copy itself is unchanged. After spatial relayout, rerun structure QA; correct the minimum bounded measure rather than adding containers.

Status: `VERIFIED_LOCAL`.
