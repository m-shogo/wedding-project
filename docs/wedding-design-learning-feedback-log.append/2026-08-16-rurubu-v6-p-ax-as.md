# Rurubu V6 — P + AX/AS design feedback

Date: 2026-08-16
Scope: Rurubu WEDDING only

## Observation

The previous preferred P + AU/AS system was structurally strong but Profile/Q&A remained materially quieter than Outer P and Story/chronology AS. The defect was most visible at thumbnail and actual Profile size: three lower Profile images stopped early and Q&A retained a passive lower field.

## Hypothesis

Before adding more decorative assets, increase the visual authority of already legitimate replaceable photos. Then compare that stronger baseline against a bounded fixed/composed-decoration treatment. Adopt decoration only if it clearly improves the artifact at real use size.

- actual Profile review exposed four micro-caption/profile-note nodes becoming noise, so those nonessential labels were hidden;
- kept variable/factual copy native and photos replaceable.

Result: `VERIFIED_LOCAL`, materially stronger than AU.

Three-scale evidence:

- 500 px whole spread PASS;
- 1200 px reading PASS;
- Profile actual `794×1123` PASS;
- Q&A actual `794×1123` PASS;
