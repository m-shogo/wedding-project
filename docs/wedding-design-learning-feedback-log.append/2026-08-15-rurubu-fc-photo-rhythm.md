# 2026-08-15 — Rurubu FC photo-rhythm feedback

Source: Rurubu WEDDING V5 FC clean-room experiment.

## What changed the production decision
The current outer had improved typography but still used a large colored caption block and repeated the same coast image on front and back. A rollback-safe candidate proved that redistributing photo scale and replacing the repeated support role with an already verified alternate image improved the magazine silhouette without adding decoration.

## Capability learned
1. Subtract containment before adding decoration: a thin editorial rule can retain caption anchoring where a large card-like field is unnecessary.
2. Repetition audit is part of image QA: a technically good image can weaken an item when the same source carries multiple large roles across the physical spread.
3. Reuse-before-generate: when an accepted, provenance-known image already satisfies a secondary role, test it before generating a new asset.
4. Three-scale rendered evidence remains required; structure `collision=0` alone is insufficient.

## Cross-item status
`CROSS_ITEM_CANDIDATE`, not a universal visual rule. Other wedding items may test containment subtraction and source-repetition audits, but must not copy Rurubu photo ratios, overlap angles, colors, or magazine grammar.
