# 2026-08-16 — Rurubu V6 Outer T photo-led back-cover experiment

Scope: Rurubu WEDDING only.

## Observation

Outer S front already behaved like a photo-led Japanese travel-magazine cover, but the back still read as a separate photo header followed by a beige information/timeline panel.

## Hypothesis

The page needed stronger field continuity rather than additional decorative density. The existing flatlay source had enough intrinsic resolution to become the dominant back-cover field.

## Test

Outer T `1447:2` duplicated S and changed only the back cover:

- expanded existing verified flatlay across the full width;
- converted the existing navy column into a compact title overlay;
- strengthened the café/skyline overlap using the same verified replaceable images;
- kept all chronology facts native and editable;
- introduced no new asset, card, gradient, shadow, or generated decoration.

The first pass exposed a rendered subline/title collision despite the broader composition looking stronger. The subline was moved and reduced before promotion.

## Three-scale result

- 500px whole item: T preferred over S; back now reads as one photographic field.
- 900px reading spread: photo/text hierarchy remains legible and the lower chronology stays separate without card containment.
- native 794×1123 back: PASS after the subline fix; text/text collision 0; 18px safe-area risk 0.

## Adoption

`VERIFIED_LOCAL`: T promoted and S retained hidden as rollback.

No generation or Drive write occurred. Existing generated section masters remain Drive-only/not adopted.

## Next application

Review T + BG/BE as one magazine system. If another region still reads as stacked modules, test photo/type field hierarchy before adding decorative objects. Do not assume extending a photo field is always correct; source fidelity and actual-size contrast remain hard gates.
