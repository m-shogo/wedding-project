# Rurubu V7 H10 — design-learning feedback

Date: 2026-08-24
Scope: Rurubu WEDDING only

## New knowledge used

This run deliberately moved away from recent numbering, folio and truth-copy studies and examined photo-led editorial construction. Professional photobook/editorial practice reinforced that photographs should participate in page structure and sequence rather than be treated as interchangeable content placed into fixed modules.

## Decision changed by the learning

Before this research, the likely next move on V7 Cafe was another micro-typography/detail pass or waiting entirely for new photography. Instead, H9 was re-read as a composition and the existing top-left photo/title split was identified as too close to equal-module grammar for a high-energy travel-magazine page.

The bounded H10 test therefore changed **role balance**, not decoration:

- dominant photo width increased `465 → 515`
- cobalt title field decreased `328.7 → 278.7`
- fixed title and native text stayed independent/editable according to hybrid-authoring authority
- no new image, UI container or decorative polish was added

## Result

H10 `2467:2` passed 500px / 1400px / 1587×1123 DESIGN QA and structure QA. It was promoted; H9 `2454:2` remains hidden rollback.

This is useful learning because the professional research changed the design decision from “polish the module” to “question whether the module weights are editorially correct.”

No new RSL fingerprint was created. The result strengthens existing RSL-006 (`Photo-role redistribution can outperform adding assets`) in a materially different V7 Cafe role.

Status remains local/candidate-level because the photography is still structural dummy imagery. Exact ratios and V7 styling are not transferable.
