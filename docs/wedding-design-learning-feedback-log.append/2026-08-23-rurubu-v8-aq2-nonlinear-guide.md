## Fresh knowledge that changed the decision

Joost Grootens' atlas/information-book practice was used to distinguish **reader navigation behavior** from mere graphic hierarchy. The useful observation was that information publications may support non-linear discovery, so visual numbering should correspond to a real retrieval/ordering function instead of being retained as neutral decoration.

This changed the live design decision from likely whitespace/spacing polish to a semantic navigation test.

## Bounded experiment
