## Visible problem

The selected V5 FU/FX comparator was structurally healthy but still carried too much legacy-derived visual DNA and some stock/template feeling. V6 therefore had to prove that a materially different macro-composition could be built without copying V5 geometry or pretending that transport/documentation alone was visual progress.

## Principle/capability tested

1. Close the V5 selected-cleanroom dummy-design gate using fresh 3-scale screenshots, absolute-coordinate structure QA, fold/safe-area checks, fresh Drive IDs/sizes, Figma hashes and rollback evidence.
2. Start V6 only after that gate.
3. Build two materially different outer concepts and two materially different inside concepts from a clean sheet using the same already-verified raster pool and native editable text.
4. Compare silhouette and editorial payload before rewarding polish time or novelty.
5. Re-check actual-size rendered typography/contrast after geometry passes; structural collision=0 is not sufficient.

## Expected improvement

V6 should read more immediately as an energetic Japanese travel-information magazine: stronger destination hierarchy, more photo-led visual mass, unequal scale, intentional overlap, native Japanese type and denser—but still readable—editorial rhythm.

## Regression risk

- Reusing verified assets can preserve stale semantic problems if image roles are not reassigned deliberately.
- More overlap can become scrapbook noise.
- Large type or timeline labels on photography can pass bounds checks while failing contrast at actual size.
- A dramatically different clean-room structure can become too sparse/formal and lose the requested travel-magazine energy.
