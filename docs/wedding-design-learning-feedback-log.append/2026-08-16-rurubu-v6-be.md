# 2026-08-16 — Rurubu V6 BE chronology feedback

Scope: Rurubu WEDDING only.

## Observation

BC chronology had already removed UI cards and integrated the page title into a strong photo hero, but `01–05` still occupied a large cream field with near-equal visual weight. At thumbnail scale this read more like a plotted chronology diagram than a dense travel-magazine feature.

## Hypothesis

Editorial rhythm could improve without more raster decoration if repeated native event facts were deliberately split into **major and support beats**, then bound with only a couple of purposeful rules.

## Experiment

Created BE `1433:2` from BC `1420:2` as a rollback-safe duplicate.

- 01 / 03 / 05 enlarged as major native anchors.
- 02 / 04 retained as compact support anchors.
- date/title/copy geometry tightened around each anchor.
- existing event photos reorganized into a lower diagonal rhythm.
- two thin rules added as group binders.
- hero, WEDDING endpoint, all factual native text, all image hashes and replaceable roles retained.
- no new generated image, Drive write, upload, card, shadow, gradient or fixed decorative raster.

## Rejected / corrected states

The first prototype was not promoted because a generic duplicate-name lookup changed the Story title and large numeral boxes wrapped. After live source readback, Story was restored and chronology queries were scoped correctly. Structural QA then found several text intersections and one safe-area issue; all were corrected before adoption.

## Evidence

- whole spread 500 px: PASS, BE stronger than BC.
- reading spread 1400×990: PASS.

- 18 px text safe-area risks 0.
- Story side unchanged: text 11 / IMAGE 3 / collision 0 / safe risk 0.

## Decision

`BE > BC`.

Promoted:

- BE `1433:2` preferred.
- BC `1420:2` hidden rollback.
- Start Here `845:27` → `V5 FU/FX · V6 Q + BD/BE INSIDE STUDIES · V7 HOLD`.

## Learning

Repeated chronology does not need equal visual authority. When order and facts remain explicit in native text, selected milestones can carry stronger type scale while others work as support beats. This can produce a more magazine-like reading rhythm before adding cards or richer decoration.

Generalizable learning is recorded as RSL-041. Exact colors, sizes, event weighting, photo arrangement and Rurubu grammar remain item-specific.
