# Rurubu V8 Profile Z design-learning feedback — 2026-08-22

Scope: Rurubu WEDDING only.

## What changed

Profile/Q&A moved from V `2207:2` to Z `2215:2` after a two-step rollback-safe comparison.

- Y `2214:2` tested stronger/staggered prompt hierarchy and was rejected because the size differences were not defensible from content.
- Z kept prompts as navigation/context and promoted the actual short answers as the editorial voice.
- `Q&A / SMALL VOICES` became reader-facing native `Q&A / 小さな会話`.
- No image, card, badge, shadow, gradient, decorative English or invented fact was added.
- Initial structural QA caught Q-label text-box overlaps that were visually subtle; label boxes were corrected and QA rerun before promotion.

## Why this is better

The Q&A is less like a polished form/template. The words actually spoken by the subjects now carry the page's visual mass, while the questions remain sufficient to preserve reading context.

## Fresh learning used

- Córdova Canillas: publication quality is content-led, not a layout trick.
- Elana Schlenker: avoid using large decorative display type as a shortcut for editorial design.

The useful project hypothesis is not a style copy. It is to ask whether article/respondent-owned content can perform the visual job before inventing decorative hierarchy.
