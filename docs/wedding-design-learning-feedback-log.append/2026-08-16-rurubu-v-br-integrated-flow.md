# Rurubu WEDDING V6 — Outer V / Profile-Q&A BR feedback

Date: 2026-08-16
Scope: Rurubu WEDDING only

## Experiment 1 — Outer T → V

### Visible problem

The back cover still read as two stacked systems: a strong photography cluster, then a detached beige `みんなとの思い出 / ふたりの旅年表` area.

### Principle tested

Before adding decoration, bind a native section heading directly to the legitimate photograph it describes and compress the following sequence so the page reads as one editorial flow.

### Bounded change

- duplicated Outer T safely;
- reused the existing memory underline as a navy photo-caption strip;
- moved native `みんなとの思い出` onto the café photo;
- pulled chronology upward;
- strengthened the existing WEDDING terminal field;
- front cover, photos and hashes unchanged.

### Expected improvement

`photo → memory heading → chronology → WEDDING` should read continuously instead of as separate modules.

### Regression risk

Photo/text contrast, chronology crowding and lower safe-area pressure.

### Evidence

- preferred Figma: Outer V `1477:2`;
- actual-size back page `1477:3 / 794×1123`;
- 500px whole PASS;
- 1000px reading PASS;
- actual-size PASS;
- native text `18`;
- replaceable images `3`;
- text collisions `0`;
- 18px safe risks `0`;
- image hashes unchanged.

### Result

`VERIFIED_LOCAL / ADOPTED`.

The back cover is more magazine-like because the heading now belongs to the photograph rather than floating in a separate beige section. Outer T remains hidden rollback.

## Experiment 2 — Profile/Q&A BK → BR

### Visible problem

BK had a good photo-led interview hierarchy, but repeated `回答をここに。文量に合わせて調整。` visible in the preferred frame made it still look like a wireframe/form.

### Principle tested

Realistic visible dummy text mass is part of visual QA. A separate overflow stress proof does not replace the need for believable copy rhythm in the preferred design study.

### Bounded change

- duplicated BK safely;
- changed only six native answer strings;
- kept geometry, images, masks, questions, fonts and type sizes unchanged;
- used distinct realistic Japanese dummy sentences;
- explicitly treat them as non-final layout-evaluation copy.

### Expected improvement

Reduce form/wireframe appearance and reveal the actual reading rhythm of repeated Japanese answers.

### Regression risk

Longer copy could collide or be mistaken for final personal facts.

### Evidence

- preferred Figma: BR `1482:2`;
- actual-size Q&A page `1482:33 / 794×1123`;
- 1200px spread PASS;
- actual-size PASS;
- native text `25`;
- replaceable images `2`;
- text collisions `0`;
- 18px safe risks `0`;
- image hashes unchanged.

### Result

`VERIFIED_LOCAL / ADOPTED`.

BR reads more like a finished editorial study without sacrificing editability. BK remains hidden rollback.
