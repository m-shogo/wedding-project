# Wedding Design Learning / Feedback Log append — Rurubu JB chronology

Date: 2026-08-21
Scope: Rurubu WEDDING only

## Visible problem

IR's chronology right page had already replaced the legacy timeline rail, but Event 04 `同棲` still floated beside the dominant Event 03 street photo as a small utility-like text island. At whole-spread scale the middle of the page still partially read as a list rather than a designed magazine beat.

## Principle tested

A subordinate sequential event may need **visual attachment**, not merely semantic adjacency. Test one bounded editorial binder only when it clearly connects the subordinate event to its parent photographic beat.

## Bounded experiment

- duplicated IR `2104:2` to JB `2144:2`;
- preserved Story left page;
- enlarged/repositioned existing Event 03 image without changing source hash;
- added one square-corner yellow strip attached to the lower-left photo edge;
- moved native Event 04 number/title/copy onto the strip;
- retained 01/02 and 05/06 as separate unequal beats;
- no new image, generated asset, rounded card, shadow, gradient, or rasterized text.

## Expected improvement

Reduce residual dashboard/list reading while strengthening the 03→04 journey transition and preserving editability.

## Regression risk

The binder could become a generic badge/card, cover too much image, or strand an inherited caption.

## Evidence and outcome

- 500 px whole spread: PASS and stronger than IR.
- 1400 px reading scale: PASS.
- native 794×1123 chronology right: PASS.
- visible native text: 26.
- visible IMAGE fills: 2.
- text intersections: 0.
- 18 px text safe risks: 0.
- image hashes unchanged.

Reading-scale QA caught one real regression: inherited white `01 / 旅のはじまり` caption landed awkwardly at the new strip/photo boundary. That intermediate state was rejected; the redundant caption was hidden, then three-scale QA was rerun.

Final status: `ADOPTED / VERIFIED_LOCAL` as preferred JB `2144:2`; IR `2104:2` retained hidden as rollback.

## Next application

Do not repeat the yellow strip as a style token. Re-run the common-scale preferred-set comparison and use the attachment principle only if another distinct role has the same ownership problem.
