# Rurubu V6 AR feedback — 2026-08-16

## Observation

AM was already clean and structurally safe, but its profile page still read as a template because the dominant photograph remained a contained horizontal module above a separate information field.

## Hypothesis

Before adding decoration, increase the authority of an already-valid photographic role. A full-width image field should create more travel-magazine energy while preserving native copy and replacement resilience.

## Test

AR `1389:2` cloned AM and changed only existing profile roles: full-width hero, tighter profile facts, unequal overlapping snapshot cluster, native pullquote brought above the cluster. Q&A remained unchanged.

## Result

- Profile native text 18 / IMAGE 4 / collision 0 / 18px safe risk 0;
- Q&A native text 24 / IMAGE 2 / collision 0 / 18px safe risk 0.

## Transferable lesson

When a print layout feels weak despite correct structure, first test whether an existing legitimate photo can become a stronger continuous visual field. Do not automatically add cards/stickers/decoration to manufacture density.

## Rurubu-specific and non-transferable

Exact photo ratio, Yokohama imagery, snapshot rotations, cream/coral/teal treatment, title scale, and Rurubu editorial grammar.
