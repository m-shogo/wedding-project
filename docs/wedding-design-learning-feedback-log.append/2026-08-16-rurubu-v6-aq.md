# Rurubu V6 AQ visual learning feedback — 2026-08-16

Scope: Rurubu WEDDING only.

## Observation

AP was structurally strong but still slightly too quiet/minimal for the requested Japanese travel-information-magazine feel. The weak point was not missing containers; it was that existing photos carried too little editorial annotation and the Story lower field still read partly as unused template space.

## Hypothesis

Before adding more cards/stickers/boxes, use the project-wide hybrid-authoring split more aggressively: keep all meaningful copy native, keep photos replaceable, and add only small native editorial captions/metadata that attach directly to image roles.

## Test

Created rollback-safe AQ `1387:2` from AP `1384:2`.

Changes:

- slightly stronger Story support-photo overlap while staying within registered intrinsic bounds;
- stronger native Story anchor typography;
- native photo captions on Story and chronology photos;
- compact native `TRAVEL NOTE / 03 SCENES` metadata in the Story lower field;
- native `01 — 06 / JOURNEY` and scene labels on chronology;
- hid the chronology top rule after typography provided enough binding;
- no new image generation, Drive write, binary upload, card, badge, shadow, gradient, or native decorative shape construction.

Two early text collisions were detected and corrected before promotion. A weak vertical side mark was hidden rather than retained.

## Result

AQ preferred and promoted.

- whole spread: PASS;
- Story actual-size `794×1123`: PASS;
- chronology actual-size `794×1123`: PASS;
- Story native text `12`, IMAGE roles `3`, collisions `0`, 18px safe risks `0`;
- chronology native text `32`, IMAGE roles `6`, collisions `0`, 18px safe risks `0`.

AP is preserved hidden as rollback.

## Learning

`VERIFIED_LOCAL → CROSS_ITEM_CANDIDATE`: when strong images still feel under-designed, tiny native captions/metadata attached to image roles can create useful editorial density without returning to UI-like containment or fragile decorative micro-geometry.

Do not transfer Rurubu palette, layout, caption wording, photo positions, or magazine grammar to unrelated items.
