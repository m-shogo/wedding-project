# Rurubu V8 Cafe AC — design learning feedback

Date: 2026-08-22
Figma current: `2226:2`
Previous current: `2212:2` hidden rollback

## Problem observed

Cafe X had correct structure and removed semantically weak generated imagery, but the spread still felt too close to a polished wireframe. The cafe-side sensory copy behaved as one uniform text module rather than as lived moments.

## New professional input

Apartamento's editorial direction was used as a new hypothesis source: real human occupation and everyday life can be more compelling than sterile perfection. The project did not copy Apartamento's layouts or visual identity.

## Test

Used only existing native copy and rebuilt the cafe sensory sequence with content-owned emphasis:

- strong `カップの音。`
- quiet `窓の光。`
- stronger relational `次の店を決める会話。`

On the dinner side, `一皿ずつ分け合いながら。` was bound more tightly to the semantic food/table headline.

## Before / after learning check

Earlier V8 subtraction work successfully removed weak generated imagery and pseudo-editorial mass, but that knowledge alone did not solve the current defect. The new professional input changed the actual design decision: instead of adding another visual or preserving equal restraint, the page now derives tempo from the human content already present.

## What remains specific to Rurubu

Exact copy, font sizes, positions, cafe/dinner sequence, color values, page numbers and the Cafe/Table role are Rurubu-specific and must not be copied to other wedding items.

## Next receiving experiment

If a later V8 role is visually quiet and human/lifestyle-led, first test whether its article-owned moments have genuine semantic differences before introducing more decoration or imagery. Do not scatter text merely to create variety.
