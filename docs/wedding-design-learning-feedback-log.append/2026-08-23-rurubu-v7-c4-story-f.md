# Rurubu WEDDING learning feedback — V7 C4 + Story F

Date: 2026-08-23
Scope: Rurubu WEDDING only

## What changed in design judgment

This run did not merely repeat the previous cover fixed-lockup treatment.

Fresh travel/editorial research changed two decisions:

1. **High density must be content-owned.** POPEYE's own production commentary reinforces that extreme information density is justified when the subject produces that much worthwhile material, not when the design wants to look busy. V7 Story therefore uses a quieter photo-led rhythm than the guide/1DAY spread instead of forcing equal information density across every spread.
2. **Travel identity can be carried by typography and colour, but must survive thumbnail competition.** The 38Hours travel-cover case strengthened the decision to test fixed display type on an inside V7 title while keeping utility copy native and separate.
3. **Strict structure can support scale variation.** The NYT Magazine travel-issue case strengthened the choice to avoid a UI timeline rail and make 2019/2026 stronger than 2021/2024 through scale and placement.
