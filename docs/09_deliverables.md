# 納品仕様

## 作るもの

- プロフィールムービー
- オープニングムービー
- 紹介ムービー、その他必要なムービー
- AI背景素材ライブラリ
- テロップ、ナレーション、編集指示書
- 返礼品、しおり、搭乗券風などの印刷物案。動画の世界観が固まった後に作るサブ制作物

## 書き出し管理

書き出しは `90_exports/` に置く。ただし、実ファイルは原則Gitに入れない。

会場仕様は `docs/templates/venue-specs.csv` に記録する。
書き出し前後の確認は `docs/templates/export-checklist.csv` に記録する。

命名例:

```text
profile-movie_v001_review_2026-06-07.mp4
profile-movie_v002_music-adjusted_2026-06-07.mp4
profile-movie_final_screening_2026-10-24.mp4
```

## チェック項目

- 会場指定の画角、解像度、形式に合っている
- 冒頭で引き込める
- 写真が見やすい
- テロップが読める
- BGMの盛り上がりと章切り替えが合っている
- AI素材が目立ちすぎない
- 人物や犬の扱いが自然
- 会場上映とSNS投稿で権利確認が分かれている
- 最後が新郎新婦入場につながる
- 予備ファイルとバックアップがある

## バージョン管理

- `v001`: 初回ラフ
- `v002`: 写真順、秒数、テロップ調整
- `v003`: BGM、トランジション調整
- `final`: 上映版
- `sns`: SNS投稿用に権利・尺・画角を調整した版

## バックアップ

- 上映版
- 予備形式
- SNS版が必要な場合は別ファイル
- 外部ストレージまたはクラウド保管
- 会場提出用と手元保管用を分ける
