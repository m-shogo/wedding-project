# 失敗例リスト

## 目的

動画AIとCapCutで起きやすい失敗を先に潰す。

## 動画AIの失敗

### 即不採用

- 人物が映る
- 犬や動物が映る
- 読める文字が出る
- ロゴや看板が出る
- 透かしがある
- 顔のようなものが出る
- 手や人影のようなものが出る

### 修正候補

- カメラが速すぎる
- 主役が多すぎる
- 光が強すぎてテロップが読めない
- 暗すぎる
- ループ時にカクつく
- 画面が忙しい
- テーマは合うが結婚式らしくない

## CapCutの失敗

### よくある失敗

- 写真の表示時間が短すぎる
- テロップが長すぎる
- テロップが顔にかぶる
- BGMの山と章切り替えがズレる
- トランジションが派手すぎる
- AI素材が多すぎて主役がぼやける
- 写真の動きが全部同じ
- 音量が大きすぎる
- 最後に余韻がない

### 修正方針

- 写真を見せる時間を増やす
- テロップを短くする
- 動きを減らす
- トランジションを減らす
- AI素材を削る
- BGMの山に章を合わせる
- 最後に無音または余韻を少し残す

## 判断基準

迷ったら、次の順で優先する。

1. 二人らしさ
2. 写真の見やすさ
3. BGMとの気持ちよさ
4. 世界観の統一
5. AI素材の綺麗さ
