# 失敗例リスト

## 目的

動画AIとCapCutで起きやすい失敗を先に潰す。

## 動画AIの失敗

### 即不採用

- 人物が映る
- 犬や動物が映る
- 読める文字が出る
- ロゴや看板が出る
- 透かしがある
- 顔のようなものが出る
- 手や人影のようなものが出る
- 窓枠、翼、建物、水平線などの形が時間方向に変形する
- 同じ物体が増える・消える
- 勝手なカットや場面転換が入る

### 修正候補

- カメラが速すぎる
- 主役が多すぎる
- 光が強すぎてテロップが読めない
- 暗すぎる
- ループ時にカクつく
- 画面が忙しい
- テーマは合うが結婚式らしくない
- 加速・減速が機械的でカメラの重さを感じない
- 影・反射・露出がフレーム間で飛ぶ
- 背景だけ不自然に泳ぐ
- 終端で急停止して編集点が作れない

## 「AIっぽい」見え方の典型

生成自体が綺麗でも、実写真・実動画の間に置くと浮く場合は不採用または再設計。

### 過剰演出

- cinematic / masterpiece / epic / 8K など抽象的な高品質語を重ねすぎる
- 意味のないレンズフレア、粒子、発光、霧が増える
- 必要のないdolly zoomやorbitが入る
- 1ショットでpan + dolly + tilt + zoomを同時に指示する
- 光源の理由がないのにドラマチックに明暗が変わる

修正:

- 1ショット1主動作、1カメラ意図へ削る
- `natural exposure response`、`realistic inertia`、`gentle acceleration/deceleration` のように物理的な指示へ置き換える
- I2Vでは静止画の内容を再説明せず、動きだけを書く

### 完璧すぎるカメラ

- 常に完全な中央構図
- 速度が一定でロボットアームのように見える
- 被写体に吸い付くような追従
- 手持ち風なのに周期的な揺れ

修正:

- restrained framing
- slight real-camera imperfection
- subtle optical breathing
- gentle acceleration and a soft stop
- 必要ならlocked cameraへ戻す

### ツルツルCG化

- 表面が過剰に滑らか
- エッジが鋭すぎる
- ノイズが無く、全域が同じ解像感
- 雲や水の動きが流体シミュレーション風に過剰

修正:

- natural film footage
- restrained contrast
- small real-world imperfections
- 生成後にCapCutで実写素材と同じ粒度・シャープネスへ寄せる

### 指示過多

症状:

- 何かは合っているが全体が散らかる
- モデルごとに違う部分を優先し、比較にならない
- 失敗するたびにプロンプトが長文化する

修正:

1. 用途を1文に戻す
2. 主動作を1つにする
3. カメラを1つにする
4. 参照素材の役割を分ける
5. 3回同じ失敗なら別モデル/別静止画/別ショットへ切り替える

## 生成ワークフローの失敗

### 最初から高コストモデルへ投げる

構図・動きが未確定なのに最終品質モデルを回すと、品質より試行回数が足りなくなる。

修正:

- 静止画で構図確定
- Seedance Mini/Fast系で動き比較
- 採用候補だけRunway Gen-4.5 / Veo 3.1 / 高品質Seedanceへ

### 参照を増やしすぎる

「参考が多いほど忠実になる」と考え、何を真似るか曖昧なまま複数素材を入れる。

修正:

```text
composition = image A
camera motion = video B
color mood = image C
```

のように責務を分ける。

### 一発生成で完成を狙う

ショット設計、静止画、動画、文字、音まで一度にAIへ任せると、どこを直すべきか分からなくなる。

修正:

- shot intent
- still
- I2V
- QA
- CapCut composite

を分離する。

## CapCutの失敗

### よくある失敗

- 写真の表示時間が短すぎる
- テロップが長すぎる
- テロップが顔にかぶる
- BGMの山と章切り替えがズレる
- トランジションが派手すぎる
- AI素材が多すぎて主役がぼやける
- 写真の動きが全部同じ
- 音量が大きすぎる
- 最後に余韻がない
- AI素材だけ色・シャープネス・コントラストが違う

### 修正方針

- 写真を見せる時間を増やす
- テロップを短くする
- 動きを減らす
- トランジションを減らす
- AI素材を削る
- BGMの山に章を合わせる
- 最後に無音または余韻を少し残す
- AI素材を前後の実写に合わせて色・粒度・速度を調整する

## 判断基準

迷ったら、次の順で優先する。

1. 二人らしさ
2. 写真の見やすさ
3. BGMとの気持ちよさ
4. 世界観の統一
5. 実写との馴染み
6. AI素材の綺麗さ

AI素材単体で綺麗でも、5より下なら採用しない。
