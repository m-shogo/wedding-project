# Rurubu V10 — Reference Fingerprint / Anti-AI Editorial Gate

Status: `CANONICAL_V10_AI_ASSIST_AUTHORITY`
Scope: Rurubu WEDDING V10 only.

This authority exists for one reason: prevent an AI-generated/Figma-template look and push V10 toward the visual behavior of the approved Rurubu reference while preserving factual correctness, editability, readability and print safety.

Reference nodes:
- `2771:2` — PROFILE + Q&A spread
- `2771:3` — MEMORY SPOTS + 1DAY spread
- `2771:4` — COVER + GUIDE spread

The reference is not production art and must never be copied literally. It is evidence for editorial behavior: hierarchy, density, scale, overlap, crop, color, typography, rhythm and information staging.

## 1. The reference fingerprint

### A. One dominant editorial gesture
Every page must have one unmistakable first read.

Good:
- very large Japanese title;
- one hero photo/cutout dominating the page;
- one oversized numbered/topic marker;
- a strong route/map/feature graphic when that is the page job.

Bad:
- four equal cards;
- every item the same size;
- title, photo and decorations all competing equally;
- a centered heading above a uniform grid.

The first read should be identifiable from thumbnail scale in roughly three seconds.

### B. Asymmetric composition with local order
The reference is energetic because the whole page is asymmetric, but each local cluster is understandable.

Use:
- offset title blocks;
- one large area balanced by several smaller areas;
- different image aspect ratios;
- selective edge crop/bleed;
- local alignments inside a cluster even when the overall page is irregular.

Do not use randomness as a substitute for art direction. Every offset, rotation, overlap and crop needs a reading or emphasis job.

### C. Mixed image hierarchy
A typical editorial page should not treat every photo equally.

Prefer a hierarchy such as:
- hero / anchor image: 1;
- support image: 1–2;
- micro-photo / cutout / food / location detail: 1–4 as the page job allows.

Not every page needs all roles. The important rule is visible difference in weight.

Avoid:
- same-width image rows;
- four identical rounded rectangles;
- identical frame treatment for every image;
- perfectly regular 2×2 photo matrices unless the reference/job explicitly calls for it.

### D. Layered depth, not flat UI modules
Reference pages typically read through at least three visual planes:

1. atmosphere/background/photo field;
2. editorial information surfaces, native text and photo frames;
3. foreground title, badge, sticker, flower, route, cutout or accent.

Use 2–5 meaningful overlaps per page as a loose editorial heuristic, not a quota. Overlap should connect related information or create emphasis.

Avoid:
- every element isolated in its own card;
- every surface having the same corner radius/shadow;
- decorative overlays that obscure body text.

### E. Edge tension and bleed
The reference frequently lets a title, photo, flower, route or large visual approach/cross an edge. This prevents a timid template look.

Per page, consider at least one controlled edge gesture when appropriate:
- hero photo reaches bleed;
- title extends toward trim;
- decorative cluster is partially cropped;
- large map/route continues beyond a local box.

Critical text still obeys safe area. Edge tension is for visual energy, not for losing information.

### F. Editorial clusters instead of cards
Build semantic clusters such as:

`photo + destination label + short caption + small icon/deco`

`question number + question + answer pair`

`time + activity + tiny photo/food cue`

`profile photo + name + compact fact list`

A cluster may have a support shape, but it should read as magazine editing, not application UI.

### G. Controlled imperfection
Reference-like energy benefits from limited handmade/print variation:
- slight rotations around roughly 1–3° on selected photos/labels;
- torn/polaroid/postcard/ribbon forms;
- hand-drawn arrows or flight paths;
- optical rather than mathematically equal alignment;
- decorative overlap that feels placed by an editor.

Never randomize every element. Keep body text, fact tables and core reading baselines stable.

### H. Display typography has a silhouette
A strong Rurubu-style title is not simply a bold font at large size.

It often has several of:
- extreme scale;
- tight custom line breaks;
- thick outline / multi-color edge;
- strong foreground/background separation;
- mixed Japanese/Latin hierarchy;
- slight crop/overlap;
- a supporting ribbon/badge/subtitle.

Hero display art may be generated/composed when that materially improves quality. Authoritative names, dates, facts, captions and body copy remain native editable text.

### I. Micro-information creates magazine density
The reference feels like a magazine because it contains many small useful reads, not because it contains many decorations.

Useful micro-information includes:
- short captions;
- numbered facts;
- time labels;
- place names;
- mini recommendations;
- checklists;
- Q&A prompts;
- destination labels;
- short pull quotes;
- tiny but readable metadata.

Do not invent facts merely to create density. If real content is unavailable, leave a clearly named editable placeholder role instead of fake copy.

### J. Color has editorial jobs
Do not distribute all brand colors evenly.

Assign jobs:
- dominant color = page identity / major title field;
- support color = secondary grouping;
- surprise accent = small emphasis only;
- dark ink / paper = stable reading base.

Strong color may be loud. Body copy must remain calm and legible.

### K. Texture and atmosphere
The reference does not feel like flat vector UI. Use visual atmosphere where appropriate:
- photography;
- sky/ocean/tropical color fields;
- paper/scrapbook texture;
- floral/tropical edge artwork;
- subtle print-like support assets.

Do not add texture under long copy if it harms readability.

## 2. AI-look fatal tells

A page fails the Anti-AI Gate if any of these dominate the composition:

- uniform card dashboard grammar;
- identical corner radii across most content;
- perfectly even gaps everywhere;
- centered-everything composition;
- 2×2 / 3×N equal module grids used as the default answer;
- all photos same size/aspect/frame;
- every page reusing the same template rhythm;
- excessive white/pastel empty space sold as “premium” when the reference is dense;
- generic English filler such as `TRAVEL / LOVE / JOURNEY` with no editorial purpose;
- arbitrary stickers placed only to fill holes;
- one font family/weight system doing all hierarchy;
- generated fake text inside production graphics;
- over-smoothed vector decoration with no tactile or editorial character;
- symmetric, mathematically perfect placement that ignores optical balance;
- decorative airline/passport UI clichés unrelated to actual content;
- body copy forced into tiny type to preserve a decorative layout;
- reference raster used as production background or copied literally.

If two or more fatal tells are clearly visible at thumbnail scale, revise before further polish.

## 3. Reference Match Score — 100 points

Score each materially changed page after screenshot review. This is an editorial diagnostic, not a mathematical guarantee.

### Hierarchy — 20
- 0–5: no clear first read
- 6–12: readable but generic
- 13–16: strong page hierarchy
- 17–20: unmistakable reference-like editorial hierarchy

### Composition / asymmetry — 20
- 0–5: grid/dashboard
- 6–12: safe but static
- 13–16: asymmetric with controlled balance
- 17–20: strong editorial tension, crop and local order

### Image behavior — 15
- difference in photo scale;
- crop quality;
- hero/support distinction;
- frame/cutout variation;
- no accidental spill.

### Editorial density / information rhythm — 15
- useful micro-information;
- clear clusters;
- no empty AI-template zones;
- no invented filler facts.

### Typography — 15
- Japanese-first hierarchy;
- expressive title silhouette;
- readable body;
- role variation;
- credible line breaks and optical spacing.

### Color / contrast — 10
- dominant/support/accent logic;
- stable reading contrast;
- no hue-only meaning;
- grayscale hierarchy survives.

### Texture / tactile character — 5
- enough atmosphere to avoid flat UI;
- no texture that harms reading.

Pass guidance:
- `90–100`: reference-level candidate; move to detailed QA.
- `80–89`: production direction is credible; refine weak categories.
- `70–79`: recognizable magazine intent but still visibly AI/template-like in places; revise before polish.
- `<70`: rebuild hierarchy/composition rather than micro-adjusting.

Hard rule: a high total score cannot override an AI-look fatal tell, unreadable body copy, DUMMY/REFERENCE misuse, broken masks or print-safety failure.

## 4. Reference-distance comparison loop

For each page after a meaningful pass:

1. capture current page screenshot at thumbnail scale;
2. place mentally beside the closest reference role, not necessarily the same content;
3. answer these questions in order:
   - Which has the stronger first read?
   - Which has greater image-scale variation?
   - Which creates more useful reading destinations?
   - Which feels less like equal cards?
   - Which uses edges/overlap more confidently?
   - Which title has a stronger silhouette?
   - Which remains easier to read at actual A5 size?
4. identify the largest reference-distance cause;
5. make one structural correction before micro-spacing.

Never respond to a weak reference match by simply adding more stickers.

## 5. Page-specific anti-template mutation grammar

The eight pages must feel like one magazine family, not eight copies of one template.

Use different dominant composition verbs:

- P01 COVER: `CROP + STACK + BURST` — huge title/hero, coverlines, edge energy.
- P02 PROFILE: `PAIR + LABEL + FACT` — two personalities, uneven but balanced portrait/fact rhythm.
- P03 Q&A: `NUMBER + QUESTION + ANSWER` — repeated semantic system with visual variation, not generic cards.
- P04 STORY: `FLOW + MILESTONE + PHOTO` — directional narrative, editorial timeline cues.
- P05 TIMELINE + MEMORY: `SEQUENCE + ANCHOR + INTERRUPTION` — chronology with one or two visual memory interruptions.
- P06 MEMORY SPOTS + GALLERY: `HERO + SATELLITES + DESTINATION` — one large memory/photo with smaller varied support.
- P07 1DAY + CAFE TABLE: `ROUTE + TIME + FOOD` — time sequence and route/map as information graphics, food used as editorial accents.
- P08 BACK COVER: `RESOLVE + UTILITY + MESSAGE` — quieter ending but still magazine-like; useful guide/message, not an empty brand end-card.

Across adjacent pages, avoid repeating the same hero position, same photo frame set, same title alignment and same dominant color.

## 6. Humanization rules for AI assembly

AI should deliberately preserve signs of editorial judgment:

- choose one thing to exaggerate and several things to quiet;
- allow optical adjustments instead of equal spacing everywhere;
- vary photo crop and aspect based on subject, not template slot;
- align captions to the image they explain even if this breaks a global grid;
- reuse motifs with variation rather than exact cloning;
- prefer one memorable graphic gesture over many small generic icons;
- leave a small calm reading zone near a dense area;
- use decorative objects where they point, frame, separate, emphasize or locate information;
- remove any decoration that has no job.

## 7. Production-safe exceptions

Reference similarity never overrides:
- factual correctness;
- user-specified wedding details;
- actual readable Japanese;
- safe trim/bleed;
- replaceable masks;
- photo identity/provenance boundaries;
- final resolution requirements;
- editability of changeable text;
- printer requirements.

If reference behavior conflicts with a production constraint, preserve the editorial principle in a safer form rather than copying the literal treatment.

## 8. Required reporting additions

After meaningful page work, report:
- closest reference node used for comparison;
- Reference Match Score /100 with the lowest two categories;
- any AI-look fatal tell found;
- largest reference-distance cause;
- structural correction made or next required;
- semantic assets + Drive IDs actually placed;
- actual-size readability / mask / resolution warnings.

Do not claim `REFERENCE_MATCH_PASS` unless score is at least 80, no fatal tell is visible, and readability/mask gates pass.
