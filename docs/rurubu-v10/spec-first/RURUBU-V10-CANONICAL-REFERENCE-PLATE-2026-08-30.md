# 1. What this reference gets right

The image succeeds because it does not behave like a UI layout. It behaves like a Japanese travel-magazine spread built from overlapping editorial clusters.

Core visible traits:

- very strong title silhouettes;
- saturated travel colors used in large, confident shapes;
- asymmetrical photo clusters rather than equal cards;
- photos in multiple treatments: cutout, polaroid, postcard, square, portrait, landscape, framed, tilted;
- foreground decorations that deliberately cross photo and text boundaries;
- small useful labels and micro-discoveries filling secondary zones;
- page-specific composition rather than one repeated template;
- consistent tropical/travel vocabulary tying pages together;
- warm cream/paper support zones that keep dense pages readable;
- large editorial titles plus many smaller callouts;
- visible edge tension: decorative elements touch/crop near page edges instead of floating safely in the center;
- a clear sense of a printed object, not a web dashboard.

The design should feel busy, joyful and collectible, but not random.

# 2. The visual grammar to reproduce

## 2.1 Hierarchy grammar

Every page should have five recognizable levels:

1. `FIRST READ` — page title or hero visual.
2. `SECOND READ` — dominant photo / main story cluster.
3. `EDITORIAL SUPPORT` — labels, short copy, secondary images.
4. `UTILITY` — dates, facts, location, sequence, guide information.
5. `MICRO DISCOVERY` — stamps, arrows, icons, handwritten notes, tiny visual jokes.

Do not give all five levels equal weight.

## 2.2 Photo grammar

Reference behavior:

- one photo usually dominates;
- support images vary strongly in size;
- images overlap each other and/or decoration;
- some frames tilt by a few degrees;
- white frame/polaroid/postcard treatments appear as accents, not as one global rule;
- the same frame family is not repeated mechanically;
- photo clusters form shapes rather than rows.

Production rule:

Photos remain independently replaceable in Figma. The visual reference may be raster, but final photo containers must preserve replaceability.

## 2.3 Title grammar

Titles are not merely text placed at the top.

They often use:
- white keyline;
- drop/offset shadow;
- strong pink/blue/yellow contrast;
- ribbon/backplate;
- decorative underline or brush stroke;
- small English subtitle;
- flowers or travel elements partially overlapping the title zone.

Body text must not be rasterized into these display-title assets.

## 2.4 Decoration grammar

Decorations have editorial jobs.

Use:
- tropical leaves / hibiscus / flowers as framing and page-edge anchors;
- airplane / suitcase / passport / ticket / camera as semantic travel signals;
- hearts / handwritten marks as emotional accents;
- stamps / postmarks / ribbons as grouping labels;
- arrows / routes / dots as reading-path aids;
- small illustrated objects as micro-discovery.

Never add decoration only to fill empty space when hierarchy is weak.

## 2.5 Density grammar

Target density is high, but density should be clustered.

Use:
- one or two dense zones;
- one calmer reading zone;
- deliberate overlap;
- varied object scale;
- selective negative space around body copy.

Avoid evenly distributing the same amount of content across the whole page.

## 2.6 Edge behavior

The reference frequently anchors the composition to page edges.

Good:
- leaves entering from corners;
- flowers clipped by trim;
- title ribbon touching an outer edge;
- photo/camera/suitcase clusters positioned near the bottom/side edge;
- decorative crop entering bleed.

Bad:
- every object floating inside a safe centered rectangle;
- giant unused margins that create generic luxury-web whitespace.

Critical copy remains inside safe area even when decoration enters bleed.

# 5. Anti-AI lessons from this reference

The strongest lesson is not “add more stickers.”

It is:

- vary scale;
- vary crop;
- vary alignment;
- create dominant editorial clusters;
- intentionally overlap layers;
- make page titles visually authored;
- create tactile object language;
- make each page composition role-specific;
- keep readable calm zones inside the energy.

Immediate failure patterns:

- 3–6 equal rounded cards;
- equal gaps everywhere;
- all content centered;
- one Auto Layout stack controlling the whole page;
- one repeated photo component used at identical size;
- pastel blocks with thin gray text;
- generic gradients;
- empty decorative English;
- a page that looks like a SaaS dashboard with wedding stickers added.

# 6. Reference-match review order

When comparing a V10 page to this plate, inspect in this order:

1. title silhouette;
2. dominant photo weight;
3. asymmetry;
4. scale variation;
5. overlap;
6. cluster density;
7. photo-treatment variation;
8. edge tension;
9. useful labels and micro-discovery;
10. color rhythm;
11. body-copy calm zone;
12. print-size readability.

Do not fix a failure in 1–6 by adding more decoration.
