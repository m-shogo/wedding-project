# P02 — PROFILE Page Manual

## PAGE JOB
Let guests understand Shogo and Shiori as two distinct people within seconds, then reward closer reading with small personality discoveries.

## READING PATH
1. FIRST READ: profile title.
2. SECOND READ: two portrait anchors.
3. THIRD READ: names + core facts.
4. USEFUL INFO: compact profile facts / comparison.
5. MICRO DISCOVERY: personal icons, handwritten comments, tiny objects.

## ZONE MAP
- top 0–16%: expressive profile title across top, with floral/travel overlap.
- upper-middle 14–50%: two portrait anchors, deliberately not identical in geometry.
- middle 42–72%: factual blocks near each person.
- lower 68–94%: shared comparison / favorite-things / mini story strip.
- edges: small flowers/travel accents, not full border decoration.

## PHOTO PLAN
- SHOGO_PROFILE: portrait/polaroid, ~32–38% page width, slight negative tilt.
- SHIORI_PROFILE: portrait/polaroid or rounded/organic frame, ~32–38%, slight positive tilt.
- SUPPORT_PERSONAL: 2–4 small images/objects total, mixed shapes.

Both people receive equal editorial respect, but not mirror-image cards.

## TITLE / TYPOGRAPHY
- large Japanese title with small English subtitle optional.
- names visually strong and handwritten/display-like if legible.
- facts remain native INK text on cream/paper fields.
- use labels rather than color alone to associate facts with each person.

## PARTS INVENTORY
- profile title;
- 2 differentiated portrait frames;
- small fact labels ×6–10;
- small hand-drawn arrows/hearts ×2–4;
- personal/travel object accents ×2–3;
- floral corner/mini cluster ×2;
- shared comparison/favorite strip shell ×1.

## COLOR JOBS
Dominant: warm paper/cream.
Support: pink and travel cyan used as labels/accents.
Surprise: yellow.
Body: INK.

## OVERLAP / Z-ORDER
paper → subtle floral edge → photo sources → frames → names/title → fact labels/native copy → foreground micro accents.

Allow one frame to overlap title support decoration slightly. Avoid body text crossing busy imagery.

## DENSITY MAP
Highest: portraits + name zone.
Medium: fact clusters.
Playful dense strip: lower shared-interest area.
Calm: inside factual text fields.

## EDGE TENSION
Small floral leaves may enter from upper corners. One personal object can sit partly off the lower edge of a photo cluster.

## EDITABILITY CONTRACT
NATIVE_EDITABLE: names, birth dates, hometowns, jobs, hobbies, facts, comparison text.
REPLACEABLE_IMAGE: profile photos and personal snapshots.
COMPOSED_DISPLAY_ASSET: title, decorative frames, floral/travel objects.

## ANTI-PATTERNS
- two identical employee-profile cards;
- perfect left/right mirror symmetry;
- pink = bride / blue = groom as the only identification;
- every fact in a pill;
- tiny body text squeezed into decoration.

## FIGMA EXECUTION
Place title and portraits first. Establish unequal but balanced portrait silhouettes. Add native fact clusters close to each portrait. Build the lower shared-interest strip last, then add only a few directional doodles/objects.

## QA
- both people immediately identifiable by name/position;
- portraits balanced but not cloned;
- factual copy readable at A5;
- 3+ size levels;
- lower area feels editorial, not like a settings table;
- photos independently replaceable.
