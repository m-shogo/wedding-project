# P03 — Q&A Page Manual

## PAGE JOB
Make the couple feel playful and human. Questions should be instantly scannable, while answers remain comfortable to read.

## READING PATH
1. FIRST READ: `6つの質問 Q&A`-type title.
2. SECOND READ: Q1/Q2 anchors.
3. THIRD READ: remaining question rhythm.
4. USEFUL INFO: native answer copy.
5. MICRO DISCOVERY: small camera/food/travel/heart objects tied to specific questions.

## ZONE MAP
- top 0–15%: large Q&A title, floral/travel support.
- body 15–88%: 4–6 question zones arranged in alternating, non-uniform rhythm.
- bottom/edge 78–96%: one supporting cutout/object/photo to finish the page.

Avoid a rigid 2×3 dashboard grid even if the six-question count suggests one.

## QUESTION SHAPE PLAN
Use 3–4 different shell treatments across six questions:
- question number burst;
- paper note with taped corner;
- speech-like irregular box;
- photo + caption answer cluster.

Repeat visual family enough for coherence but vary width, height and alignment.

## PHOTO PLAN
- SUPPORT_COUPLE/OBJECT: 1–2 only.
- use small contextual imagery for selected questions, not one image per card.
- photo size should interrupt the question rhythm rather than align to grid cells.

## TITLE / TYPOGRAPHY
- title: strong pink/blue display treatment with white keyline or ribbon support.
- Q-number: large, high-contrast, 10–13pt+ equivalent.
- question: bold native text.
- answer: BODY native INK on stable light field.

## PARTS INVENTORY
- Q&A title;
- Q-number markers 01–06;
- 3–4 question-shell variants;
- contextual mini objects ×3–5;
- hand-drawn arrows/hearts ×2–4;
- floral edge accents ×2;
- optional couple/corgi/camera-like support cutout only if semantically appropriate.

## COLOR JOBS
Dominant: warm paper/cream.
Support: pink.
Secondary: cyan/blue.
Surprise: yellow on selected Q-number or accent only.

## OVERLAP / Z-ORDER
paper → edge decoration → question shells → native Q/A text → selected supporting photo/object → foreground doodles.

Do not place long answers over illustrations.

## DENSITY MAP
High: top title + first two questions.
Medium-high: central question rhythm.
Medium: lower ending cluster.
Calm zones: inside answer fields.

## EDGE TENSION
Flowers/leaves can enter top corners; one lower object/cutout may crop near bottom edge.

## EDITABILITY CONTRACT
NATIVE_EDITABLE: every question and answer, numbers if likely to change.
REPLACEABLE_IMAGE: contextual photo(s).
COMPOSED_DISPLAY_ASSET: title, shells, decorative objects.

## ANTI-PATTERNS
- six identical rounded cards;
- exact 2×3 equal grid;
- every answer a different random color;
- answer type too small;
- decorative icons repeated uniformly in every box;
- unnecessary center alignment.

## FIGMA EXECUTION
Start with title, then place Q1/Q2 as strongest anchors. Build Q3–Q6 with alternating widths/heights and slight positional offsets. Establish readable answer fields. Add contextual micro-parts only after reading flow works.

## QA
- Q1–Q6 sequence obvious without perfect grid;
- answers readable at A5;
- question shells visibly vary;
- at least one photo/object interrupts module rhythm;
- no generic card dashboard feel;
- all answers editable.
