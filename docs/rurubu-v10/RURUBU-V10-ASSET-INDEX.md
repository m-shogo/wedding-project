## Prefix interpretation

- `LOGO_`: cover/identity hero candidate.
- `TITLE_`: section/page title candidate.
- `BADGE_`: small/medium callout, date or editorial accent.
- `REAL_PHOTO_`: real-photo candidate; verify actual subject/pixels before final use.
- `DUMMY_`: layout-only placeholder; never final real-person imagery.
- `GENERATED_PHOTO_` / `GENERATED_FOOD_`: generated visual candidate; requires AI-artifact + resolution QA.
- `PHOTO_CUTOUT_`: cutout/support visual; intentional spill only.
- `FRAME_`: decorative/support frame; image remains independent below/inside it.
- `DECORATION_`: optional editorial accent; must have a compositional job.
- `MAP_` / `ROUTE_`: only use where geography/sequence is semantically real.
- `BACKGROUND_`: background/full-field candidate; confirm A5 + bleed effective resolution.
- `REFERENCE_`: visual quality/composition reference only; never production placement.
