## Professional principles extracted

1. Fast music does not require permanently fast pictures.
2. A high-energy chorus is stronger when the visual peak is a great real photo, not a stronger transition.
3. Micro accents can answer 190 BPM while primary photo changes use the slower 95 BPM reading grid.
4. Directional transitions require directional source evidence.
5. Motion graphics should clarify rhythm or information, not advertise editing skill.
6. After a dense phrase, create a quiet/static phrase so the next peak can be felt.
7. Reference analysis records timing, scale, direction, density and hierarchy—not the surface template.
