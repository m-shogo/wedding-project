# 権利・プライバシー

## 基本

結婚式当日の上映、SNS投稿、YouTube公開、親族共有では必要な確認が変わる。使う範囲を分けて判断する。

## 写真・動画

- 新郎新婦、家族、友人、犬は実写真・実動画を使う。
- 友人や家族が大きく写る写真をSNS投稿に使う場合は、投稿前に確認する。
- 顔をAIで変形、合成、若返り、別衣装化する提案はしない。

## 音源

- 会場上映で使えるかを確認する。
- SNS投稿やYouTube公開で使えるかは別で確認する。
- CapCutテンプレや音源は、利用範囲が限定される場合があるため注意する。

## フォント・テンプレート

- 商用利用、映像利用、配布可否を確認する。
- 不明な場合は、標準フォントか利用条件が明確な素材を優先する。

## AI生成サービス

- 料金、無料枠、クレジット消費、商用利用、透かし、保存期間、入力データの扱いは使う直前に確認する。
- 実写真、家族写真、犬の写真を外部AIへアップロードする前に確認する。
- 人物が出ない背景素材でも、実在ロゴ、看板、読み取れる文字が出ないようにする。

## GitHub

- 写真、動画、音源、最終書き出しは原則コミットしない。
- 共有するのは構成、指示書、プロンプト、ログ、制作判断を基本にする。
