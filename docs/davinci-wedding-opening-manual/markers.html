STEP 02 / MUSIC MARKERS

曲の中に、
目印を置く。

写真も文字も、まだ置かなくていい。
「ここからサビ」「ここで旅行」「ここから5→1」が見えるだけで、一気に作りやすくなる。

KEY

M

再生ヘッドがある場所にマーカーを置くキー。今日はほぼこれだけ。

最初の1個を置く →
← Studio 最初の1個 7個の目印 終わったら

FIRST ONE

まず、0:16付近に1個だけ。

1個できれば、残りは同じことの繰り返し。

1分で確認

やること

イントロの終わりに「1番START」の目印

  1. 1
    StaRtを再生するタイムラインの▶︎、またはSpace。
  2. 2
    0:16付近で止めるピッタリじゃなくてOK。あとで直せる。
  3. 3
    キーボードの M を1回押すタイムラインに色付きの目印が付けば成功。
  4. 4
    同じ場所でMをもう一度押す名前を入れる画面が開いたら「1番 START」と入力。

POINT

秒数は仮で大丈夫。

曲を聴いて「ここだ」と思った位置に少し動かしてOK。今は編集の地図を作る段階。

再生→止める→M→名前

MARKER MAP

あとは、この7か所。

上から順番に置けばOK。秒数は今の仮位置。

迷ったら： 秒数を打ち込んで正確に置くより、まず曲を聴きながら「ここ」と思う位置でM。細かい調整は演出を置く時で大丈夫。

AFTER THIS

目印が並んだら、やっと演出へ。

次からは「どこを作りたい？」で選ぶ。順番に勉強する必要はない。
