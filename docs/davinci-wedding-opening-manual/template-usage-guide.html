WEDDING OPENING / BEGINNER TEMPLATE GUIDE

テンプレは
必要なところだけ使う

Mrs. GREEN APPLE「StaRt」のオープニング用。探す → ダウンロード → DaVinciに入れる → 必要な数秒だけ使うまでを、動画編集初心者向けに整理。

THE RULE

今回の基本ルール

① PreviewStaRtの速さに合うか見る
② 1本だけ入れるResolve 21で動くか確認
③ 1〜8秒だけ使う全部をテンプレ化しない
④ 自分の素材に直す文字・写真・色を変更

第一候補＝最初に試す。補佐候補＝第一候補が合わない、重い、使いにくい時に見る次候補。

DOWNLOAD → DAVINCI

ダウンロードしてから入れるまで

優先.drfx

.drfxなら一番簡単

  1. 配布ページでPreviewを見る。
  2. DaVinci Resolve対応版をDownload。
  3. Macの「ダウンロード」フォルダを開く。
  4. .drfxをダブルクリック。
  5. DaVinciが開いたらInstallを押す。
  6. Edit画面 → 左上のEffectsを開く。
  7. Titles / Transitions / Effects / Generators の中から追加されたものを探す。
  8. タイムラインへドラッグ。

初心者はまずこの形式を優先。

.settingFusion

.settingは第二候補

Fusionのテンプレート本体。良いテンプレが.settingしかない時に使う。最初からこれを優先しない。

必要になったテンプレだけ個別に導入手順を確認する。

.compFusion

.compは後回し

Fusion Composition。使えるが、初心者には.drfxより手順が増える。

第一候補に良いものがなければ見る。

動画素材MP4/MOV

完成動画素材なら普通の素材として入れる

ダウンロードしたMP4/MOVをMedia Poolへドラッグ。その後タイムラインへ置くだけ。

カウントダウンなど「完成済み動画」の場合。

CUT / TRIM

テンプレ全部を使わず、必要なところだけ使う

  1. テンプレをタイムラインへ置く。
  2. 再生して、使いたい動きの開始位置を探す。
  3. 再生ヘッドをそこへ置く。
  4. Command + B で切る。
  5. 終了位置でも同じように Command + B。
  6. 不要な前後を選択してDelete。
  7. 必要ならクリップの左右端をドラッグして長さを微調整。
覚えるのはこれだけ： テンプレを置く → 再生する → Command+Bで前後を切る → いらない部分を消す。

01 / LYRICS

歌詞

全文ではなく、曲の中で目立たせたい短いフレーズだけ。

第一候補・無料

Quick Switch Text Title

短い文字がテンポよく切り替わる。StaRtの速さと相性が良い。

使い所：イントロ / サビの短い歌詞 / 「StaRt」

目安：1〜3秒。

Preview / Download
補佐候補

Kinetic Text Titles

文字が弾む・伸びる系。サビで1フレーズだけ強調すると効く。

使い所：サビのキーワード

Preview
補佐候補

Happy Text Animator

Bounce / Spin / Wiggle系。WELCOMEやStaRtなど1語向け。

使い所：冒頭タイトルのアクセント

Preview

第一候補

Fast Photos Opener

高速写真切替。StaRtのサビで一番使いやすい候補。

使い所：1番または2番サビの写真ラッシュ

目安：5〜10秒だけ。

Preview
補佐候補

Photo Slideshow

写真＋短文をセットで見せたい場合。

使い所：2人の思い出

Preview
補佐候補・無料

Motion Blur Swipe

テンプレではなく写真間の切替だけ追加したい時。

使い所：連続写真の一部

Preview

05 / COUNTDOWN

カウントダウン

最後の数秒だけ。テンプレを使う価値が高い場所。

第一候補・無料

Uppbeat Countdown Timers

まずこれを試す。1920×1080のカウントダウン候補。

使い所：2番後の間奏終盤 → 5,4,3,2,1 → 入場

目安：5〜8秒。

Preview / Download
補佐候補

Countdown Timer

7種類から選択。無料候補が合わなかった時。

使い所：最後の5→1

Preview
補佐候補・旅行寄せ

Modern Digital Countdown

デジタル表示なので、空港のDeparture Board風と統一する場合に面白い。

使い所：空港案内風のラスト

Preview

FOR THIS MOVIE

今の第一候補だけ並べると

  1. WELCOME： Travel Titles
  2. StaRt： Quick Switch Text または Stamp
  3. 新郎新婦： Titles With Photo
  4. 歌詞： Quick Switch Text、サビだけKinetic
  5. 写真ラッシュ： Fast Photos Opener
  6. 旅行： Route Planner + 必要ならTravel Icons
  7. 最後： Uppbeat Countdown → 5,4,3,2,1

これを全部使うと決めたわけではない。 Previewを見て好きなものだけ採用する。
