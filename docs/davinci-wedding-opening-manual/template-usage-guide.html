RULE

まず1本だけ。

気に入ったものを1本試す。動いたら次を増やす。

入れ方を見る →
← Studio 入れる 使う部分 歌詞 紹介 写真 旅行 5→1 候補棚

DOWNLOAD → DAVINCI

落としたら、どう入れる？

ファイルの最後を見る。そこで入れ方が決まる。

.drfx
いちばん楽

ダブルクリックで入れる

  1. ダウンロードした .drfx をダブルクリック
  2. DaVinciが開いたら Install
  3. Edit → Effects
  4. Titles / Transitions / Effects / Generators を探す
  5. 見つけたらタイムラインへドラッグ
MP4
完成動画素材

普通の動画として入れる

  1. MP4 / MOVを Media Pool へドラッグ
  2. そこからタイムラインへドラッグ

カウントダウンが「完成済み動画」で配られている時はこれ。

.setting
必要な時だけ

Fusionテンプレ

使えるけど、最初からここに飛び込まない。欲しいテンプレが.settingしかない時に、そのテンプレ専用の入れ方を確認する。

.comp
さらに後

Fusion Composition

編集自由度は高い。そのぶん触る場所も増える。今は補佐候補。

迷ったら： `.drfx` → MP4/MOV → `.setting` → `.comp` の順で見る。
