WEDDING OPENING / BEGINNER TEMPLATE GUIDE

テンプレを
必要なところだけ使う

動画編集は初心者でOK。まず覚えるのは見る → ダウンロード → 入れる → 置く → 切る → 文字や写真を変えるの6つだけ。

FIRST

最初はこの6手順だけ

① 見るPreviewを再生。StaRtの速さに合うかだけ見る。
② Download気に入った1本だけ。最初から大量に入れない。
③ DaVinciへ入れる.drfxならダブルクリックが基本。
④ タイムラインへ置くEdit画面のEffectsからドラッグ。
⑤ 必要な部分だけ切るCommand + Bで前後を切る。
⑥ 自分用に変える文字・写真・色だけ変更。

第一候補＝最初に試す。補佐候補＝第一候補が好みでない・動かない・使いにくい時の次候補。

FILE TYPE

ダウンロードした後、まずファイル名の最後を見る

初心者おすすめ.drfx

.drfx → ダブルクリック

DaVinci用のインストールファイル。今回まず選びたい形式。

  1. Macのダウンロードフォルダを開く。
  2. ○○○.drfx をダブルクリック。
  3. DaVinciが開いたら Install。
  4. DaVinciのEdit画面へ。
  5. 左上のEffectsを押す。
  6. Titles / Transitions / Effects / Generators から追加されたものを探す。
  7. 見つけたらタイムラインへドラッグ。

迷ったら「.drfxか？」を最初に見る。

簡単MP4 / MOV

MP4 / MOV → 普通の動画として入れる

完成済みのカウントダウン動画など。Media Poolへドラッグ → タイムラインへドラッグでOK。

文字や数字を後から変更できない素材もある。

必要な時だけ.setting

.setting → まだ覚えなくていい

Fusionテンプレート本体。欲しいテンプレが.settingしかない時だけ、そのテンプレ専用の導入手順を見る。

後回し.comp

.comp → Fusion用

今は第一候補にしない。良い.drfxや動画素材がない時の補佐候補。

WHERE TO PUT IT

タイムラインのどこに置く？

V3歌詞・WELCOME・名前など文字
V2旅行アイコン・スタンプ・装飾
V1写真・動画・スライドショー
A1Mrs. GREEN APPLE「StaRt」

たとえば写真の上に「WELCOME ABOARD」を出したいなら、写真はV1、文字テンプレはV2かV3に置く。上下に重ねると同時に表示できる。

CUT

テンプレの「使いたい数秒だけ」にする

  1. テンプレをタイムラインへ置く。
  2. ▶︎で再生して、使いたいところを探す。
  3. 使い始めたい位置に白い再生ヘッドを合わせる。
  4. Command + B。
  5. 使い終わりたい位置でも Command + B。
  6. 前後のいらない部分をクリックして Delete。
今はこれだけ覚える： 再生 → Command+B → 不要部分をDelete。

注意： Fusionタイトルなどは「クリップの長さを短くするだけ」でアニメーション全体が圧縮・変化するタイプもある。Previewと動きが変になったら無理に切らず、そのテンプレは一旦補佐候補へ。
