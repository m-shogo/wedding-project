AI × DAVINCI

生成動画AIを使わずにできること

完成動画をAIに丸投げせず、AIに部品や設計を作らせて、DaVinciで自分が仕上げる。今回はこちらを優先する。

01

AI → SVG / PNG素材 → DaVinciで動かす

搭乗案内、スタンプ、地図、飛行機、ルート線、チケットなどをAIで作り、DaVinciのZoom / Position / Keyframeで動かす。初心者向けで失敗しにくい。

02

AI → Fusionテンプレート（.setting）

AIに「StaRtタイトル」「カウントダウン」「搭乗案内」などのFusion構成を作らせる方法。FusionのマクロはTitle / Generator / Effect / TransitionとしてEditページに保存できる。

03

.setting をまとめて .drfx にする

自作テンプレートを1つのインストール用ファイルにまとめられる。ダブルクリックでDaVinciへ追加できるので、今回用の「Wedding Travel Pack」にすることも可能。

04

AI → SRT → テキストを時間どおり配置

決めた秒数とテキストからAIにSRTを作らせ、DaVinciへ読み込める。字幕として素早くタイミング確認する用途に向く。凝った歌詞演出は最終的にText+ / Fusionへ置き換える。

05

AI → JSON構成表 → Python / Lua → DaVinci

JSONをDaVinciが直接読み込むわけではない。「0:12でStaRt表示」「1:59からカウントダウン」などをJSONで管理し、DaVinciのスクリプトAPIを使うPython / Luaがその指示を読む。写真配置、マーカー、テキストなどの自動化候補。

06

DaVinci 21の既存テンプレートを使う

最初からあるFusionタイトルをドラッグし、文字・色・速度だけ変更する方法も使う。ゼロからFusionを組む必要がないものは既存テンプレート優先。

今回のおすすめ順： まず「SVG/PNG + Editページ」→ 必要な演出だけ「Fusionテンプレート」→ 同じ作業が増えたら「JSON + Script」。最初から自動化を目的にしない。

生成AIへそのまま渡すプロンプト

ここにプロンプトを集約する。チャット本文には大量に並べない。

IMAGE / DESIGN旅行風「StaRt」タイトル素材
結婚式のオープニングムービーで使う「StaRt」のタイトル演出用ビジュアル素材を作ってください。テーマは旅行・出発・搭乗開始。明るく爽やかで、これから楽しい旅が始まるワクワク感を最優先にしてください。空港の搭乗案内、飛行機、旅のルート線、出発スタンプ、航空券などから必要な要素だけを洗練して組み合わせてください。人物は生成しません。実際の新郎新婦の写真を後からDaVinci Resolveで重ねます。文字を後から編集できるよう、「StaRt」そのものを画像に焼き込む案と、文字なし背景素材の案を分けて提案してください。16:9、1920x1080を前提。テンプレート感・AIっぽい過剰な装飾・映画予告風の重い雰囲気は避け、旅行雑誌や航空会社の明るいトラベルグラフィックのような方向にしてください。
DAVINCI / FUSIONFusionテンプレート生成依頼
DaVinci Resolve 21のFusionで使える、結婚式オープニングムービー用の再利用可能なタイトルテンプレートを設計してください。テーマは旅行・出発。メイン文字は「StaRt」で、WELCOME ABOARD、DESTINATION: WEDDING、日付などへ差し替えられる構造にしてください。初心者がEditページのInspectorだけで Text / Font / Size / Color / Animation Speed を調整できるよう、必要なパラメータだけ公開してください。過剰な3Dや重いプラグインは使わず、標準ノード中心。最終的にFusion Macro / .setting として保存し、Edit > Titlesから使える構成を優先してください。必要ならノード構成、キーフレーム、保存手順までセットで出してください。実在しないノードやパラメータ名を作らず、DaVinci Resolve 21で確認可能な標準機能のみ使用してください。
AUTOMATIONJSON構成表 + DaVinciスクリプト依頼
DaVinci Resolveで結婚式オープニングムービーを組むための補助ツールを設計してください。まず、人間が編集しやすいJSONに、timeStart / timeEnd / type / text / asset / note を持つ構成表を定義してください。そのJSONを読み、DaVinci Resolveの公式スクリプトAPIを使って可能な範囲でタイムライン作成、マーカー配置、素材配置などを自動化するPythonまたはLuaスクリプトを作ってください。JSONをDaVinciへ直接importできるとは仮定しないでください。対応APIがない操作は無理に自動化せず「人間がDaVinci上で行う操作」と明記してください。今回の動画は1920x1080、旅行テーマ、Mrs. GREEN APPLE「StaRt」を2番後の間奏まで使う予定です。

CHAPTER 01

起動したところから、音楽を取り込むまで

ここではまだ動画を作り込みません。「プロジェクトを作る → Edit画面を開く → StaRtをDaVinciに入れる」だけです。

このマニュアルのルール

  • 一度にたくさん覚えない。
  • 初めて出てくる言葉は、その場で意味を書く。
  • 「どこを押すか」が分かる操作図を付ける。
  • 会話で実際に決めたこと・進んだことだけ追記する。
  • PCで読みやすいことを最優先。SPは普通に読めれば十分。
STEP 1

新しいプロジェクトを作る

DaVinci Resolveを起動した直後の画面で、下のほうにある New Project を押します。

入力する名前

Wedding Opening

名前を入れたら Create を押します。

STEP 2

画面下の「Edit」を押す

プロジェクトが開くと、画面の一番下にページ切り替えがあります。今回はまず Edit だけ使います。

今は触らなくてOK： Fusion / Color / Fairlight / Deliver
STEP 3

「Media Pool」がどこかだけ確認する

Edit画面の左上に、写真・音楽・動画を置いておく場所があります。これを Media Pool（メディアプール） と呼びます。

難しい言葉を日本語にすると Media Pool ＝ 素材置き場

この段階では、他の場所の名前は覚えなくて大丈夫です。

STEP 4

StaRtの音楽ファイルを入れる

  1. MacのFinderを開く。
  2. 手元にある「StaRt」の音楽ファイルを探す。
  3. そのファイルをマウスでつかむ。
  4. DaVinci左上のMedia Poolの空いているところへドラッグ。
  5. Media Poolに曲名が表示されたら成功。
