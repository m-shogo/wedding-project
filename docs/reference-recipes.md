# 参考レシピ一覧（おいしいとこどり素材集）

有名な旅行フィルム、映画予告編、冒険アニメOP、航空ブランド映像などから
**技法（型）だけを学んで**、結婚式ムービーで使い回せる形にした一覧。

- 映像そのものはコピーしない。学ぶのはカメラの動き、間、つなぎ、光の使い方など抽象化した型だけ。
- 各レシピは「どのモーションを、どの章の、どの役割で使うか」をセットで持つ。
- `motion` の語彙は `docs/templates/sample-clips.csv` の `motion` 列と共通。
  素材を切り出したら、そのクリップに使ったレシピの `motion` をタグ付けする。
- 実素材が集まらない/権利が不安な型は、`motion-studio` のRemotionテンプレで自作できる。

関連: [Style Bible](02_style-bible.md) / [ムービー構成](03_movie-structure.md) / [失敗例](failure-patterns.md) / [切り出しツール](../scripts/slice_clips.py)

## パイプライン（集める→まとめる→切る→選ぶ）

```text
① 集める     無料素材を 10_references/media/pool/ に置く（Git管理外）
             入手先: docs/free-sample-sources.md（ライセンスは都度確認）
② まとめる   python3 scripts/slice_clips.py reel --write
             → 10_references/media/reel/review_reel.mp4（1本の確認用リール）
③ 切る       1本をスクラブし、使いたい区間の in/out を sample-clips.csv に記録
             → python3 scripts/slice_clips.py slice --write
④ 選ぶ       切り出したクリップを見て pick と rating を更新
             → おいしいとこどりだけが 10_references/media/clips/ に残る
```

切り出す時は、下のレシピから「この動き（motion）を使う」と決めてから区間を選ぶと、
散らからずにストックできる。

## モーション語彙（motion）

`sample-clips.csv` の `motion` 列と、下のレシピで共通に使う値。

| motion | 動き | 向く章・用途 | 破綻・注意 |
|---|---|---|---|
| `slow-push-in` | ゆっくり寄る | 導入・写真・扉 | 寄りすぎない。加速を柔らかく |
| `slow-pull-out` | ゆっくり引く | 締め・全景見せ | 最後は急停止させない |
| `slow-pan-left` | 左へ横移動 | 空・海・地平線 | 一定速のロボ移動を避ける |
| `slow-pan-right` | 右へ横移動 | 空・海・地平線 | 同上 |
| `tilt-up` | 上へ振る | 出発・希望・空へ | 上げ切りで余韻を残す |
| `tilt-down` | 下へ振る | 到着・着地・現在へ | 落ち着かせて止める |
| `drift` | 微速で漂う | 雲・水・光の背景 | 主役を作らずループ前提 |
| `parallax` | 前後景がずれる | 機内窓・車窓 | 前景の破綻に注意 |
| `rack-focus` | ピント送り | 手元→背景の切替 | 一回だけ。往復させない |
| `speed-ramp` | 速度を変える | 離陸・高揚・章転換 | 変化点は1つ |
| `whip-pan` | 振り切ってつなぐ | 冒険章の畳みかけ | 連発しすぎない |
| `match-cut` | 形/光でつなぐ | 章と章の間 | 形か光のどちらかを合わせる |
| `locked` | 固定 | 予告編の「間」・夜景 | 動かさない勇気 |
| `handheld-subtle` | 微手持ち | ドキュメント感 | 周期的な揺れにしない |

## レシピ一覧

型の出どころは「ジャンルの定番文法」を指す。特定作品の複製ではない。

| id | 名前 | 章 / role | motion | 型の出どころ | ビート・尺 | つなぎ | テロップ | 避けること |
|---|---|---|---|---|---|---|---|---|
| rec-01 | 出発の予感 | 1 / 導入 | `slow-push-in` | 旅行CM/航空ブランド | 3–5秒。静→ほんの少し寄る | 白/光フェードで次へ | 下中央に一言、余白広め | 速い寄り、人物の顔 |
| rec-02 | 空へ抜ける | 1 / 章切替 | `tilt-up` + `speed-ramp` | 予告編の高揚 | 4秒。地上→空へ上げ切り | 雲へディゾルブ | ここでは入れない | 同時多重カメラ |
| rec-03 | 雲海を流す | 1→3 / 背景 | `drift` | 旅行フィルムB-roll | 5秒ループ | クロスフェード | 上部に余白確保 | 流体CG風の作りすぎ |
| rec-04 | 距離を地図で語る | 3 / つなぎ | `slow-push-in` | アドベンチャー地図演出 | 4秒。航路がゆっくり伸びる | 到着地でカット | 地名はRemotionで載せる | 読める文字を焼き込む |
| rec-05 | 光で章を切る | 5 / 章切替 | `match-cut`(光) | 予告編/ブランド映像 | 2–3秒。光が満ちて白へ | 白フェード | なし | 派手なフレア連発 |
| rec-06 | 予告編の「間」 | 全般 / 緊張 | `locked` | 映画予告編 | 1–2秒静止→一拍→カット | 黒フェード | 短い一行だけ | 動かしてしまう |
| rec-07 | 冒険OPの畳みかけ | 4 / テンポ | `whip-pan` | 冒険アニメOP | 各0.3–0.6秒を連続 | スタンプ/whipで連結 | 地名スタンプを重ねる | 3連以上の乱発 |
| rec-08 | 窓の外を流す | 1・3 / 背景 | `parallax` | 機内・車窓の定番 | 5秒。窓枠固定で外が流れる | 次シーンへディゾルブ | 窓の暗部に短く | 窓枠の変形 |
| rec-09 | 海のゴールド | 4 / 背景 | `drift` | 旅行フィルム夕景 | 5秒ループ | クロスフェード | きらめきを避けた位置 | 露出のちらつき |
| rec-10 | 夜景の粒 | 3 / 背景 | `locked` | 都市ブランド映像 | 4秒。ボケが静かに明滅 | 黒フェード | 下中央 | カメラを動かす |
| rec-11 | 形でつなぐ | 章間 / つなぎ | `match-cut`(形) | 予告編の編集文法 | 前カット終端と次カット頭で丸→丸等 | ハードカット | なし | 形が合っていないのに使う |
| rec-12 | 到着の余韻 | 5 / 締め | `slow-pull-out` + `tilt-down` | 旅行CMの着地 | 5–6秒。引きながら落ち着く | 入場へ黒フェード | 日付・会場を静かに | 急停止・急ズーム |
| rec-13 | 写真に呼吸 | profile / 全般 | `slow-push-in` | 写真演出の定番 | 100%→108%を8秒 | クロスフェード | 顔にかけない | 全写真同じ動き |
| rec-14 | 手元から世界へ | profile / つなぎ | `rack-focus` | ドキュメンタリー | 3秒。手元→背景へ送る | ソフトカット | なし | ピント往復 |

## 使い方（どのモーションとこれ、の組み合わせ例）

章ごとの「効く並び」の例。素材が揃わない箇所は `motion-studio` で代替。

- **章1 出発**: rec-01 → rec-08 → rec-02 →（雲へ）rec-03
- **章3 交差**: rec-04 → rec-10 → rec-08
- **章4 冒険**: rec-09 → rec-07（スタンプ連打）→ rec-09
- **章5 到着**: rec-05 → rec-12 →（入場）
- **プロフィール**: rec-13 を主軸に、要所で rec-14

## motion-studio との対応（自作できる型）

権利が不安、または素材が集まらない型はRemotionで作れる（[motion-studio/README.md](../motion-studio/README.md)）。

| レシピ | motion-studio 代替 |
|---|---|
| rec-03 雲海 / rec-08 窓 | `雲海` / `飛行機窓` |
| rec-04 地図 | `地図-成田-沖縄` ほか区間テンプレ |
| rec-05 光で章を切る | `扉-光` |
| rec-07 冒険の畳みかけ | `押印連打-全路線` |
| rec-13 写真に呼吸 | `写真一枚` / `写真-沖縄` ほか |

## 学びを増やす時のルール

- 新しい型を見つけたら、まず1行レシピとしてここに追加する（idを振る）。
- 「特定作品のこのカット」ではなく「抽象化した動き・間・つなぎ」で書く。
- 実際に切り出して良かったクリップは `sample-clips.csv` に残し、
  使ったレシピの `motion` と `notes` にレシピidを書いて相互リンクする。
- 著作権のある映像・音源を本編へ焼き込まない。学ぶのは型だけ。
