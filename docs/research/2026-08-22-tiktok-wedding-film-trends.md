# 1. 2026 TikTokの大きな変化

TikTok公式の2026 Trend Reportの中心は **Irreplaceable Instinct**。
その中で最もOpeningに関係するのが `Reali-TEA`。

公式の要旨:

- fantasy / romanticizing 一辺倒から離れる
- staged scenarioよりreal world
- AIが作る完璧さよりhuman spark
- mundane / everyday momentsにも価値
- polishedなブランド演出より、実際の人の感情・背景・文脈

### Openingへの翻訳

**NG**

- どのカップルにも使える「Luxury Wedding Journey」
- 全写真へ同じslow zoom
- 意味のない英語ラベル
- 過剰なcinematic glow
- 完璧に均等な3カラム写真
- AI生成した旅行風景を主役にする

**採る**

- 実際の旅行写真のちょっとした失敗や偶然
- スマホ撮影特有の揺れ・露出差を完全には消さない
- 二人しか意味が分からない小さいdetail shot
- 写真同士の視線・構図・色・動きでつなぐ
- 画質差を「欠点」ではなく記憶の層として使う

# 2. 2026 Weddingで強い6つの方向

## 2.1 Documentary / candid

2026は「映画っぽく作る」より、「本当にあった日・本当にあった関係」に戻る傾向が強い。

Openingでは当日映像がまだ無いので、旅行写真・旅行中のスマホ動画をdocumentary素材として扱う。

### 原則

- poseよりin-between
- 正面記念写真だけでなく、歩いている・食べている・移動している・笑っている写真
- 完璧な一枚より、連続2〜3枚の方が強い場合がある
- 「二人の旅行の記録」に見えることを優先

---

## 2.2 Camcorder / Super 8 / home movie

Vogueを含め、2026 Weddingではcamcorder / Super 8 / guest cameraが明確に増えている。
理由は「レトロだから」ではなく、**不完全さが親密さに見えるから**。

### 採用方法

本物のSuper 8風filterを全編へ掛けない。
それをやると再びテンプレ化する。

使うなら:

- 0.5〜2秒の短いmemory fragment
- 低解像度の昔のスマホ動画
- 一瞬のdirect-flash静止画
- white balanceの揺れ
- date stampを使う場合も事実に基づく

### 禁止

- fake film burn大量使用
- fake dust / scratch全面常時
- 24fpsにしただけで「film」と呼ぶ
- 画質の良い写真をわざと全て汚す

---

## 2.3 Mixed media

2026 Weddingは、digital cinematic一色より

- digital
- phone
- camcorder
- film
- still photo
- voice / ambient sound

を混ぜるhybridが強い。

### Openingへの翻訳

旅行ごとに同じPhotoCardテンプレを使うのではなく、素材によってpresentationを変える。

例:

- 景色写真 → full bleed
- 縦スマホ写真 →余白を生かした1枚置き
- 連写2枚 → hard cut
- 短い実動画 → 音付き1〜2秒
- detail → crop close-up
- hero → 完全静止でも良い

---

## 2.4 Vertical social cut

TikTok / Reels向け9:16は2026 Weddingの標準的な副納品物になっている。
ただし披露宴上映本体は16:9。

### 方針

Opening V1を9:16へ無理に寄せない。
代わりに**16:9 masterを作る時点で、主要被写体を9:16 safe crop可能にする**。

最終的に:

- 16:9 / 60秒：披露宴上映
- 9:16 / 30〜45秒：SNS teaser

を同じ素材から別編集する。
単純cropはしない。

---

## 2.5 Sound-first storytelling

2026 Weddingではvows / speech / voice note / room toneなど音声が重要になっている。
Openingには誓いの言葉はまだ無いが、同じ考え方を適用できる。

### Openingで使える音

- 空港環境音
- 離陸前の低い機内音
- 海
- 街の環境音
- シャッター
- 一瞬のスマホ動画のoriginal audio

### 編集技術

- J-cut: 次の場所の音を画より先に入れる
- L-cut: 前の場所の音を次の画まで残す
- 全カットへwhooshを入れない
- BGMのkickだけに切らない
- 音ハメと意味ハメを混ぜる

---

## 2.6 Short-form pacing

TikTok/Reelsの影響でWedding Opening自体も短尺化。
60〜90秒は現状に合う。
Opening V1の60秒は維持して良い。

ただし「短尺 = 全カット速い」ではない。

### 重要

速い部分と止まる部分を作る。

例:

```text
0.0 - 0.7  hook detail
0.7 - 1.1  hard cut
1.1 - 1.8  second detail
1.8 - 3.5  breathe / hero
3.5 - 3.8  flash of another memory
```

同じ2秒尺を並べない。

# 3. TikTokの「Photo Dump」をWedding Openingへ翻訳する

TikTokのtravel文脈ではPhoto Dumpが継続的に使われる。
重要なのはscrapbook装飾ではなく、**「選び抜かれた完成作品」ではなく、記憶の束を覗く感じ**。

Openingでは:

- 旅行ごとに写真3枚を均等に並べない
- 1枚を大きく → 0.3秒detail → 別の1枚、のように階層化
- 縦横比を無理に統一しない
- 必要なら黒/白の余白を残す
- 位置を少しずらすのは意味がある場合だけ

Pinterest風collageにはしない。

# 4. 2026 nostalgiaをどう扱うか

2026は2010年代回帰を含むnostalgiaが強い。
Weddingでもcamcorder / Super8が伸びている。

このプロジェクトでは「古く見せる」のではなく、
**二人が実際に撮った年代ごとのカメラ差を残す**方が強い。

例:

- 古いiPhone写真 → そのまま
- 夜のノイズ → 必要以上にAI denoiseしない
- 4:3動画 → 16:9へ無理にcropしない選択肢
- live photo / burstがあれば短いmotion化

偽のnostalgiaより本物のデジタル記憶を使う。

# 5. Opening V1に対する具体的な変更判断

## 維持

- 60秒
- 実写真主体
- 旅行 → 横浜 → 入場というstory arc
- AIは背景/B-rollのみ

## 廃止候補

- 全scene共通のdecorative border
- `MEMORY 01 / 02 / 03`
- `ALTITUDE`
- `OUR JOURNEY`
- generic inspirational English copy
- 3枚を同寸法で横並び
- 全写真へ常時Ken Burns
- navy + goldを全編へ強制

## 新しい基準

### 写真表示

1. full bleed
2. native aspect ratio with intentional negative space
3. close crop detail
4. two-frame sequence
5. static hero

この5種を優先。
「カードに入れる」は6番目以降。

### transition

優先順:

1. straight cut
2. action / composition match cut
3. J/L audio bridge
4. dip to black / natural exposure transition
5. dissolve
6. designed transition

whoosh / zoom transitionは原則使わない。

### motion

写真にmotionを割り当てるのではなく、写真の構図から決定。
静止も正式なmotion choice。

# 6. AI生成動画の新ルール

TikTok 2026のhuman / real方向とWeddingのdocumentary回帰を考えると、AI B-rollを増やすほどOpeningは弱くなる可能性がある。

### AIを使う条件

- 実素材が存在しない
- 3〜4秒以下
- 人物なし
- story上必要
- 実写真を邪魔しない

### Prompt

形容詞を積むよりmotion command中心。

Bad:

```text
cinematic epic luxury romantic beautiful breathtaking wedding travel movie
```

Better:

```text
Clouds drift slowly from right to left.
Camera remains nearly locked.
Preserve the existing horizon and cloud structure.
```

AIの仕事を狭くするほどAIっぽさを減らす。

# 7. Openingで狙う独自スタイル

流行をそのまま採用すると2026テンプレになる。
このWedding Projectでは以下を混ぜる。

## `Travel Memory Documentary / Editorial` 

比率イメージ:

- 55% real travel photo/video
- 20% documentary / phone / imperfect memory
- 10% editorial typography / graphic
- 10% atmosphere / location B-roll
- 5% AI-assisted material maximum

これは厳密な秒数規則ではない。
「AI・graphicが主役になっていないか」を見るための判断目安。

# 判断原則

**流行しているから採用しない。**

採用条件は:

- 二人の実素材を強くするか
- 旅行の記憶として自然か
- 2026の見た目をコピーせず数年後も見られるか
- AI/テンプレを感じさせないか

この4つを満たすものだけOpeningへ入れる。
