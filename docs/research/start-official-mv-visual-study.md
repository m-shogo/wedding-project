# StaRt 公式MV 視覚研究ログ

日付: 2026-08-25
対象: Mrs. GREEN APPLE「StaRt」公式MV(YouTube, `https://www.youtube.com/watch?v=OTUtF7ZxRN8`)

## 調査方法と制約(重要)

- YouTube上で**ミュート再生**し、`currentTime`をJSで指定してframe単位のscreenshotを取得する方法で視覚研究を行った。動画・音源ファイルはdownloadしていない。
- **音声は一切聴取していない。** このセッションのブラウザ操作では音を再生・聴取する手段がないため、「音に反応した変化」の項目は**画面上の視覚的根拠(動きの唐突さ、graphic hitのタイミング、frameの構図変化)から強く推測したものであり、実際のビートと照合した確認ではない**。この限界を隠さず明記する。
- YouTubeの字幕(caption)は歌詞を含むため、**表示前にOFFにした**。歌詞本文はこの文書に一切書き写していない。歌詞をネットから取得・転載する行為はしていない。
- ここに書くのは一般化した「原理」であり、公式MVの固有デザイン(具体的な図形の形、キャラクター性、正確な色コード等)を結婚式映像へそのまま複製しない。

## 一般化できる原理(公式表現の複製ではなく、原理として抽出したもの)

1. **「frame」という共通の窓を作り、中身だけを差し替える。** 額縁のような角丸長方形を固定の視覚的container(=identity)として使い、その中でtitle→楽器→アイコンとcontentを切り替える。frameが消えるとfull-bleedの生演奏shotになる、という**2つの状態(frame内/frame外)の往復**が全体のリズムを作っている。
2. **タイトル文字を1つの塊ではなく、独立したgraphic要素の集合として扱う。** 各文字が別の色・別のタイミングで登場することで、「文字が音と一緒に組み上がる」感覚が生まれる。
3. **物理的な動作(指で弾く、手を叩く)に、誇張されたgraphicを同期させる。** 音のwaveformを直接可視化するのではなく、「動作の瞬間」に「漫画的な反応」を足すことで音を感じさせている。
4. **背景motif(色・小道具)を区間ごとに切り替えて、雰囲気の対比を作る。** グレー+3D図形の区間と、暖色+星/月の区間が明確に違う。
5. **強い一体感が欲しい瞬間はwide shotを再利用する。** 同じ画を複数回使うことをためらわず、motifとして機能させている。
6. **静と動のコントラストが「気持ちよさ」を作っている。** frame内の小さな静かなgraphicシーンと、full-bleedで身体を大きく動かす演奏shotが交互に来ることで、密度に強弱がついている。

## 結婚式版への翻訳方針(公式デザインを複製しない)

公式MVの「frame」「文字色」「多面体」「星/月」といった**固有の見た目**はコピーしない。翻訳するのは**構造原理**だけ。

| 公式MVの原理 | 結婚式129秒への翻訳 |
|---|---|
| frame(窓)の中身だけ差し替える | A/B/C共通で使える「窓」の概念を作るのではなく、各案が独自のframe装置を持つ(A=光の縁、B=手描きコマ枠、C=editorial grid線)。公式のrounded-rectをそのまま使わない |
| 1文字ずつ・別色で組み上がるtitle | "StaRt"というband名/曲名のロゴを複製せず、**新郎新婦の名前や「ようこそ」等、結婚式の文脈の言葉**で同じ原理(1文字ずつ・音に同期)を使う |
| 動作に誇張graphicを同期 | 写真のcut/hard cutの瞬間に、控えめな(漫画的爆発ではなく)光・粒子・図形のaccentを同期させる。Style Bible上、過剰な漫画的表現はA/C案では避け、B案でのみ抑制的に使う |
| 背景motifの区間切り替え | 旅の場所(沖縄/ソウル/ハワイ/横浜)ごとに、色温度・質感を変える。ただし固定paletteを全編に被せない(既存Style Bible方針を維持) |
| wide shotの再利用 | Hero写真の再登場(cold open→chorus→End)は既存のOpening V1にもある考え方。公式MVから新たに借りるというより、既存方針の裏付けとして扱う |
| 静と動の交互 | 129秒全体の感情曲線(静か→溜め→hit→開放→余韻)の密度設計にそのまま反映する |

## 未確認・今後の限界

- 音声を聴いていないため、**上記の「音に反応した変化」はすべて画面の動きからの推測**であり、実際のbeat/歌唱と照合していない。正規音源が投入され次第、実際に聴きながら同じtimecode帯を再確認する必要がある。
- 219.8秒(約3:40)のMV全体のうち、約17地点のみをsamplingした。10秒間隔より粗い区間もあり、細かいcutの数(例: 1秒未満の高速cut)は数えていない。
- 歌詞の内容・意味とeditingの対応は、歌詞を見ていないため一切分析していない。
