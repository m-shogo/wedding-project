# Wedding Style Bible

## 目的

旅行テーマの結婚式ムービーで、すべての素材、テロップ、AI生成プロンプト、編集判断を同じ世界観にそろえる。

## 手順

1. `docs/02_style-bible.md` を読む。
2. ユーザーの好み、参考動画、写真の雰囲気を抽出する。
3. 色、光、質感、カメラ、フォント、禁止事項に分類する。
4. 曖昧な表現を、生成や編集で使える具体語に直す。
5. 変更する場合は `docs/02_style-bible.md` に反映する。

## 判断基準

- 主役は二人、家族、友人、犬、思い出。
- AIは背景、空気感、章切り替え。
- 旅行、出発、航路、到着のモチーフを優先する。
- 派手さより統一感を優先する。
