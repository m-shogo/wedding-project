# Wedding Rights Check

## 目的

会場上映、SNS投稿、YouTube公開、親族共有で権利・プライバシーのリスクを分けて確認する。

## 手順

1. `docs/08_rights-privacy.md` を読む。
2. 素材を `写真`, `動画`, `音源`, `フォント`, `テンプレート`, `AI生成素材` に分類する。
3. 利用先を `会場上映`, `SNS投稿`, `YouTube公開`, `親族共有` に分ける。
4. 不明な利用条件は推測せず、公式情報または素材配布元で確認する。
5. 判断が残る場合は `docs/decisions/` にメモする。

## 禁止

- 権利が不明な音源を安全だと断定する。
- 実写真を外部AIへアップロードしてよいと断定する。
- 人物や犬のAI変形を安易に提案する。
