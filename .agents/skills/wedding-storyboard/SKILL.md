# Wedding Storyboard

## 目的

写真、動画、AI背景素材、テロップ、BGMタイミングを1秒単位で設計する。

## 手順

1. `docs/03_movie-structure.md` を読む。
2. 使用予定の素材リストを確認する。
3. 各素材を `実写真`, `実動画`, `AI画像`, `AI動画`, `テロップ`, `不採用候補` に分類する。
4. 章ごとに役割を決める。
5. `docs/templates/storyboard.csv` の列に合わせて秒割りを作る。

## 注意

- AI動画候補は先に絞る。
- 人物や犬はAI化しない。
- 緩急を入れる。
- ゲストが飽きないよう、同じ動きを続けすぎない。
