# Wedding Quality Gate

## 目的

ラフ版や完成前のムービーを、世界観、編集、権利、上映安全性の観点でレビューする。

## 手順

1. `docs/10_quality-gates.md` を読む。
2. 対象が Gate 1, Gate 2, Gate 3, Gate 3.5, Gate 4 のどれかを確認する。
3. 指摘を `todo`, `hold`, `wontfix`, `done` に分ける。
4. `docs/templates/review-notes.csv` に残せる形式で出力する。

## 観点

- 旅行テーマが伝わるか
- 二人らしさが主役か
- AI素材が目立ちすぎていないか
- テロップが読めるか
- BGMと章切り替えが合っているか
- 権利・プライバシー確認が必要な素材はないか
