# Wedding CapCut Plan

## 目的

素材リストを、CapCutで迷わず組める編集指示書に変換する。

## 手順

1. `docs/05_capcut-editing.md`、`docs/capcut-operation.md`、`docs/failure-patterns.md` を読む。
2. 写真ごとに表示秒数、パン方向、ズーム、テロップ位置を決める。
3. BGMの盛り上がりに章切り替えを合わせる。
4. トランジションはクロスフェード、黒フェード、白フェードを基本にする。
5. 派手な効果より、テンポと感情の流れを優先する。

## 出力形式

素材ごとに次を出す。

- ファイル名
- 秒数
- 動き
- テロップ
- トランジション
- BGMメモ
- 注意点

可能なら `docs/templates/capcut-edit-plan.csv` の列に合わせる。
