# CapCut編集指示書 — オープニングムービー（105秒版）

作成日: 2026-06-10

## 作業前の確認

1. プロジェクト作成・会場仕様に合わせた画角・解像度設定（未確定の場合は16:9 / 1920x1080 暫定）
2. BGMを最初に置く
3. BGMを聴きながら下記マーカーを打ってから各クリップを配置する

## BGMマーカー位置

| マーカーID | 秒数 | 目的 |
|-----------|------|------|
| M-01 | 0秒 | 暗転スタート。BGMを10%から開始 |
| M-02 | 8秒 | 映像スタート |
| M-03 | 18秒 | テロップ章。BGMを落ち着かせる |
| M-04 | 45秒 | **白フェード明転・BGM第1の山（最重要）** |
| M-05 | 65秒 | 実写真解禁。BGMが温かくなる位置 |
| M-06 | 82秒 | 到着・現在。BGMが穏やかになる |
| M-07 | 93秒 | 余韻スタート。BGMフェードアウト開始 |
| M-08 | 105秒 | エンド暗転。BGM完全に0 |

## 各クリップ設定

### Chapter 0 — カウントダウン（0〜8秒）

| 項目 | 設定 |
|------|------|
| 背景 | 黒クリップ（カラークリップで黒） |
| テロップ | 「5」→「4」→「3」→「2」→「1」各1秒、白文字、中央 |
| テロップフォント | 細ゴシックまたは明朝、影なし |
| テロップフェード | イン0.3秒 / アウト0.2秒（各数字ごと） |
| トランジション | 入口: なし（暗転スタート）、出口: 黒フェード0.5秒 |
| BGM | 0〜8秒でボリュームを10%→80%に上げる |

### Chapter 1-A — 空港・出発の気配（8〜18秒）

> 注意: この章の素材の元静止画（op_11 / op_01）は人物入りで不採用（`asset-status.md` 参照）。
> 人物なし版を再生成・I2V化してから下記ファイル名で配置する。それまでこの章は仮組み扱い。

| 項目 | 設定 |
|------|------|
| ファイル | airport-lobby-01.mp4 / taxiway-light-01.mp4 |
| クリップ数 | 2カット（各5秒） |
| キーフレーム | 0秒=100% → 5秒=105%（両カット共通） |
| テロップ | なし |
| トランジション | 入口: 黒フェード0.8秒 / クリップ間: クロスフェード0.8秒 |
| 注意 | AI素材の音声は0にする |

### Chapter 1-B — 搭乗券・出発宣言（18〜27秒）

| 項目 | 設定 |
|------|------|

| テロップ位置 | 下中央（下端から15〜18%） |
| テロップフェード | イン1.0秒 / 表示6秒 / アウト1.5秒 |
| トランジション | 入口: クロスフェード1.0秒 |
| 注意 | 背景の輝度を-20前後に落としてテロップを際立たせる |

### Chapter 5-B — 余韻・入場へ（93〜105秒）

| 項目 | 設定 |
|------|------|

## 書き出し前チェックリスト

### 映像
- [ ] Chapter 0 の黒背景が完全に黒になっている
- [ ] 2-B → 3 の白フェードがBGM山（45秒）と一致している
- [ ] AI素材が背景として機能し、目立ちすぎない
- [ ] 写真1枚の表示時間が3秒を下回っていない
- [ ] 写真の動きが単調（ズームインだけ）になっていない

### テロップ
- [ ] 全テロップが白文字になっている
- [ ] テロップが顔・目線にかかっていない
- [ ] 「2026.10.24 / Yokohama」の日付・会場名が正しい
- [ ] 写真テロップの年・場所が合っている

### トランジション
- [ ] 白フェードは2-B→3のみ
- [ ] エンドの黒フェードが2秒以上ある

### 音
- [ ] AI素材の音声がすべてミュート
- [ ] BGMが0秒から小さく始まり、105秒で完全に0
- [ ] 入場曲へ無音でつなぐ余白がある

### 書き出し
- [ ] 解像度が会場仕様に合っている
- [ ] MP4 H.264形式
- [ ] バックアップファイルを別名で書き出している

## 作業順序

1. プロジェクト作成・画角設定
2. BGMをタイムラインに置く
3. M-01〜M-08のマーカーを打つ
4. 黒クリップをChapter 0（8秒）に置く
5. AI素材を章順に並べる
6. 実写真を4-B・5-Aに並べる
7. マーカーと各章の入口を揃えてクリップ長を調整
8. キーフレームを設定
9. **2-B→3の白フェードを最初に確認**
10. 残りのトランジションを入れる
11. テロップを各章に置く
12. BGMのフェードイン・フェードアウト設定
13. AI素材の音声をミュート
14. 通しで再生して書き出し前チェック
15. ラフを書き出す
