# オープニングムービー

## 目的

披露宴の始まりとして、旅行の出発感を作る。

現在のサンプル題材は「旅行」。今後テーマが変わる可能性があるため、旅行モチーフは差し替え可能なレイヤーとして扱う。

## 作業ファイル

- 詳細ロードマップ: `02_opening-movie/roadmap.md`
- Style Bible: `docs/02_style-bible.md`
- 会場仕様: `docs/templates/venue-specs.csv`
- BGM候補: `docs/templates/music-candidates.csv`
- 参考映像: `docs/templates/reference-log.csv`
- AI素材候補: `docs/templates/ai-shot-list.csv`
- CapCut編集指示: `docs/templates/capcut-edit-plan.csv`

## 方向性

- 空港
- 搭乗券
- 滑走路
- 雲
- 出発アナウンス

AI素材は背景と空気感に限定する。

## 最初の作業

1. 会場の入場前演出の流れを確認する。
2. BGM候補を集める。
3. 旅行テーマの参考映像を集める。
4. 10秒試作を作る。
5. 30秒試作へ進む。
