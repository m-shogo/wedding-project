# プロフィールムービー

## 目的

旅行テーマで、新郎新婦それぞれの旅、出会い、冒険、到着を見せる。

## 作業ファイル

- ブリーフ: `01_profile-movie/brief.md`
- 詳細ロードマップ: `01_profile-movie/roadmap.md`
- 章別プラン: `01_profile-movie/chapter-plan.md`
- 絵コンテ: `docs/templates/storyboard.csv`
- 写真選定: `docs/templates/photo-selection.csv`
- CapCut編集指示: `docs/templates/capcut-edit-plan.csv`
- 素材ログ: `docs/templates/asset-log.csv`
- Style Bible: `docs/02_style-bible.md`

## 素材

実写真・実動画は原則Gitに入れず、ローカルで管理する。

## 最初の作業

1. 会場仕様を確認する。
2. BGM候補を集める。
3. 写真候補を選ぶ。
4. Chapter 1 出発の10秒試作を作る。
5. 30秒試作へ進む。
