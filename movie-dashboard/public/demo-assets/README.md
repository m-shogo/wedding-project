# Demo stock media

このディレクトリはモーション図鑑の表示・演出検証用です。本人、家族、挙式当日の実素材ではありません。

- `stock-photos/`: Pexels由来のデモ写真。各ファイルの配布ページ、作者、ライセンスURL、SHA-256は `src/data/demoStockMediaCatalog.ts` を正本とします。
- `bgm-candidates/`: Pixabay由来のジャンル別BGM候補。全4曲が配布ページ上でContent ID登録済みのため、試聴・編集候補に限定し、最終公開承認は `false` のままです。
- 写真は最終納品前に本人素材へ差し替えます。
- BGMは採用時点で配布ページ、Pixabay Content License、ダウンロード記録、公開先のContent ID運用を人間が再確認します。
