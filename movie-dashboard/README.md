# MEMORY FLIGHT — Wedding Movie Dashboard

結婚式ムービー制作の管理ハブ。オープニングムービー、プロフィールムービーなど複数ムービーに対応。

シーン、素材、プロンプト、タスクをブラウザ上で編集・管理できる。データはlocalStorageに保存され、JSON形式でエクスポート・インポート可能。

詳しい使い方、運用ガイド、Tipsはアプリ内の **📖 使い方** ページに集約する。

## 起動方法

```bash
cd movie-dashboard
pnpm install
pnpm dev
```

ブラウザで `http://localhost:5173` を開く。

## まずダッシュボードを見る

ダッシュボードの **AI動画パイプライン** が現在地を自動集計する。

```text
① Prompt下書き
   ↓
② 生成・結果待ち
   ↓
③ 結果レビュー
   ↓
④ 採用 → CapCut実尺

不採用
   ↓
retry 1/3 → retry 2/3 → retry 3/3
   ↓
STOP / ショット設計見直し
```

レビュー待ちがあれば新規生成よりレビューを優先するなど、`NEXT ACTION` に次に開く画面を表示する。

## AI動画の最短フロー

1. **絵コンテ** で用途を決める。
2. **動画プロンプト** でシーンを選び、結婚式・旅行プリセットを適用する。
3. shot intentを必要な部分だけ修正する。
4. **動画生成キュー** で同じモデルのPromptをまとめて処理する。
5. 生成結果を素材ライブラリへ登録する。
6. Prompt Bankで結果AssetをPromptへ紐付ける。
7. **AI動画 結果レビュー** で共通QA＋プリセット固有QAを確認する。
8. PASSだけ採用し、CapCut実尺へ進める。
9. 不採用は理由を記録し、必要ならretry draftを作る。
10. 同系統のretryは最大3回。3回失敗したら静止画・参照・ショット・モデルを見直す。

## 動画プロンプトの考え方

動画AIへ毎回長文を手書きせず、先にショット意図を固定してモデル別に翻訳する。

```text
shot intent
  ↓
主動作 / カメラ / 速度 / 光 / 参照素材の役割 / テロップ余白
  ↓
Seedance / Runway / Veo 向けプロンプト
  ↓
生成前warning + AIっぽさQA
```

標準は **低コストで比較 → QA → 採用候補だけ高品質モデル → CapCut実尺確認**。

結婚式・旅行プリセット:

- 雲海
- 飛行機窓・地上
- 無人の搭乗ゲート
- 無人の空港ロビー
- 滑走路の灯り
- ハワイの海
- 旅先の夜景
- 扉から差す光

## 主な機能

- **AI動画パイプライン表示** — 下書き / 結果待ち / レビュー待ち / 採用 / 不採用をTOPで集計し、次の操作へ誘導
- **動画プロンプトビルダー** — Seedance 2.0 Mini / 2.0 / 2.5 preview / Veo 3.1 / Runway Gen-4.5 / Kling向けにshot intentを変換
- **結婚式・旅行プリセット** — 頻出8ショットの動き・カメラ・モデル候補・固有QAを初期入力
- **シーン自動紐付け** — Prompt保存時に絵コンテのsceneIdへ相互リンク
- **動画生成キュー** — モデル別グルーピング、一括コピー、draft→testing、Markdown/JSON出力
- **AI動画 結果レビュー** — 結果Assetありのtesting PromptをQAし、採用/不採用理由を記録
- **bounded retry** — 不採用理由を引き継いだretry draftを最大3回。過去の補正文を積み上げない
- **ダークモード** — サイドバーの🌙/☀️ボタンで切り替え
- **グローバル検索** — `⌘K` でシーン・素材・プロンプト・タスクを横断検索
- **Undo/Redo** — `⌘Z` / `⌘⇧Z`
- **キーボードショートカット** — `?`
- **ドラッグ&ドロップ** — 絵コンテの並び替え
- **シーンテンプレート** — シーン設定を再利用
- **プロンプト比較** — 2つのPromptを比較
- **品質ゲート** — Gate 1〜4
- **一括操作** — 素材・タスクの一括ステータス変更・削除
- **CSVエクスポート** — 素材ライブラリ・絵コンテ・CapCut編集パック
- **サムネイルプレビュー** — 素材ライブラリの画像パス
- **自動保存インジケータ** — 最終保存時刻を表示

## AI動画の絶対ルール

- AIは本編の主役ではなく、背景・B-roll・つなぎ素材。
- 新郎新婦、家族、友人、犬はAIで置換しない。
- 人物・動物・読める文字・ロゴ・看板が出た生成素材は不採用。
- 重要文字やテロップは生成映像へ焼き込まず、CapCut / Motion Studio側で載せる。
- 1ショット1主動作、1カメラ意図。
- 綺麗さより、実写真・実動画の前後に置いた時に浮かないことを優先する。
- 同じ失敗を3回続けない。retry 3/3で止める。

## データ管理

初期データは `src/data/*.json`。画面編集はlocalStorageへ自動保存される。

| ファイル | 内容 |
|----------|------|
| `movies.json` | ムービープロジェクト |
| `scenes.json` | 絵コンテ |
| `assets.json` | 素材 |
| `prompts.json` | 生成Prompt |
| `tasks.json` | タスク |

### localStorageとJSON

- 初期データは `src/data/*.json`。
- 画面編集後はlocalStorageが優先される。
- `src/data/*.json` を変更してもlocalStorageが残っていると画面へ反映されないことがある。
- 「デフォルトに戻す」でlocalStorageを破棄して初期JSONへ戻せる。
- 実制作データはJSONエクスポートでバックアップし、必要に応じて `src/data/*.json` へ反映してcommitする。

## 素材ファイルの保存先

大きな画像、動画、音源はGitに入れない。Assetにはパス・用途・採否を記録する。

| タイプ | 保存先 | Git |
|--------|--------|-----|
| 自前写真 | `/05_photos/` | ✕ |
| 自前動画 | `/06_videos/` | ✕ |
| 生成画像 | `/04_ai-video-assets/generated-images/` | ✕ |
| 生成AI動画 | `/04_ai-video-assets/ai-videos/` | ✕ |
| Motion Studio書き出し | `/90_exports/motion-studio/` | ✕ |
| 音源・BGM | `/07_music/` | ✕ |
| 参考資料 | `/10_references/` | URLやメモのみ |
| テキスト | `/08_texts/` | OK |

## 実制作Tips

- 作業開始時はダッシュボードの `NEXT ACTION` を見る。
- AI動画は動画Prompt → 生成キュー → 結果レビューの順で進める。
- 結果AssetをPromptへ紐付けるまで「生成完了」扱いにしない。
- retryを作る前に必ず不採用理由を記録する。
- 素材を登録したらシーンに紐付ける。
- CapCutで使った素材は「使用中」にする。
- 不足は口頭管理せず不足・未確定リストへ入れる。
- 大きな変更前はデータ管理からJSONをバックアップする。

## トラブル時

1. データが反映されない → JSONエクスポート後、「デフォルトに戻す」。
2. 整合性エラー → データ管理の検証実行。
3. `src/data/*.json` が反映されない → localStorageを確認。
4. 素材がシーンに出ない → 絵コンテで紐付け確認。
5. 生成結果がレビュー待ちに出ない → Prompt.status=`testing` かつresultAssetIdsありを確認。
6. retryが作れない → 不採用理由があるか、retry 3/3に到達していないか確認。
7. CapCut準備完了にならない → 必要素材のパス・状態を確認。
