# MEMORY FLIGHT — Wedding Movie Dashboard

結婚式ムービー制作の管理ハブ。オープニングムービー、プロフィールムービーなど複数ムービーに対応。

シーン、素材、プロンプト、タスクをブラウザ上で編集・管理できる。データはlocalStorageに保存され、JSON形式でエクスポート・インポートが可能。

詳しい使い方、運用ガイド、Tipsはアプリ内の **📖 使い方** ページに集約しています。

## 起動方法

```bash
cd movie-dashboard
pnpm install
pnpm dev
```

ブラウザで `http://localhost:5173` を開く。

## 基本の使い方

1. **ダッシュボード** で全体状況と優先タスクを確認する
2. **絵コンテ** でシーン構成を作る
3. **素材ライブラリ** で素材パスを登録し、シーンに紐付ける
4. **プロンプト管理** で生成プロンプトを登録する
5. **不足・未確定リスト** で足りない素材や未決定事項を管理する
6. **制作マップ** で詰まりを確認する
7. **CapCut編集パック** で編集指示を確認・書き出す
8. **データ管理** で整合性チェックとバックアップを行う

## 主な機能

- **ダークモード** — サイドバーの🌙/☀️ボタンで切り替え。設定はlocalStorageに保存される
- **グローバル検索** — `⌘K` でシーン・素材・プロンプト・タスクを横断検索
- **Undo/Redo** — `⌘Z` / `⌘⇧Z` でデータ変更を元に戻す・やり直す
- **キーボードショートカット** — `?` キーでショートカット一覧を表示
- **ドラッグ&ドロップ** — 絵コンテでシーンをドラッグして並び替え
- **シーンテンプレート** — 📌ボタンでシーン設定をテンプレートに保存、新規作成時に再利用
- **プロンプト比較** — ⚖️ボタンで2つのプロンプトを並べて比較
- **品質ゲート** — Gate 1〜4のチェックリストで制作段階ごとの品質を確認
- **一括操作** — 素材・タスクのチェックボックス選択で一括ステータス変更・削除
- **CSVエクスポート** — 素材ライブラリ・絵コンテ・CapCut編集パックからCSV出力（BOM付き）
- **サムネイルプレビュー** — 素材ライブラリで画像パスのプレビュー表示
- **自動保存インジケータ** — サイドバーに最終保存時刻を表示

## データ管理

初期データは `src/data/*.json`。画面で編集した内容はlocalStorageに自動保存される。

| ファイル | 内容 |
|----------|------|
| `movies.json` | ムービープロジェクト（オープニング、プロフィールなど） |
| `scenes.json` | シーン（絵コンテ）情報 |
| `assets.json` | 素材情報（パス、用途、ステータス） |
| `prompts.json` | 生成プロンプト |
| `tasks.json` | タスク（不足素材、未確定事項など） |

### localStorageとJSONの違い

- 初期データは `src/data/*.json` に入っている
- アプリで編集するとlocalStorageに保存される
- localStorageに保存済みの場合、`src/data/*.json` を直接編集しても画面に反映されないことがある
- データ管理の「デフォルトに戻す」でlocalStorageを破棄し、初期JSONに戻せる
- 実制作データを残すには「JSONエクスポート」でバックアップし、必要に応じて `src/data/*.json` に反映してcommitする

### Export / Import の使い方

- **エクスポート**: データ管理 → 「JSONエクスポート」で全データをダウンロード
- **インポート**: データ管理 → 「JSONインポート」でJSONファイルを読み込み（現在のデータは上書き）
- **リセット**: データ管理 → 「デフォルトに戻す」でlocalStorageを初期状態に戻す

大きな変更の前にはエクスポートでバックアップを取ること。

## 素材ファイルの保存先

大きな画像、動画、音源ファイルはGitに入れない。JSONには素材パス、メモ、用途、ステータスだけを保存する。

| タイプ | 保存先 | Git |
|--------|--------|-----|
| 自前写真 | `/05_photos/` | ✕ |
| 自前動画 | `/06_videos/` | ✕ |
| 生成画像 | `/04_ai-video-assets/generated-images/` | ✕ |
| 生成AI動画 | `/04_ai-video-assets/ai-videos/` | ✕ |
| Motion Studio書き出し | `/90_exports/motion-studio/` | ✕ |
| 音源・BGM | `/07_music/` | ✕ |
| 参考資料 | `/10_references/` | URLやメモのみ |
| テキスト | `/08_texts/` | OK |

素材ライブラリで素材を追加するとき、素材タイプに応じた「おすすめ保存先」が表示される。詳しくはアプリ内の **📁 素材置き場ガイド** ページを参照。

## 実制作Tips

- 作業の前後にデータ管理の「検証実行」でエラー0 / 警告0を維持する
- 素材を登録したら絵コンテでシーンに紐付ける
- CapCutで使った素材は「使用中」にステータスを変更する
- プロンプトの結果素材ができたら紐付ける
- 足りないものは不足・未確定リストに登録する — 口頭管理にしない
- 詳細は **📖 使い方** ページを参照

## トラブル時の確認方法

1. **画面にデータが反映されない** → データ管理の「デフォルトに戻す」でlocalStorageをリセット（先にエクスポート）
2. **整合性エラーが出る** → データ管理の「検証実行」でエラー内容を確認して修正
3. **src/data/*.jsonを変えたのに反映されない** → localStorageが優先されている。「デフォルトに戻す」で反映
4. **素材がシーンに表示されない** → 絵コンテの「+ 紐付け」でシーンに紐付ける
5. **CapCut準備完了にならない** → 紐付いた素材にパス未設定やステータス「必要」「アイデア」のものがないか確認
